:::box 直しノートの作り方（英語）
- ノートを1冊用意し、1ページを上下に分ける。上に「問題（写す or 番号）」、下に「正しい答え＋間違えた理由1行」。
- 理由は**自分の言葉で短く**：「三単現」「for と since」「分詞は名詞の後ろ」「know の過去分詞は known」など。
- 3日後・1週間後・前日の3回、ノートだけを見返す。**赤で書いた理由が読めれば、そのミスはもう起きない**。
:::

:::point 本番直前チェック10（読むだけ）
1. 主語が he / she / it で現在の話 → 動詞に **s**。
2. yesterday / last / ago → **過去形**。since / for → **現在完了**。now / Look! → **進行形**。
3. 前置詞（in, at, for, of, about, without）のあと → **-ing**。look forward to も **-ing**。
4. want / hope / decide / would like → **to ＋原形**。enjoy / finish / stop → **-ing**。
5. 「〜している人」→ **-ing** を名詞の後ろに。「〜された物」→ **過去分詞** を名詞の後ろに。
6. 受け身は **be ＋過去分詞**。「〜によって」は by。
7. It is … **for** 人 to 〜。want / tell / ask 人 **to** 〜。let / make / help 人 **原形**。
8. 比較は **than**、最上級は **the ＋ -est / most**、同じくらいは **as … as**。
9. if / when の中は**未来でも現在形**。
10. 英作文は **意見・理由・例の3文**。書いたら s・ed・大文字・ピリオドをチェック。
:::

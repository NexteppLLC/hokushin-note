# 4　リスニング（戦略＋原稿つき演習8セット）

## L0　リスニング戦略（15分で読む）

:::box 北辰のリスニング（28点）の形
| 問題 | 形式 | 配点 | 放送 |
|:--:|:--|--:|:--|
| No.1〜3 | 短い対話＋質問 → 絵・表から選ぶ | 各2点＝6点 | 2回 |
| No.4〜5 | 短い対話＋質問 → 英語の選択肢ア〜エ | 各2点＝4点 | 2回 |
| No.6 | 長めの対話 → (1)(2)(3) の質問に合う答えをア〜エから | 各3点＝9点 | 2回 |
| No.7 | 英文（スピーチ・案内など）→ メモの空所に**英語1語** | 各3点＝9点 | 2回 |
:::

:::point 得点を安定させる7つの技
1. **先読み**：放送が始まる前（説明が読まれている間）に、No.1〜3の絵と、No.6・No.7の選択肢・メモを見る。「時刻？場所？人？物？」と**何を聞き取るかを決めてから**聞く。
2. **1回目は答えを決める、2回目は確認**。1回目で聞き取れなくても、2回目があるとわかっていれば落ち着ける。
3. **数・曜日・時刻・値段はメモ**：数字は聞いた瞬間に書く。thirteen（13）と thirty（30）、fifteen と fifty の聞き分けはアクセント（-teen は後ろが強い）。
4. **対話の「最後の発言」に答えがあることが多い**。ただし途中の「変更」（At first … but …／Actually …／Sorry, I can't … so …）に注意。
5. **No.6・No.7は選択肢の語がそのまま放送に出るとは限らない**。言いかえ（buy ＝ get、begin ＝ start、by bike ＝ ride a bike）を意識。
6. **No.7の単語記述**は、**メモの前後の語から品詞と形を予想**（on ( ) → 曜日、at ( ) → 時刻、( ) years old → 数、bring ( ) → 名詞）。**複数形の s・過去形の ed・大文字（曜日・月）**を落とさない。
7. わからない問題は**必ずどれかにマーク**して次へ。放送はどんどん進む。引きずらない。
:::

:::box 毎日10分の「音読・シャドーイング」（LS）
1. 前回のリスニング原稿（No.6かNo.7）を、意味を確認しながら**音読3回**。
2. 家族に読んでもらう（または読み上げアプリで流す）音声のすぐ後を追いかけて言う（**シャドーイング**）2回。
3. 最後に原稿を見ずに、聞くだけで内容が追えるか確認。
- リスニングの点が伸びる一番の近道は「自分で言える英文を増やす」ことです。
:::

:::note 家の人へ（放送のしかた）
- 原稿は**ふつうの速さで、はっきり**と読んでください。各問題の英文は**2回**、間に3秒ほどあけます。問題と問題の間は10秒あけます。
- 読み上げアプリ（スマホの「読み上げ」機能や翻訳アプリの音声）を使う場合、原稿の英文部分をコピーして再生してください。
- 「Question:」の部分も読みます。No.7は英文のあとに「Question: 空所に入る語を書きなさい」は言わず、英文を2回読むだけでOKです。
:::

**No.6**

B: Hi, Daiki. Not yet. Why?
A: I'm going to the city museum on Sunday afternoon. They have a special show about dinosaurs. Would you like to come with me?
B: Sounds interesting! But I have piano practice on Sunday afternoon. How about Sunday morning?

B: Great. I'll bring it. See you on Sunday!

**No.7**

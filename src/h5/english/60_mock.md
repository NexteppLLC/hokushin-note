# 8　模擬テスト（本番形式・50分×2回）

:::box 模擬テストのやり方
- **50分を計る**（リスニング約10分を含む）。リスニングは家の人に原稿を読んでもらうか、読み上げアプリで再生。
- 解く順番は本番と同じ：大問1（放送）→ 大問2 → 大問5の英作文 → 大問3 → 大問4。
- 終わったら採点し、大問ごとの得点を総合計画の記録表に書く。**直し**は翌日（M1R・M2R）。
:::

## G1　文の基本（be動詞・一般動詞・三単現・命令文・There is）

:::box 要点
**① be動詞（am / is / are、過去は was / were）**：「〜です／〜にいる」。主語とセットで決まる。
- I **am** / You **are** / He, She, It **is** / We, They **are**。過去：I, He, She, It → **was**、You, We, They → **were**。
- 否定は be動詞のあとに not（isn't / aren't / wasn't / weren't）。疑問は be動詞を前に出す。

**② 一般動詞**：主語が **3人称単数（he, she, it, 人の名前、this…）で現在形**なら動詞に **-s / -es**（三単現）。
- play → plays、watch → watch**es**、study → stud**ies**、have → **has**、go → go**es**。
- 否定・疑問は **do / does / did** を使い、動詞は**原形**に戻す：He does**n't** play. / Did you go?

**③ 命令文**：動詞の原形で始める。「〜しないで」は **Don't** ＋原形。「〜しましょう」は **Let's** ＋原形。ていねいに言うなら **Please**。
- Be quiet. / Don't run here. / Let's go.

**④ There is / are**：「〜がある／いる」。あとの名詞が単数なら is、複数なら are。過去は was / were。
- There **is** a cat under the chair. / There **are** two cats. / **Is there** a park near here? — Yes, there is.
:::

:::point ここで差がつく
- 三単現の s は**北辰で最も多い減点**。主語が he / she / it / 人名 / 単数の物で、現在の話なら s。**主語を見る→時制を見る**の順で確認。
- does / did のあとの動詞は**必ず原形**：Did he **went**（×）→ Did he **go**（○）。
- 「〜がある」は There is。「私は〜を持っている」は I have。日本語の「ある」につられて has を使わない。
:::

:::q 演習（20問）
**A　（　）内から適切な語を選びなさい。**
1. My sister ( play / plays ) the piano every day.
2. Ken and I ( am / are / is ) good friends.
3. ( Do / Does ) your father like cooking?
4. She ( don't / doesn't ) eat breakfast.
5. There ( is / are ) some books on the desk.
6. ( Is / Are ) there a hospital near the station?
7. We ( was / were ) very tired last night.

**B　（　）内の語を適切な形に直しなさい。直す必要がなければそのまま書きなさい。**

**C　日本語に合うように（　）内の語を並べかえなさい。**

15. 静かにしなさい。 ( quiet / be ), please.
16. 彼はテニスをしません。 He ( play / doesn't / tennis ).

**D　英語にしなさい。**
18. 私の父は毎朝コーヒーを飲みます。（drink, coffee, every morning）

20. ここで走ってはいけません。（run, here）
:::

:::a 解答・解説
1. plays　2. are（主語は Ken and I ＝ we）　3. Does　4. doesn't　5. are（books は複数）　6. Is（a hospital は単数）　7. were　8. Don't

:::

## G2　過去形・進行形・未来（will / be going to）

:::box 要点
**① 過去形**：規則動詞は **-ed**（play → played、study → stud**ied**、stop → stop**ped**）。不規則動詞は暗記（go → went、see → saw、have → had、come → came、take → took、make → made、get → got、write → wrote、read → read〈発音レッド〉、buy → bought、think → thought、teach → taught、bring → brought、give → gave、eat → ate、run → ran、speak → spoke、leave → left、find → found、know → knew、say → said、tell → told、meet → met、send → sent、build → built、sit → sat、stand → stood、swim → swam、win → won、begin → began、break → broke、fall → fell、feel → felt、forget → forgot、hear → heard、hold → held、lose → lost、put → put、cut → cut）。
- 否定：**didn't** ＋原形。疑問：**Did** ＋主語＋原形？

**② 進行形**：be動詞 ＋ **-ing**。「〜している（現在進行形）」「〜していた（過去進行形）」。
- -ing のつくり方：run → run**ning**、swim → swim**ming**、make → mak**ing**、write → writ**ing**、study → study**ing**（y はそのまま）。
- **when** とセットで過去進行形がよく出る：I **was reading** when he **called**.（電話をかけてきたとき読んでいた）

**③ 未来**：**will** ＋原形（その場で決めた・単純な未来・「〜でしょう」）／**be going to** ＋原形（前から決めていた予定・起こりそうなこと）。
- will not ＝ **won't**。Will you …? は「〜してくれませんか」の依頼にもなる。
- 未来を表す語：tomorrow, next week, next Sunday, in the future, someday。
- **時や条件を表す接続詞（when / if / before / after）の中は、未来のことでも現在形**：If it **rains** tomorrow, I will stay home.
:::

:::point ここで差がつく
- 「昨日〜していた」は過去進行形、「昨日〜した」は過去形。**動作の途中なら進行形**。
- 「〜するつもりです」→ be going to、「〜するでしょう」→ will。どちらでも通じるが、並べ替えでは与えられた語で判断。
- last …, … ago, yesterday, then があれば過去形。**現在完了とは一緒に使えない**（G10で確認）。
:::

:::q 演習（20問）
**A　（　）内の語を適切な形に直しなさい。**
1. I ( see ) a beautiful bird in the park yesterday.
2. She ( write ) a letter to her grandmother last night.
3. We ( go ) to the museum two days ago.
4. He ( study ) math for three hours last Sunday.
5. They ( swim ) in the river now.
6. My brother ( read ) a book when I came home.
7. Look! The dog ( run ) in the garden.
8. It ( be ) rainy tomorrow, so I will take an umbrella.

**B　（　）に入る適切な語を選びなさい。**
9. ( Did / Were / Was ) you watch the game last night?
10. What ( did / were / was ) you doing at seven yesterday?
11. I ( will / am ) going to visit my uncle next week.
12. If it ( is / will be ) sunny tomorrow, we will go hiking.
13. She ( didn't / wasn't ) come to school yesterday.

**C　日本語に合うように（　）内の語を並べかえなさい。**
14. 私が電話したとき、彼女は夕食を作っていました。 She ( dinner / was / cooking ) when I called her.
15. 今週末は何をするつもりですか。 ( are / what / going / you / to / do ) this weekend?
16. 明日は雪が降らないでしょう。 It ( snow / won't ) tomorrow.
17. 私は昨日その本を買いませんでした。 I ( the book / buy / didn't ) yesterday.

**D　英語にしなさい。**
18. 私は昨夜10時に寝ました。（go to bed, at ten）
19. 彼らは今、体育館でバスケットボールをしています。（in the gym）
20. 私は来年、京都を訪れるつもりです。（be going to, visit）
:::

:::a 解答・解説
1. saw　2. wrote　3. went　4. studied　5. are swimming（now → 現在進行形）　6. was reading（when I came ＝過去のある時点で進行中）　7. is running（Look! → 現在進行形）　8. will be（tomorrow → 未来）
9. Did（watch は一般動詞）　10. were（doing があるので過去進行形）　11. am　12. is（if の中は現在形）　13. didn't（come は一般動詞）
14. She was cooking dinner when I called her.　15. What are you going to do this weekend?　16. It won't snow tomorrow.　17. I didn't buy the book yesterday.
18. I went to bed at ten last night.　19. They are playing basketball in the gym now.　20. I am going to visit Kyoto next year.
:::

## G3　助動詞（can, may, must, should, have to …）

:::box 要点
助動詞は **主語に関係なく形が同じ**で、あとは**動詞の原形**。否定は助動詞のあとに not。疑問は助動詞を前に。

| 助動詞 | 意味 | 言いかえ・注意 |
|:--|:--|:--|
| can | 〜できる／〜してもよい（許可） | ＝ **be able to**。過去は could、未来は will be able to |
| may | 〜してもよい／〜かもしれない | May I …?（〜してもいいですか） |
| must | 〜しなければならない／〜にちがいない | ＝ **have to**（三単現は has to、過去は had to）。**must not**＝してはいけない（禁止）、**don't have to**＝しなくてよい |
| should | 〜すべきだ／〜したほうがよい | should not ＝ shouldn't |
| will | 〜でしょう／〜するつもり | Will you …?（〜してくれませんか） |
| would | Would you …?（〜していただけませんか） | **would like to** ＝ want to のていねい形 |
| shall | Shall I …?（〜しましょうか） / Shall we …?（〜しませんか） | Shall we …? ＝ Let's … |

**依頼・許可の表現の強さ**：Can you …? ＜ Will you …? ＜ Could you …? ＜ Would you …?（ていねい）
**答え方**：Can I …? → Sure. / Of course. / Sorry, you can't.　Shall I …? → Yes, please. / No, thank you.
:::

:::point ここで差がつく
- **must not（禁止）と don't have to（不要）の違い**は毎年どこかで出る。You must not swim here.（泳いではいけない）／You don't have to hurry.（急がなくてよい）
- 助動詞は2つ重ねられない：will can（×）→ will **be able to**（○）。
- have to の疑問文は **Do you have to …?**、否定は **don't have to**。
:::

:::q 演習（20問）
**A　（　）に入る適切な語（句）を選びなさい。**
1. You ( must / can ) be quiet in the library.（〜しなければならない）
2. I ( can't / mustn't ) swim well. I want to practice more.（できない）
3. ( May / Must ) I use your pen? — Sure.
4. You ( don't have to / must not ) touch this. It's dangerous.
5. It's Sunday. You ( don't have to / must not ) get up early.
6. He ( has to / have to ) finish the report by Friday.
7. ( Shall / Will ) we go shopping tomorrow? — Yes, let's.
8. ( Would / Shall ) you like some coffee? — Yes, please.

**B　ほぼ同じ意味になるように（　）に適切な語を入れなさい。**
9. I can play the guitar. ＝ I ( ) ( ) ( ) play the guitar.
10. You must clean your room. ＝ You ( ) ( ) clean your room.
11. Let's have lunch. ＝ ( ) ( ) have lunch?
12. I want to see the movie. ＝ I ( ) ( ) ( ) see the movie.
13. Don't speak Japanese here. ＝ You ( ) ( ) speak Japanese here.

**C　日本語に合うように（　）内の語を並べかえなさい。**
14. 窓を開けてくれませんか。 ( you / open / could / the window )?
15. 私たちは明日早く起きなければなりません。 We ( get up / to / have / early ) tomorrow.
16. 私はその日、学校に行く必要はありませんでした。 I ( go / have / to / didn't ) to school that day.
17. あなたは医者に行ったほうがいいです。 You ( a doctor / should / see ).

**D　英語にしなさい。**
18. あなたはここで写真を撮ってはいけません。（take pictures）
19. 手伝いましょうか。（Shall, help）
20. 彼女は来週、その仕事を終えることができるでしょう。（be able to, finish the work）
:::

:::a 解答・解説
1. must　2. can't　3. May　4. must not（禁止）　5. don't have to（不要）　6. has to（三単現）　7. Shall　8. Would
9. am able to　10. have to　11. Shall we　12. would like to　13. must not（mustn't も可）
14. Could you open the window?　15. We have to get up early tomorrow.　16. I didn't have to go to school that day.　17. You should see a doctor.
18. You must not take pictures here.（You mustn't … / Don't take pictures here. も可）　19. Shall I help you?　20. She will be able to finish the work next week.
:::

## G4　疑問詞と間接疑問文

:::box 要点
**① 疑問詞**：what（何）、who（だれ）、whose（だれの）、which（どちら・どれ）、when（いつ）、where（どこ）、why（なぜ）、how（どのように）。
- **How** の仲間：how many（いくつ）、how much（いくら・どのくらいの量）、how long（どのくらいの時間・長さ）、how often（どのくらいの頻度）、how far（どのくらいの距離）、how old（何歳）、how tall（どのくらいの高さ）。
- 疑問詞が主語のとき：**Who** made this cake?（語順はそのまま）→ 答え：My mother did.
- What time …?（何時に）、What kind of …?（どんな種類の）、Which … or …?（AとBのどちら）。

**② 間接疑問文**：疑問文が文の中に入ると **「疑問詞＋主語＋動詞」の語順**になる（疑問文の語順ではなくなる）。
- Where does he live? → I don't know **where he lives**.（does が消えて lives に）
- What is this? → Do you know **what this is**?
- よく使う前半：I don't know / Do you know / Please tell me / I wonder / I want to know。
- **whether / if（〜かどうか）**：I don't know **if** she will come.
:::

:::point ここで差がつく
- 間接疑問の**時制**：前半が過去なら中も過去に。I didn't know where he **was**.
- 「疑問詞＋to＋原形」（what to do／how to use／where to go）と混同しない。**主語があるなら間接疑問、主語がないなら to 不定詞**。
- 「あなたは〜だと思いますか」は **What do you think …?**（Do you think what …? は×）。
:::

:::q 演習（20問）
**A　（　）に適切な疑問詞（句）を入れなさい。**
1. ( ) is that girl? — She is my cousin.
2. ( ) do you go to school? — By bike.
3. ( ) is your birthday? — It's May 5.
4. ( ) ( ) does it take to get to the station? — About ten minutes.
5. ( ) ( ) brothers do you have? — I have two.
6. ( ) bag is this? — It's Mika's.
7. ( ) do you like better, summer or winter?
8. ( ) were you late? — Because I missed the bus.

**B　日本語に合うように（　）内の語を並べかえなさい。**
9. 彼がどこの出身か知っていますか。 Do you know ( from / he / is / where )?
10. 私は彼女が何がほしいのかわかりません。 I don't know ( she / what / wants ).
11. この本がだれのものか教えてください。 Please tell me ( this book / is / whose ).
12. 彼がいつ来るのか知りたいです。 I want to know ( will / when / come / he ).
13. なぜ彼女が泣いていたのかわかりません。 I don't know ( was / she / why / crying ).
14. 彼が来るかどうかわかりません。 I'm not sure ( come / if / will / he ).

**C　2つの文を1つの文にしなさい。**
15. Do you know? ＋ What time does the store open?
16. I don't know. ＋ Where did he buy the watch?
17. Tell me. ＋ Who is that man?

**D　英語にしなさい。**
18. あなたは何時に起きますか。
19. 私はあの建物が何か知りません。（that building）
20. 駅までどのくらいの距離ですか。（far, to the station）
:::

:::a 解答・解説
1. Who　2. How　3. When　4. How long　5. How many　6. Whose　7. Which　8. Why
9. Do you know where he is from?　10. I don't know what she wants.　11. Please tell me whose this book is.　12. I want to know when he will come.　13. I don't know why she was crying.　14. I'm not sure if he will come.
15. Do you know what time the store opens?（does が消えて opens）　16. I don't know where he bought the watch.（did が消えて過去形に）　17. Tell me who that man is.
18. What time do you get up?　19. I don't know what that building is.　20. How far is it to the station?
:::

## G5　不定詞（3用法）と動名詞

:::box 要点
**不定詞 ＝ to ＋動詞の原形**。3つの使い方。

| 用法 | 意味 | 例 |
|:--|:--|:--|
| 名詞的用法 | 〜すること | I like **to read** books. / **To swim** is fun. / My dream is **to be** a teacher. |
| 副詞的用法 | 〜するために（目的）／〜して（感情の原因） | I went to the library **to study**. / I'm happy **to see** you. |
| 形容詞的用法 | 〜するための・〜すべき（名詞のすぐ後ろ） | I have a lot of homework **to do**. / something **to drink** |

**動名詞 ＝ 動詞の -ing 形**「〜すること」。主語・目的語・前置詞のあとで使う。
- **動名詞だけ**をとる動詞：enjoy, finish, stop, practice, keep, mind, give up（enjoy **playing**）
- **不定詞だけ**をとる動詞：want, hope, decide, plan, wish, would like, need（want **to go**）
- **どちらも可**：like, love, start, begin（like **to swim** ＝ like **swimming**）
- **前置詞のあとは必ず動名詞**：good at **swimming**、interested in **reading**、thank you for **coming**、before **eating**、without **saying**。
- **be動詞＋-ing は進行形**と区別：He is running.（走っている＝進行形）／His hobby is running.（趣味は走ること＝動名詞）
:::

:::point ここで差がつく
- stop **to** 〜（〜するために立ち止まる）と stop 〜**ing**（〜するのをやめる）は意味が違う。
- 「〜するための時間」time **to** …、「〜する方法」way **to** …、「〜すべきこと」things **to do** は形容詞的用法。something / anything / nothing ＋ to ＋原形 の語順（something **hot to drink**：形容詞は間）。
- 副詞的用法「〜して（うれしい・悲しい・驚いた）」：glad / happy / sad / surprised ＋ to ＋原形。
:::

:::q 演習（20問）
**A　（　）内の語を適切な形（to＋原形 または -ing）に直しなさい。**
1. I want ( visit ) Australia someday.

**B　下線部の不定詞の用法を、ア 名詞的用法　イ 副詞的用法　ウ 形容詞的用法 から選びなさい。**

10. She went to the store __to buy__ some milk.
11. __To learn__ a foreign language is not easy.
12. I was surprised __to hear__ the news.
13. Do you want something __to eat__?

**C　日本語に合うように（　）内の語を並べかえなさい。**
14. 私の夢は宇宙飛行士になることです。 My dream ( be / is / to / an astronaut ).
15. 私たちは新しい友達を作るために、そのクラブに入りました。 We ( the club / joined / make / to ) new friends.
16. 何か飲むものをください。 Please ( something / me / to / give / drink ).
17. 彼女は英語を話すことが上手です。 She ( speaking / good / is / at ) English.

**D　英語にしなさい。**
18. 私は本を読むことが好きです。（動名詞で）
19. 彼は昼食を食べるために家に帰りました。（go home, eat lunch）
20. 私には今日、やるべき宿題がたくさんあります。（a lot of homework）
:::

:::a 解答・解説
1. to visit　2. listening　3. cleaning　4. to study　5. inviting（前置詞 for のあと）　6. playing　7. raining（雨がやんだ）　8. to see

18. I like reading books.　19. He went home to eat lunch.　20. I have a lot of homework to do today.
:::

## G6　不定詞の応用（It is … for A to／want A to／how to／too … to／使役 let・help・make）

:::box 要点
| 形 | 意味 | 例 |
|:--|:--|:--|
| **It is … (for A) to ＋原形** | （Aが）〜することは…だ | It is important **for us to** study English. |
| **want A to ＋原形** | Aに〜してほしい | I want **you to** help me. |
| **tell / ask A to ＋原形** | Aに〜するように言う／頼む | My mother told **me to** clean my room. / I asked **him to** open the door. |
| **疑問詞 ＋ to ＋原形** | how to（〜のしかた）、what to（何を〜すべきか）、where to（どこで〜すべきか）、when to（いつ〜すべきか） | I know **how to** use this. / I didn't know **what to** say. |
| **too … to ＋原形** | …すぎて〜できない ＝ so … that ＋主語＋ can't | He is **too** tired **to** walk. ＝ He is **so** tired **that** he **can't** walk. |
| **… enough to ＋原形** | 〜するのに十分…だ | She is old **enough to** drive.（enough は形容詞のあと） |
| **let A ＋原形** | Aに〜させてやる（許可） | My father **let me use** his car. |
| **help A (to) ＋原形** | Aが〜するのを手伝う | I **helped her carry** the boxes. |
| **make A ＋原形** | Aに（無理に）〜させる | The teacher **made us clean** the room. |
:::

:::point ここで差がつく
- **It is … for A to** の「A」は目的格（for **me**, for **him**）。「〜にとって」。ただし kind / nice などの性格をあらわす形容詞は **of**：It is kind **of** you to help me.
- want to（自分がしたい）と want A to（Aにしてほしい）を区別：I want **to** go.／I want **you to** go.
- let / make / help のあとは **to をつけない原形**。北辰9月範囲で追加された項目なので、並べ替えで狙われる。
- too … to の書きかえ「so … that … can't」は主語を補う：The box is too heavy for me to carry. ＝ The box is so heavy that **I** can't carry **it**.
:::

## G7　比較（比較級・最上級・as … as）

:::box 要点
**① 比較級「〜より…」＝ 比較級 ＋ than**／**最上級「いちばん…」＝ the ＋最上級 ＋ in（場所・範囲）／ of（複数の仲間）**

| 種類 | 原級 → 比較級 → 最上級 |
|:--|:--|
| 短い語：-er / -est | tall → taller → tallest、long、old、young、fast、high、small、large → larg**er**（e で終わる）、big → big**ger**（子音を重ねる）、hot → hot**ter**、busy → bus**ier** → bus**iest**（y → i）、easy、early、happy、pretty |
| 長い語：more / most | beautiful, difficult, important, popular, famous, interesting, useful, expensive, exciting, careful |
| 不規則 | good / well → **better** → **best**、bad → **worse** → **worst**、many / much → **more** → **most**、little → less → least |

- in ＋ 場所・集団（in my class, in Japan, in the world）／of ＋ 複数（of the three, of all, of the five）
- **much** ＋比較級（ずっと〜）：much taller。
- **like A better than B**（BよりAが好き）／**like A the best**（Aがいちばん好き）
- **Which is 比較級, A or B?**（AとBどちらが〜？）

**② as … as「〜と同じくらい…」**（間は原級）：He is **as tall as** my father. 否定 **not as … as**（〜ほど…ない）：I am **not as tall as** he (is). ＝ He is taller than I.
**③ 比較級 and 比較級**（ますます〜）：It's getting colder and colder. **one of the ＋最上級＋複数名詞**（最も〜なうちの1つ）：one of the most famous **singers**。
:::

:::point ここで差がつく
- 最上級の **the** 忘れ、in と of の使い分け、複数名詞（one of the best **players**）は定番の減点ポイント。
- **書きかえ**：Tom is taller than Ken. ＝ Ken is **not as tall as** Tom. ＝ Ken is **shorter than** Tom.
- 「AとBでは、どちらが〜？」は **Which … 比較級, A or B?** 人なら Who。
:::

:::q 演習（20問）
**A　（　）内の語を適切な形に直しなさい。**

2. Mt. Fuji is the ( high ) mountain in Japan.

**C　ほぼ同じ意味になるように（　）に適切な語を入れなさい。**

15. This book is not as interesting as that one. ＝ That book is ( ) ( ) than this one.

**D　日本語に合うように（　）内の語を並べかえなさい。**

**E　英語にしなさい。**

:::

## G8　接続詞（that, when, if, because, though …）

:::box 要点
| 接続詞 | 意味 | 例 |
|:--|:--|:--|
| **and / but / or / so** | そして／しかし／または／だから | I was tired, **so** I went to bed early. |
| **that** | 〜ということ（省略できる） | I think **(that)** he is kind. / I know **(that)** you are busy. / I'm sure **(that)** … / I'm glad **(that)** … |
| **when** | 〜するとき | **When** I was a child, I lived in Osaka. ＝ I lived in Osaka **when** I was a child. |
| **if** | もし〜なら | **If** you are free, let's go out. |
| **because** | 〜なので（理由） | I stayed home **because** it was raining. → Why …? の答えにも使う |
| **though / although** | 〜だけれども | **Though** he was tired, he kept working. |
| **before / after** | 〜する前に／〜したあとで | Wash your hands **before** you eat. |
| **while** | 〜する間に | **While** I was sleeping, he called me. |
| **until (till)** | 〜まで（ずっと） | Wait here **until** I come back. |
| **as soon as** | 〜するとすぐに | I'll call you **as soon as** I get home. |
| **so … that** | とても…なので〜 | It was **so** cold **that** we couldn't swim. |

**大原則**：**when / if / before / after / until / as soon as の中では、未来のことでも現在形**。
- I'll go out **if** it **is** sunny tomorrow.（will is ではない）
- 接続詞の部分が前に来るときはコンマを打つ：When I got home, my mother was cooking.
:::

:::point ここで差がつく
- that のあとは「主語＋動詞」がそろった文。I think that **he is** kind.
- because は「文＋because＋文」。Because で始めて1文で終えるのは、Why …? の答えのときだけ。
- 「〜なので」を so と because で書き分ける：**理由＋so＋結果**／**結果＋because＋理由**。
- 「〜まで」until と「〜までに」by（前置詞）は別物：**by** Friday（金曜までに）。
:::

:::q 演習（20問）

**C　日本語に合うように（　）内の語を並べかえなさい。**

:::

:::

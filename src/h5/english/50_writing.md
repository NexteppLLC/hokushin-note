# 7　英作文（型・練習8回・チェック表）

## W0　英作文の型とルール（減点されない書き方）

:::box 北辰の英作文はどこに出るか
- **大問4の最後**：会話の流れに合わせて「あなたの考え」を**2文以上**（4〜6点）。
- **大問5の最後**：テーマについて「あなたの考え＋理由」を**3文以上**（5点前後）。
- 合計で約10点。**白紙は0点、書けば部分点**。「型」で書けば安定して7〜9点が取れます。
:::

:::point 3文の型（これだけ覚える）
| 文 | 役割 | 使う形 |
|:--:|:--|:--|
| 1文目 | **意見・答え** | I think (that) … ／ I want to … ／ My favorite … is … ／ I agree (with …). |
| 2文目 | **理由** | … because … ／ There are two reasons. First, … ／ It is … for me to … |
| 3文目 | **具体例・一言** | For example, … ／ I also … ／ So I … ／ I hope … |

**書き出しが指定されていたら、その文をそのまま使って1文目にする。**
:::

:::rule 減点されない7つのルール
1. **知っている単語・文法だけで書く**。難しい語を使おうとしてスペルミスするより、簡単な語で正しく書く。
2. **主語と動詞を必ず入れる**。日本語のように主語を省略しない（× Like soccer. → ○ I like soccer.）
3. **三単現の s／過去形の ed／複数形の s** を、書いたあとに指でなぞってチェック。
4. **文の最初は大文字、最後はピリオド**。I は常に大文字。
5. **冠詞（a / the）と前置詞（in / on / at / to / for）**は、自信のある形だけ使う。迷ったら覚えている熟語ごと使う（in the morning、at school、on Sunday、go to the park）。
6. **and / because / so** で文をつなぐと自然になる。ただし1文を長くしすぎない（1文＝10語前後）。
7. 書いたら**必ず読み直す**（30秒）。「s・ed・大文字・ピリオド」の4点チェック。
:::

:::box 使える表現40
**意見**：I think that 〜. ／ I don't think that 〜. ／ In my opinion, 〜. ／ I agree with 〜. ／ I'm for (against) 〜.
**理由**：〜 because … ／ There are two reasons. First, … Second, … ／ That's why 〜. ／ The reason is that 〜.
**例**：For example, 〜. ／ Such as 〜. ／ When I 〜, I … ／ Last year, I 〜.
**好み・希望**：My favorite 〜 is … ／ I like 〜 the best. ／ I want to 〜. ／ I would like to 〜. ／ I'm interested in 〜. ／ I'm good at 〜.
**経験**：I have 〜 (過去分詞) before. ／ I have never 〜. ／ When I was a child, I 〜.
**効果・結果**：〜 makes me happy. ／ It is good for our health. ／ We can learn 〜. ／ It helps us (to) 〜. ／ It is important for us to 〜.
**提案**：We should 〜. ／ Why don't we 〜? ／ Let's 〜. ／ It is a good idea to 〜.
**まとめ**：So I 〜. ／ I hope 〜. ／ I will try to 〜. ／ I'm sure (that) 〜. ／ That is my idea.
**つなぎ**：Also, 〜 ／ However, 〜 ／ On the other hand, 〜 ／ Then, 〜 ／ In addition, 〜
:::

:::ex 例題：Which do you like better, summer or winter?（3文以上）
**型どおりに書く**
1. I like summer better than winter.（意見）
2. I can swim in the sea with my friends in summer.（理由）
3. Also, we have a long vacation, so I can visit my grandparents.（具体例・追加）
→ 3文・約30語。難しい語はゼロ。これで満点です。
:::

## W1〜W8　英作文練習（各15分：書く10分＋見直し5分）

:::box やり方
- 各回、**3文以上**書く。書いたら W0 のルール7つでチェック → 下の解答例と比べる。
- 家族や先生に見てもらえるなら、**s・ed・大文字・ピリオド**の4点だけ見てもらう。
- 解答例と同じ内容である必要はありません。**自分の言葉で、簡単に、正しく**。
:::

:::q W1　あなたの好きな季節はいつですか。理由を含めて3文以上で書きなさい。
[[lines:4]]
:::
:::a 解答例
My favorite season is winter. I like snow, and I can enjoy skiing with my family. Also, I like eating hot food such as *nabe* on cold days.
:::

:::q W2　あなたの将来の夢は何ですか。理由を含めて3文以上で書きなさい。
[[lines:4]]
:::
:::a 解答例
I want to be a nurse in the future. When I was sick, a kind nurse helped me a lot. I want to help sick people like her, so I will study hard.
:::

:::q W3　外国から来た友達に、日本のどんな場所をすすめますか。理由を含めて3文以上で書きなさい。
[[lines:4]]
:::
:::a 解答例
I want to take my friend to Kawagoe. There are many old buildings there, and we can feel the history of Japan. Also, we can eat delicious sweet potato snacks on the street.
:::

:::q W4　「本を読むこと」と「テレビを見ること」では、どちらがよいと思いますか。理由を含めて3文以上で書きなさい。
[[lines:4]]
:::
:::a 解答例
I think reading books is better than watching TV. When I read, I can imagine the story in my head. Also, I can learn many new words from books.
:::

:::q W5　次の会話の（　）に合うように、2文以上の英語を書きなさい。
Emma: What do you usually do on weekends?
You: ( )
[[lines:3]]
:::
:::a 解答例
I usually play basketball with my friends on Saturday. On Sunday, I stay home and read books or help my mother.
:::

:::q W6　あなたは、環境を守るためにどんなことをしていますか、またはしたいですか。理由を含めて3文以上で書きなさい。
[[lines:4]]
:::
:::a 解答例
I carry my own water bottle every day. If I do so, I don't have to buy plastic bottles. I want to reduce plastic because it is bad for the sea and the animals.
:::

:::q W7　あなたが中学校生活で一番の思い出だと思うことは何ですか。3文以上で書きなさい。
[[lines:4]]
:::
:::a 解答例
My best memory is the chorus contest in my second year. Our class practiced every day after school for a month. We won first prize, and everyone cried with joy.
:::

:::q W8　次の会話の（　）に合うように、2文以上の英語を書きなさい。
Mr. Brown: Why do you study English, Ken?
Ken: ( )
[[lines:3]]
:::
:::a 解答例
I study English because I want to travel around the world. If I can speak English, I can make friends with people from many countries.
:::

## WR　英作文の見直し（自分の答案のミス分類・20分）

:::check ミス分類表（W1〜W8と模擬の英作文を見直して、当てはまるものに数を書く）
| ミスの種類 | 回数 | 直し方 |
|:--|:--:|:--|
| 三単現の s 忘れ | | 主語が he / she / it のとき、動詞に丸をつけてから s |
| 時制（過去の話を現在形で） | | 「昨日・去年・was」があれば動詞は過去形 |
| 複数形の s 忘れ | | many / two / some のあとは s |
| 冠詞（a / the）の抜け | | 数えられる名詞の単数には a か the |
| 前置詞のまちがい | | 熟語ごと覚える（on Sunday, in the morning） |
| 語順（日本語の順で書いた） | | 主語→動詞→目的語→場所→時 |
| スペルミス | | 単語ノートへ。書いて3回 |
| 文の数が足りない | | 型（意見・理由・例）で必ず3文 |
| 大文字・ピリオド | | 見直しの4点チェック |

**いちばん多いミスを1つ選び、次の英作文ではそれだけを意識して書く**。1つずつ消していけば、10点満点に近づきます。
:::

# 3　日本地理（要点・一問一答・演習）

## G5　日本地理1：日本の姿（位置・領域・地形・気候）

:::box 要点
**① 位置と領域**：日本はユーラシア大陸の東、**北緯 20〜46 度、東経 122〜154 度**。国土面積約 **38 万 km²**、約 1 万 4000 の島（本州・北海道・九州・四国）。
- **領域**＝**領土**＋**領海**（沿岸から **12 海里**）＋**領空**。**排他的経済水域**（**EEZ**、沿岸から **200 海里**、水産資源・鉱産資源を利用する権利）。日本の EEZ は国土の 10 倍以上。
- 端の島：北端**択捉島**、南端**沖ノ鳥島**（EEZ を守るため護岸工事）、東端**南鳥島**、西端**与那国島**。
- 領土問題：**北方領土**（択捉島・国後島・色丹島・歯舞群島、ロシアが占拠）、**竹島**（島根県、韓国が占拠）。**尖閣諸島**（沖縄県）は日本固有の領土で領土問題は存在しない（中国が主張）。
- **都道府県**：1 都 1 道 2 府 43 県 ＝ 47。**7 地方区分**：北海道・東北・関東・中部・近畿・中国四国・九州。県庁所在地が県名とちがう県（宮城→仙台、栃木→宇都宮、群馬→前橋、埼玉→さいたま、神奈川→横浜、石川→金沢、山梨→甲府、愛知→名古屋、三重→津、滋賀→大津、兵庫→神戸、島根→松江、香川→高松、愛媛→松山、沖縄→那覇 など）。

**② 地形**：**環太平洋造山帯**に位置し、火山・地震が多い。国土の約 **4 分の 3** が山地。
- **日本アルプス**（飛驒・木曽・赤石山脈）、**フォッサマグナ**（東西の境）。
- 川は**短く急流**。**扇状地**（川が山地から平地に出るところ、水はけがよい → **果樹園**）、**三角州**（河口、水田・都市）。**リアス海岸**（三陸・志摩半島・若狭湾：出入りが複雑、養殖、津波の被害大）。**大陸棚**（浅い海底、好漁場）。
- 海流：**黒潮**（日本海流、暖流）・**親潮**（千島海流、寒流）→ ぶつかる**潮目**（三陸沖、好漁場）。対馬海流（暖流）、リマン海流（寒流）。

**③ 気候**：大部分が温帯（北海道は冷帯、南西諸島は亜熱帯）。**季節風**：夏は南東（太平洋側に雨）、冬は北西（**日本海側に雪**）。**梅雨**・**台風**。

| 気候区分 | 特徴 |
|:--|:--|
| 北海道 | 冷帯、冬は長く寒い、梅雨がない |
| **日本海側** | **冬に雪が多い**（北西季節風） |
| **太平洋側** | **夏に雨が多い**、冬は乾燥して晴れ |
| 内陸（中央高地） | 降水量が少ない、**気温差が大きい** |
| **瀬戸内** | 山地にはさまれ**一年中降水量が少ない**（ため池） |
| 南西諸島 | 一年中温暖、台風 |

**④ 自然災害と防災**：地震（**東日本大震災** 2011、阪神・淡路大震災 1995）、津波、火山、台風・豪雨・土砂災害、冷害（東北のやませ）、雪害。**ハザードマップ**、**公助・自助・共助**。
:::

## G6　日本地理2：人口・資源・産業・交通

:::box 要点
**① 人口**：約 **1 億 2400 万人**（減少中）。**三大都市圏**（東京・大阪・名古屋）に人口集中 → **過密**（交通渋滞、住宅不足、ごみ）。地方は**過疎**（人口減少、高齢化、公共交通の廃止）。**人口ピラミッド**：富士山型（多産多死）→ つりがね型 → **つぼ型**（少子高齢化、現在の日本）。政令指定都市（20 市）。

**② 資源・エネルギー**：日本は資源に乏しく、**石油**（サウジアラビア・アラブ首長国連邦などから）、**石炭・鉄鉱石**（オーストラリア）、**天然ガス**（オーストラリア・マレーシア）を輸入。
- 発電：**火力**が中心（約 7 割、二酸化炭素を出す）、**水力**、**原子力**（2011 年の福島第一原発事故後に減少）、**再生可能エネルギー**（太陽光・風力・地熱・バイオマス）の拡大が課題。

**③ 農業・水産業**
- **稲作**：東北・北陸（新潟県・北海道・秋田県が上位）。**減反政策**（2018 年廃止）。**促成栽培**（高知・宮崎：温暖な気候とビニールハウスで早く出荷）、**抑制栽培**（長野・群馬の高原野菜：夏でも涼しい気候で遅く出荷）、**近郊農業**（大都市周辺で新鮮な野菜）。果樹：みかん（和歌山・愛媛・静岡）、りんご（青森・長野）、ぶどう・もも（山梨）。畜産：北海道・鹿児島・宮崎。
- 課題：**食料自給率**が低い（約 38 %）、農家の高齢化と後継者不足、**6 次産業化**（生産＋加工＋販売）。
- 水産業：**沖合漁業**が中心、**遠洋漁業**は 200 海里水域で減少、**養殖業**・**栽培漁業**（稚魚を放流）の重要性が高まる。

**④ 工業**：**太平洋ベルト**（関東〜九州北部の臨海部）に工業地帯・地域が集中（原料の輸入と製品の輸出に便利）。
- **中京工業地帯**（愛知県：**自動車**、出荷額 1 位）、**京浜**（東京・神奈川：印刷・機械）、**阪神**（大阪・兵庫：金属・化学）、北九州（かつて鉄鋼、八幡製鉄所）、**瀬戸内工業地域**（石油化学コンビナート）、東海、京葉、北関東（内陸、高速道路沿い）。
- **加工貿易**（原料を輸入して製品を輸出）から、海外に工場を移す**産業の空洞化**へ。近年は機械類・自動車の輸出、機械類・石油・衣類の輸入。**中小企業**が多い。

**⑤ 交通・通信**：**高速道路・新幹線・航空**の整備で人・ものの移動が高速化。貨物輸送は**自動車**（トラック）が中心、遠距離は船（重い物）・航空機（軽くて高価な物：IC など）。**成田国際空港**は貿易額日本 1 位。**情報通信網**、ICT の発達。
:::

(5) 高速道路が整備され、トラックで原料や製品を運びやすくなったから（土地が安く工場を建てやすい、も可）。
(6) 各国が 200 海里の排他的経済水域を設定し、外国の海で自由に漁ができなくなったから。

## G7　日本地理3：地形図の読み取り

:::box 要点
**① 縮尺**：実際の距離を地図上に縮めた割合。**2 万 5 千分の 1**（地図上 1 cm ＝ 実際 **250 m**）、**5 万分の 1**（1 cm ＝ **500 m**）。
- **実際の距離 ＝ 地図上の長さ × 縮尺の分母**。例：2 万 5 千分の 1 の地図で 4 cm → $4 \times 25000 = 100000$ cm ＝ **1 km**。
- 分母が**小さい**ほど（2 万 5 千分の 1）くわしい地図（大縮尺）。

**② 方位**：ふつう地図の**上が北**。8 方位（北・北東・東・南東・南・南西・西・北西）。

**③ 等高線**：同じ高さの地点を結んだ線。**2 万 5 千分の 1 では 10 m ごと**（主曲線）、**5 万分の 1 では 20 m ごと**。計曲線（太い線）は 50 m／100 m ごと。
- 等高線の**間隔がせまい**ほど**傾斜が急**、広いほどゆるやか。等高線が高いほうから低いほうへ張り出しているところが**尾根**、低いほうから高いほうへ食いこんでいるところが**谷**。川は谷を流れる。

**④ 地図記号**

| 記号の意味 | 由来 | 記号の意味 | 由来 |
|:--|:--|:--|:--|
| **市役所** ◎、町村役場 ○（小さい丸） | | **警察署** ⊗、交番 × | 警棒を交差 |
| **消防署** Y | さすまた | **郵便局** 〒 | |
| **学校** 文（小中）、高校は文を○で囲む | 「文」の字 | **病院** ⊕ | |
| **神社** 鳥居、**寺院** 卍 | | **図書館** 本の形 | |
| **博物館・美術館** 建物の形 | | **老人ホーム** 家と杖 | 2006 年新設 |
| **田** ‖、**畑** ∨ | 稲の切りかぶ／種葉 | **果樹園** ○（りんごの形）、**茶畑** ∴（小さな丸3つ） | 果実／茶の実 |
| **広葉樹林** Q、**針葉樹林** Λ | 木の形 | **荒地** 山形 | |
| **発電所** 歯車 | | **灯台** 光の形 | |
| **温泉** ♨ | | **史跡・名勝・天然記念物** ∴（点3つ） | |
| **三角点** △、**水準点** ⊡ | 位置／高さの基準 | 風車 | 2006 年新設 |

**⑤ 読み取りのコツ**：①縮尺 → ②方位 → ③等高線（高さ・傾斜） → ④土地利用（記号）の順に確認。「A 地点から見て B 地点はどの方位か」は A を中心に考える。断面図は等高線の間隔で判断。
:::

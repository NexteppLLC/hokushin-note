# 0　この教材の使い方

:::goal 社会の方針
- **用語を思い出す→資料の根拠を見つける→知識と結び付けて答える**までを練習します。
- 10月11日は**地理・歴史の全範囲と、公民の東京書籍P36まで**。公民の中心はN1〜N3「現代社会の特色・文化・対立と合意、効率と公正」です。
- N4〜N6は歴史の復習・11月以降の公民の予習です。憲法の成立など歴史で学ぶ事項は引き続き復習します。
:::

## 0-1　社会の解き方と時間配分（40分）

| 手順 | 内容 | 時間の目安 |
|:--|:--|--:|
| 全体確認 | 解答方式と資料の種類を確認 | 1分 |
| 地理・歴史・公民・総合 | 用語・資料照合・計算・記述 | 36分 |
| 見直し | 未解答・年代・指定語句・マーク欄 | 3分 |

この教材の模擬の大問数・配点は学習用です。本番の配点と指示は問題用紙で確認し、初見の過去問で時間を調整します。

:::point 資料を読む手順
- 地図・グラフ・表は**タイトル・年・単位・凡例・地域**を確認します。「割合が下がる」と「人数が減る」は同じとは限りません。
- 史料の根拠語を探してから、制度・人物・時代を判断します。並べ替えは前後関係を確認します。
- **資料から直接分かる事実と、知識を使う説明を区別**します。資料だけでは分からないことを決めつけないようにします。
- 記述は設問に合わせて事実・理由・比較を答えます。必ず2文にする必要はありません。指定語句と因果関係を確認します。
- 北辰公式：[出題範囲](https://www.hokushin-t.jp/test/hani/ha_index.html)。[東京書籍の単元構成](https://ten.tokyo-shoseki.co.jp/text/chu/shakai/komin/download/documents/koumin_tangen.pdf)では第1章がP6〜36、第2章はP37からです。範囲照合：2026年9月。
:::

## 0-2　34日間の進め方（番号は教材の単元）

[[include:plan_table.inc.md]]

:::note 40分の使い方
- **知識確認10分→図・資料の大問15分→根拠を確認して直し10分→数日前の再テスト5分**を基本にします。
- VH1〜VH12で歴史資料、VG1〜VG12で地理・公民の図表を練習します。写真・地図・統計を見てから、自分で根拠を指してください。
- 翌日・数日後・1週間後に短く再テストし、正解を覚えているだけでないか確認します。
- 9月の答案を**知識・図表・条件・計算・記述・時間**に分けて、次に練習する単元を選びます。
:::

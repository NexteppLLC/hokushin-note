# 6A　社会の図資料演習―34日間の使い方

## D0　社会の診断と、地理・歴史・公民の配分

:::box Day1は40分で診断する
**診断20分＋必要知識10分＋直し10分。** 9月北辰の自分の答案と解答を使い、既習の誤答を「知識・図表・条件・計算・記述・時間」に分ける。未習は別に記録する。未採点ならまず採点し、資料が読めなかったのか、時代や用語を知らなかったのかを区別する。

答案がないときは、手元の未見の過去問から、学習済みの地理・歴史の資料付き大問を1〜2題選び、解答を見ずに20分以内で取り組む。残りはN1の冒頭の要点を10分で確認し、診断で見つけた既習の弱点を10分で直す。**Day1にVH・VGの解答を先読みしない。**

この計画は10月11日向けの東京書籍の公民範囲を前提に、**N1現代社会の特色、N2生活と文化、N3対立と合意・効率と公正**を優先する。公民の憲法分野の先取りに時間を取りすぎない。一方、歴史は全範囲なので、日本国憲法の成立や戦後の民主化など、歴史で学ぶ基本事項は復習する。
:::

:::box 通常日の40分と、参照する知識の範囲
| 順序 | 時間 | やること |
|:--|:--|:--|
| 図資料を解く | 15分 | 当日のVHまたはVGを、解答を見ずに解く。題名・年代・単位・出典・凡例を確認する |
| 必要な知識を確認 | 10分 | 日別表のR/G/Nの該当要点と確認2問だけを見る |
| その日の直し（VX） | 10分 | 資料のどの部分が正解の根拠か確認し、誤った選択肢も直す |
| 後日再テスト（VT） | 5分 | 解説を見てから24時間以上たった問題を1〜2問、解答を閉じて解く |

**必要知識10分は、単元全体を10分で習得するという意味ではない。** 当日の指定箇所の学習と、単元全体の学習完了を分けて記録する。用語や時代が未習だった場合は未習として残し、基礎を学んでから演習を再配置する。

「資料から直接わかること」と「学習した知識を使うこと」を区別する。面積・人数・金額の資料を取り違えず、割合だけで実数が増えたかを決めない。歴史の写真は形だけでなく、時代・地域・用途の資料と照合する。
:::

## VX　社会の直し―正解の根拠を資料に戻して確かめる

:::box 当日10分の直し
| 資料の種類 | 直しで確認すること |
|:--|:--|
| 写真・絵画 | 形・構図・道具など、目で確認した特徴。時代や作者はどの知識と結び付いたか |
| 文章史料 | 制度を特定する語、対象者、時期。「禁止」「認める」の向きを取り違えていないか |
| 年表 | 古い順・原因と結果・同時期。条約の調印と発効を区別したか |
| 地図 | 位置・方位・縮尺・凡例。統計表の記号と同じ地域を見ていたか |
| グラフ・表 | 軸・単位・分母・総数・実測か学習用モデルか |
| 記述・選択肢 | 根拠が資料にあるか、別の知識が必要か。「すべて」「必ず」と断定しすぎていないか |

記録例：「VG6(3)／割合を金額と思った／総額×割合で比べる」。正解した問題も、理由が説明できないときは要確認にする。指定語句が入っているだけでは記述を正解にせず、比較する対象・原因・結果が合っているか確かめる。

Day20とDay27は、紙で40分の時間制限練習＋35分の直しを行う。手元の未見の北辰過去問に置き換えてよい。マークと記述、資料から設問への往復、解答欄の確認まで練習する。**サイトの模擬の大問構成や配点が公式と同じだとは扱わない。** 実際の試験形式・配点は問題用紙と公式案内を優先する。
:::

## VT　社会の後日再テストと、直前の仕上げ

:::box 24時間以上たってから、資料を自分で読む
前に×・△だった問題、偶然当たった問題を1〜2問選び、解答や直しノートを閉じる。**解説を見た時刻から24時間以上**あけ、なぜその選択肢か、図のどこが根拠かまで説明する。対象がなければ5分は記録整理に使い、再テスト成功の記録は付けない。

同じ写真の名前だけを覚えていた場合は、別の写真・別の地図・別の数値でも考え方を使えるか確認する。用意できなければ根拠の説明を行うが、「未見の資料問題を解けた」とは区別する。未習部分を学び終えた直後の確認も、後日再テストではなく学習後の確認とする。

| 期間 | 社会の配分 |
|:--|:--|
| Day2〜26（20除外） | 通常日の最後に5分、1〜2問の後日再テスト |
| Day20・27 | 模擬40分＋直し35分。初見結果と直しを分ける |
| Day28〜33 | 未定着問の再テスト20分＋弱点知識10分＋直し10分 |
| Day34 | 年表・公民N1〜N3・直し記録の既習箇所を20分以内で確認。新規問題は解かない |

最後の週は、全範囲を最初から周回するより、読めなかった資料や抜けていた基礎を優先する。未見の過去問を時間内に解いた結果と、間隔をあけた再テストを合わせて判断し、教材の完了率だけで実力を決めない。
:::

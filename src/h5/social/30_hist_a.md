# 4　歴史（要点・一問一答・演習）

## R1　歴史1：古代①（縄文〜古墳〜飛鳥）

:::box 要点
**① 人類の出現と文明**：猿人 → 原人 → 新人（ホモ・サピエンス）。**旧石器時代**（打製石器、狩り・採集）→ **新石器時代**（磨製石器、農耕・牧畜）。
- 四大文明（大河のほとり）：**エジプト**（ナイル川、太陽暦、象形文字、ピラミッド）、**メソポタミア**（チグリス・ユーフラテス川、くさび形文字、太陰暦、ハンムラビ法典）、**インダス**（インダス川、モヘンジョ・ダロ）、**中国**（黄河・長江、**甲骨文字**、殷）。
- 中国：殷 → 周 → 春秋・戦国（孔子の**儒教**）→ **秦**（**始皇帝**、万里の長城）→ **漢**（シルクロード）。ギリシャの都市国家（ポリス、民主政）、ローマ帝国。宗教：仏教（シャカ）、キリスト教（イエス）、イスラム教（ムハンマド）。

**② 日本の原始**

| 時代 | 特徴 |
|:--|:--|
| 旧石器 | 岩宿遺跡（群馬県、相沢忠洋）、打製石器、大型動物の狩り |
| **縄文** | **縄文土器**（厚手・黒褐色）、**たて穴住居**、**貝塚**、**土偶**（魔よけ・豊作祈願）、三内丸山遺跡（青森県）、狩り・漁・採集 |
| **弥生** | **稲作**が大陸から伝わる、**弥生土器**（うす手・赤褐色）、**高床倉庫**、金属器（**青銅器**：祭りの道具、銅鐸・銅剣／**鉄器**：武器・工具）、登呂遺跡（静岡県）、吉野ヶ里遺跡（佐賀県）、むら → くに、貧富の差 |

- 中国の歴史書：『漢書』地理志（100 余りの国）、『後漢書』東夷伝（**57 年**、奴国の王が**金印**（「漢委奴国王」、福岡県志賀島））、『**魏志倭人伝**』（**239 年**、**邪馬台国**の女王**卑弥呼**が魏に使いを送り「親魏倭王」の称号と銅鏡 100 枚）。

**③ 古墳時代**（3 世紀後半〜）：**大和政権（ヤマト王権）**が近畿地方に成立、**大王**。**前方後円墳**（**大仙古墳**：大阪府堺市、最大）、**はにわ**。**渡来人**が漢字・儒教・仏教（**538 年**または 552 年、百済から）・須恵器・機織りを伝える。氏姓制度。朝鮮半島：高句麗・百済・新羅、伽耶（任那）。**倭の五王**が中国の南朝に使い。

**④ 飛鳥時代**：**聖徳太子**（厩戸皇子、推古天皇の摂政、**蘇我馬子**と協力）：**冠位十二階**（603、家がらでなく才能で登用）、**十七条の憲法**（604、役人の心得、「和をもって貴しとなす」）、**遣隋使**（607、**小野妹子**）、**法隆寺**（現存最古の木造建築、**飛鳥文化**：仏教文化）。
- **大化の改新**（**645**）：**中大兄皇子**（のち天智天皇）と**中臣鎌足**（のち藤原鎌足）が蘇我氏（蝦夷・入鹿）をたおす。**公地公民**をめざす。
- **白村江の戦い**（663、唐・新羅に敗れる）→ **壬申の乱**（672、大海人皇子が勝ち**天武天皇**に）→ **大宝律令**（**701**、唐にならった律令国家）。
:::

## R2　歴史2：古代②（奈良・平安）

:::box 要点
**① 奈良時代**（**710** 平城京（奈良）〜 794）：唐の長安にならった都。
- **律令制度**：中央に二官八省、地方に**国司**（中央から派遣）・郡司。人民は**戸籍**に登録、6 歳以上の男女に**口分田** → 死ぬと返す（**班田収授法**）。税：**租**（稲、収穫の約 3 %）・**調**（特産物、都へ運ぶ）・**庸**（布、労役のかわり）、**雑徭**（労役）、**兵役**（**防人**：九州の防備）。
- 農民は重い負担でにげ出す → **墾田永年私財法**（**743**、開墾した土地の永久私有を認める）→ **荘園**（貴族・寺社の私有地）が広がり公地公民がくずれる。
- 政治：**聖武天皇**は仏教の力で国を守ろうと**国分寺・国分尼寺**と**東大寺の大仏**を建立（**行基**が協力）。**鑑真**が唐から来日（唐招提寺）。**遣唐使**。
- **天平文化**：国際色豊かな仏教文化。**正倉院**（校倉造、宝物）、『**古事記**』『**日本書紀**』（歴史書）、『**風土記**』（地理）、『**万葉集**』（歌集、大伴家持、防人の歌、万葉がな）。和同開珎（708）。

**② 平安時代**（**794** 平安京（京都）〜 1185）：**桓武天皇**が遷都。**坂上田村麻呂**を**征夷大将軍**に任じ東北の**蝦夷**を平定。
- 新しい仏教：**最澄**（**天台宗**、比叡山延暦寺）、**空海**（**真言宗**、高野山金剛峯寺）。
- **摂関政治**：**藤原氏**が娘を天皇のきさきにし、天皇が幼いときは**摂政**、成人後は**関白**として政治を行う。**藤原道長**（「この世をば わが世とぞ思ふ…」）・頼通（**平等院鳳凰堂**）のころ全盛（11 世紀前半）。
- 遣唐使の停止（**894**、**菅原道真**の提案）→ **国風文化**：**かな文字**、『**源氏物語**』（**紫式部**）、『**枕草子**』（**清少納言**）、『古今和歌集』（紀貫之）、**寝殿造**、大和絵、**浄土信仰**（阿弥陀仏、末法思想 → 平等院鳳凰堂）。
- 武士の台頭：**平将門の乱**・藤原純友の乱（10 世紀）→ **院政**（**1086**、**白河上皇**が上皇として政治）→ **保元の乱・平治の乱**（1156・59）→ **平清盛**が**太政大臣**（1167）、**日宋貿易**（兵庫の港）、娘を天皇のきさきに → 源平の争乱 → **壇ノ浦の戦い**（1185）で平氏滅亡。
:::

(6) 兵庫県・日宋貿易

## R3　歴史3：中世（鎌倉・室町）

:::box 要点
**① 鎌倉幕府**：**源頼朝**が**守護**（国ごと、軍事・警察）・**地頭**（荘園・公領ごと、年貢の取り立て）を置き（1185）、**1192** 年に**征夷大将軍**。幕府は鎌倉。**将軍と御家人**は**御恩**（領地の保護・新しい領地）と**奉公**（戦いで働く）の関係＝**封建制度**。
- 頼朝の死後、**北条氏**が**執権**として実権（**執権政治**）。**承久の乱**（**1221**、**後鳥羽上皇**が挙兵 → 敗北、京都に**六波羅探題**）。**御成敗式目**（**1232**、**北条泰時**、武士の最初の法律）。
- **元寇**（**1274 文永の役、1281 弘安の役**、執権**北条時宗**、元の**フビライ・ハン**）→ 恩賞が少なく御家人が困窮 → **徳政令**（1297、借金帳消し）→ 幕府の信頼低下。
- 鎌倉文化：**東大寺南大門の金剛力士像**（運慶・快慶）、『**平家物語**』（琵琶法師）、『**新古今和歌集**』、『方丈記』『徒然草』。**新しい仏教**：**浄土宗**（法然、念仏）、**浄土真宗**（親鸞、悪人正機）、**時宗**（一遍、踊念仏）、**日蓮宗**（日蓮、題目）、**臨済宗**（栄西、禅）、**曹洞宗**（道元、座禅）。農業：**二毛作**、牛馬耕、**定期市**。

**② 建武の新政と室町幕府**：**後醍醐天皇**が**足利尊氏**・楠木正成らと鎌倉幕府をたおす（1333）→ **建武の新政**（公家中心 → 武士の不満）→ 尊氏が京都に北朝、後醍醐天皇は吉野に南朝（**南北朝時代**、約 60 年）。**足利尊氏**が征夷大将軍（**1338**）。
- 3 代**足利義満**：**南北朝の合一**（1392）、**日明貿易（勘合貿易）**（**勘合**で倭寇と区別、明の銅銭・生糸を輸入）、**金閣**、**北山文化**（能（**観阿弥・世阿弥**））。**守護大名**の成長、管領。
- 8 代**足利義政**：**応仁の乱**（**1467〜77**、跡継ぎ争い＋守護大名の対立、京都が焼け野原）→ **下剋上**、**戦国大名**（**分国法**）。**銀閣**、**書院造**（畳・ふすま・床の間）、**東山文化**（**雪舟**の水墨画、茶の湯、生け花、狂言も広まる）。
- 民衆：**惣**（村の自治）、**土一揆**（正長の土一揆 1428、徳政を要求）、**山城国一揆**、**加賀の一向一揆**。**座**（商工業者の同業組合）、**馬借**、**土倉・酒屋**（金融）。琉球王国（中継貿易）、アイヌ（コシャマイン）。
:::

## R4　歴史4：近世①（安土桃山・江戸前期）

:::box 要点
**① ヨーロッパの動き**：**ルネサンス**（14〜16 世紀、イタリア、レオナルド・ダ・ビンチ）、**宗教改革**（**1517**、**ルター**、プロテスタント）→ カトリック側の**イエズス会**（ザビエル）。**大航海時代**：**コロンブス**（1492、西インド諸島）、バスコ・ダ・ガマ（インド航路）、**マゼラン**の船隊（世界一周）。スペイン・ポルトガルの植民地。
- 日本へ：**鉄砲伝来**（**1543**、種子島、ポルトガル人）、**キリスト教伝来**（**1549**、**フランシスコ・ザビエル**、鹿児島）。**南蛮貿易**（生糸・鉄砲・火薬 ↔ 銀）。

**② 織田信長**：**桶狭間の戦い**（1560、今川義元）→ **室町幕府をほろぼす**（1573）→ **長篠の戦い**（**1575**、鉄砲で武田軍に勝つ）→ **安土城**、**楽市・楽座**（座を廃止、商業の自由）、関所の廃止、**比叡山延暦寺**焼き討ち・一向一揆と対立、キリスト教を保護 → **本能寺の変**（1582、明智光秀）。

**③ 豊臣秀吉**：全国統一（**1590**）、**大阪城**。**太閤検地**（ものさし・ますを統一、田畑の面積と収穫高（**石高**）を調べ、耕作者を検地帳に記録 → 荘園制の消滅）、**刀狩**（**1588**、農民から武器を取り上げる）→ **兵農分離**。**バテレン追放令**（1587、宣教師追放。貿易は認める）。**朝鮮出兵**（文禄の役 1592、慶長の役 1597 → 失敗、豊臣氏の衰退）。
- **桃山文化**：豪華・壮大。**姫路城**、**狩野永徳**（『唐獅子図屏風』）、**千利休**（わび茶）、出雲の阿国（かぶき踊り）、南蛮文化。

**④ 江戸幕府の成立**：**関ヶ原の戦い**（**1600**、徳川家康 vs 石田三成）→ 家康が征夷大将軍（**1603**）→ 大阪の陣（1615）で豊臣氏滅亡。
- 大名の統制：**親藩**（徳川一門）・**譜代**（古くからの家臣）・**外様**（関ヶ原以後、遠くに配置）。**武家諸法度**（1615〜、3 代**家光**が**参勤交代**を制度化 1635：大名は 1 年おきに江戸と領地を往復、妻子は江戸）。**幕藩体制**。
- 身分：武士・百姓（**五人組**、年貢は四公六民〜五公五民）・町人。**えた・ひにん**の差別。
- **鎖国**：キリスト教の禁止（1612〜）、**島原・天草一揆**（**1637**、天草四郎）→ **絵踏**、**宗門改**。ポルトガル船の来航禁止（1639）→ オランダ商館を**出島**へ（1641）。貿易相手：**オランダ**・**中国**（長崎）、**朝鮮**（対馬藩、**朝鮮通信使**）、**琉球**（薩摩藩）、**アイヌ**（松前藩）。

**⑤ 産業と文化**：新田開発、備中ぐわ・千歯こき、商品作物。**五街道**、東廻り・西廻り航路（河村瑞賢）、**大阪**は「**天下の台所**」（蔵屋敷）、両替商、株仲間。
- **元禄文化**（5 代**綱吉**のころ、**上方**の町人文化）：**井原西鶴**（浮世草子）、**近松門左衛門**（人形浄瑠璃）、**松尾芭蕉**（俳諧『おくのほそ道』）、**菱川師宣**（浮世絵）、尾形光琳。綱吉：生類憐みの令。新井白石の正徳の治。
:::

## R5　歴史5：近世②（江戸後期・幕末）

:::box 要点
**① 幕政の改革**

| 改革 | 人物 | 内容 |
|:--|:--|:--|
| **享保の改革**（1716〜） | 8 代**徳川吉宗** | **公事方御定書**（裁判の基準）、**目安箱**、**上げ米の制**、新田開発、さつまいも（青木昆陽）、洋書の輸入を一部許可 |
| 田沼の政治（1772〜） | **田沼意次**（老中） | **株仲間**を奨励して税をとる、長崎貿易の拡大、印旛沼の干拓 → わいろ政治、天明のききん |
| **寛政の改革**（1787〜） | **松平定信**（老中） | 農村の復興（囲米）、**朱子学**以外の学問を禁止（寛政異学の禁）、旗本・御家人の借金帳消し → きびしすぎて失敗 |
| **天保の改革**（1841〜） | **水野忠邦**（老中） | **株仲間の解散**、江戸に出た農民を村へ帰す、上知令 → 2 年で失敗 |

- 農村の変化：**百姓一揆**、**打ちこわし**（都市）、**問屋制家内工業** → **工場制手工業**（マニュファクチュア）。**大塩平八郎の乱**（1837、大阪、元役人）。
- **化政文化**（19 世紀初め、**江戸**の町人文化）：**葛飾北斎**（『富嶽三十六景』）、**歌川広重**（『東海道五十三次』）、**十返舎一九**、**滝沢馬琴**、川柳・狂歌。学問：**国学**（**本居宣長**『古事記伝』）、**蘭学**（**杉田玄白**・前野良沢『解体新書』、**伊能忠敬**の日本地図）、**寺子屋**（読み・書き・そろばん）、藩校、**シーボルト**。

**② 開国**：外国船の接近（ロシアのラクスマン 1792、**異国船打払令** 1825、モリソン号事件、**アヘン戦争** 1840 で清が敗北 → 打払令をゆるめる）。
- **ペリー**来航（**1853**、浦賀）→ **日米和親条約**（**1854**、**下田・函館**を開港）→ **日米修好通商条約**（**1858**、大老**井伊直弼**、5 港（函館・神奈川・長崎・新潟・兵庫）、**領事裁判権を認める**・**関税自主権がない** → **不平等条約**）→ 貿易開始（横浜、生糸の輸出、物価上昇）。
- **安政の大獄**（1858〜59、吉田松陰ら処刑）→ **桜田門外の変**（1860、井伊直弼暗殺）→ **尊王攘夷運動**（長州）→ 薩英戦争・下関での四国艦隊砲撃（攘夷は不可能と悟る）→ **薩長同盟**（**1866**、**坂本龍馬**の仲介、木戸孝允・西郷隆盛）→ **大政奉還**（**1867**、15 代**徳川慶喜**）→ **王政復古の大号令** → **戊辰戦争**（1868〜69、鳥羽・伏見の戦い〜五稜郭）。**ええじゃないか**、世直し一揆。
:::

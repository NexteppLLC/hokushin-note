# 2　文法10レッスン

:::box 文法レッスンの進め方（1レッスン20〜30分）
1. **要点**を読む。表は「見て理解」でよい（写さない）。
2. **演習**を解く。判断に迷ったら、要点の「見分け方」に戻る。
3. 解答・解説を読み、間違えた問題に☐チェック。**理由を1行**で直しノートへ。
- 北辰の文法問題は「識別」（同じ形で意味の違う語を見分ける）が中心。**言いかえテスト**（「〜こと」「〜ない→ぬ」など）を武器にします。
:::

## B1　文法1：文節・単語・文の成分

:::box 要点
**① 文節**：文を「意味がわかる範囲で、できるだけ短く区切ったひとまとまり」。**「ネ」「サ」を入れて区切る**。
- 例：私はネ／昨日ネ／図書館でネ／本をネ／借りた。→ 5文節
- **注意**：「〜て（で）いる」「〜てみる」「〜ておく」「〜てほしい」は**2文節**（補助の関係）：読んで／いる、食べて／みる。

**② 単語**：文節をさらに「意味のある最小の単位」に分けたもの。
- 例：私／は／昨日／図書館／で／本／を／借り／た → 9単語
- 「借りた」＝「借り（動詞）」＋「た（助動詞）」の2単語。

**③ 文の成分**（文節の働き）
| 成分 | 働き | 例（――部） |
|:--|:--|:--|
| 主語 | 「何が」「だれが」（〜は／〜が／〜も／〜こそ） | __鳥が__ 飛ぶ。 |
| 述語 | 「どうする」「どんなだ」「何だ」「ある・いる」（ふつう文末） | 鳥が __飛ぶ__。 |
| 修飾語 | 他の文節をくわしくする（連用修飾：動詞などを／連体修飾：名詞を） | __高く__ 飛ぶ（連用）／__白い__ 鳥（連体） |
| 接続語 | 前後をつなぐ（だから、しかし、〜ので、〜が） | __疲れたので__、休んだ。 |
| 独立語 | 他と直接つながらない（呼びかけ・感動・応答・提示） | __はい__、わかりました。 |

**④ 連文節**：2つ以上の文節がまとまって1つの成分になる → **主部・述部・修飾部・接続部・独立部**。
- __私の兄は__ 医者だ（主部）／ 兄は __医者に なった__（述部）

**⑤ 文節どうしの関係**
| 関係 | 例 |
|:--|:--|
| 主・述の関係 | 花が／咲く |
| 修飾・被修飾の関係 | きれいな／花 |
| 並立の関係（対等） | 赤や／白の／花（赤や＝白の） |
| 補助の関係（意味を補う） | 咲いて／いる、食べて／みる、書いて／おく |
| 接続の関係 | 咲いたが／散った |
| 独立の関係 | ああ、／きれいだ |

**⑥ 文の種類**：単文（主語・述語が1組）／重文（主・述が2組、対等に並ぶ：雨が降り、風が吹く）／複文（主・述が2組、一方が他方の一部：__私が買った__本は高い）
:::

:::point ここで差がつく
- **主語は「〜が」だけではない**：「〜は」「〜も」「〜こそ」「〜さえ」、そして「**〜の**」（私__の__書いた作文＝私__が__書いた作文）も主語になる。
- 修飾語がどの文節にかかるかは、**修飾語を直後の文節から順に当てて、意味が通るところ**を探す。「とても」は連用修飾（とても／速い）。
- 「〜て／いる」「〜で／ある」の後ろの語は**補助動詞**。文節は2つ。
:::

:::q 演習（15問）
**A　次の文を文節に区切り、その数を答えなさい。**
1. 弟は公園で友達とサッカーをしている。
2. 私は昨日、駅前の本屋で新しい辞書を買った。
3. もし明日雨が降ったら、試合は中止になるだろう。

**B　次の文の――線部の文の成分を、ア 主語　イ 述語　ウ 修飾語　エ 接続語　オ 独立語 から選びなさい。**
4. __おや__、もう帰るのですか。
5. __疲れたので__、早く寝た。
6. 兄は __とても__ 速く走る。
7. __私も__ その本を読んだ。
8. 明日は __晴れるだろう__。

**C　――線部の文節どうしの関係を、ア 主・述　イ 修飾・被修飾　ウ 並立　エ 補助 から選びなさい。**
9. 妹が __笑って／いる__。
10. __大きな／犬__ が走ってきた。
11. __山や／川__ が美しい。
12. __鳥が／鳴く__ 声が聞こえる。

**D　次の文の――線部の修飾語が修飾している文節を書きなさい。**
13. 私は __昨日__ 買った本を読んだ。
14. 彼は __静かに__ 部屋のドアを閉めた。

**E　次の文は、単文・重文・複文のどれですか。**
15. 私が作ったケーキを、友達がおいしそうに食べた。
:::

:::a 解答・解説
1. 弟は／公園で／友達と／サッカーを／して／いる → **6**（「して／いる」は2文節）
2. 私は／昨日／駅前の／本屋で／新しい／辞書を／買った → **7**
3. もし／明日／雨が／降ったら／試合は／中止に／なるだろう → **7**（「なるだろう」は1文節：「だろう」は助動詞なので切れない）
4. オ（感動）　5. エ（〜ので）　6. ウ（とても→速く）　7. ア（「〜も」も主語）　8. イ
9. エ（補助）　10. イ　11. ウ（山や＝川：対等）　12. ア（鳥が→鳴く）
13. 買った（「昨日買った」）　14. 閉めた（「静かに閉めた」）
15. 複文（「私が作った」が「ケーキ」を修飾する形で文の中に入っている）
:::

## B2　文法2：品詞の分類（10品詞）

:::box 要点
**単語は10種類（品詞）**。まず「自立語か付属語か」「活用があるか」で分ける。

| | 活用 | 品詞 | 働き・見分け方 | 例 |
|:--|:--:|:--|:--|:--|
| **自立語**（単独で文節になれる） | あり | **動詞** | 動作・存在。言い切りが**ウ段**で終わる | 走る、ある、いる |
| | あり | **形容詞** | 性質・状態。言い切りが「**〜い**」 | 高い、美しい、ない |
| | あり | **形容動詞** | 性質・状態。言い切りが「**〜だ／〜です**」 | 静かだ、きれいだ |
| | なし | **名詞** | ものの名前。主語になれる（〜が／〜は） | 山、私、三つ、こと |
| | なし | **副詞** | 主に**用言**（動詞・形容詞・形容動詞）を修飾 | とても、ゆっくり、決して |
| | なし | **連体詞** | **体言**（名詞）だけを修飾。活用しない | この、大きな、あらゆる、ある |
| | なし | **接続詞** | 文と文・語と語をつなぐ | しかし、だから、また |
| | なし | **感動詞** | 感動・呼びかけ・応答 | ああ、おい、はい |
| **付属語**（自立語のあとにつく） | あり | **助動詞** | 意味をそえる。活用する | れる、ない、た、ようだ |
| | なし | **助詞** | 関係を示す・意味をそえる。活用しない | が、を、の、ので、か |

**用言**＝動詞・形容詞・形容動詞（活用する自立語、述語になれる）。**体言**＝名詞。
:::

:::point ここで差がつく（紛らわしい品詞）
- **「大きな」「小さな」「おかしな」＝連体詞**（活用しない）。「大きい」「小さい」＝形容詞。
- **「ある日」の「ある」＝連体詞**、「本がある」の「ある」＝動詞。
- **「この・その・あの・どの」＝連体詞**、「これ・それ」＝名詞（代名詞）。
- 副詞は**用言を修飾**：「とても静かだ」「ゆっくり歩く」。「もっと大きな声」の「もっと」は連体詞「大きな」を修飾する副詞。
- **「きれいだ」は形容動詞**（「きれい」だけで言い切れない）。「きれいな花」の「きれいな」も形容動詞（連体形）。「〜な」の形で名詞につけられれば形容動詞、「大きな」のように「〜だ」にできなければ連体詞。
- **「ない」**：形容詞（「本がない」）／助動詞（「行かない」＝動詞につく）／補助形容詞（「うれしくない」＝「は」を入れられる：うれしくはない）。→ B5・B8
- **副詞の種類**：状態（ゆっくり・すぐに）、程度（とても・かなり・少し）、呼応（決して〜ない、たぶん〜だろう、まるで〜ようだ、もし〜なら、なぜ〜か、どうか〜ください、まさか〜まい）。
:::

:::q 演習（20問）
**A　――線部の品詞名を答えなさい。**
1. __この__ 本はおもしろい。
2. 彼は __とても__ 親切だ。
3. __ああ__、疲れた。
4. 雨が降った。__しかし__、試合は行われた。
5. __静かな__ 夜だった。
6. __大きな__ 犬が走ってきた。
7. 空が __青い__。
8. 私は本を __読む__。
9. __あらゆる__ 方法を試した。
10. 昨日は __かなり__ 寒かった。
11. 彼は __いわゆる__ 天才だ。
12. __ある__ 日、手紙が届いた。
13. 机の上に本が __ある__。
14. __たぶん__ 明日は晴れるだろう。
15. 話す __こと__ が大切だ。

**B　次の副詞と呼応する（対応する）言い方をあとから選びなさい。**
16. 決して（　）　17. まるで（　）　18. もし（　）　19. なぜ（　）　20. たとえ（　）
　ア 〜ても　イ 〜ない　ウ 〜ようだ　エ 〜のか　オ 〜なら
:::

:::a 解答・解説
1. 連体詞　2. 副詞（程度）　3. 感動詞　4. 接続詞　5. 形容動詞（言い切り「静かだ」）　6. 連体詞（「大きだ」とは言えない）　7. 形容詞　8. 動詞　9. 連体詞　10. 副詞　11. 連体詞　12. 連体詞　13. 動詞（存在）　14. 副詞（呼応：たぶん〜だろう）　15. 名詞（形式名詞）
16. イ　17. ウ　18. オ　19. エ　20. ア
:::

## B3　文法3：動詞の活用（種類と活用形）

:::box 要点
**① 活用の種類（5種類）**：「**ない**」をつけて、直前の音で見分ける。
| 種類 | 見分け方（「ない」をつける） | 例 |
|:--|:--|:--|
| **五段活用** | 直前が**ア段**（書か－ない） | 書く、話す、読む、走る、泳ぐ、待つ、買う、死ぬ、飛ぶ |
| **上一段活用** | 直前が**イ段**（起き－ない） | 起きる、見る、着る、借りる、信じる、落ちる、生きる |
| **下一段活用** | 直前が**エ段**（食べ－ない） | 食べる、教える、寝る、考える、出る、受ける、決める |
| **カ行変格活用** | 「来る」1語だけ | 来る（こ－ない、き－ます、く－る） |
| **サ行変格活用** | 「する」「〜する」だけ | する、勉強する、愛する |

**② 活用形（6つ）**：あとに続く語で見分ける。
| 活用形 | あとに続く語 | 例（書く） |
|:--|:--|:--|
| 未然形 | **ない・う・よう・れる・せる** | 書か（ない）、書こ（う） |
| 連用形 | **ます・た・て・、（読点）** | 書き（ます）、書い（た）※音便 |
| 終止形 | **。（言い切り）・と・が・から・けれど** | 書く（。） |
| 連体形 | **体言（名詞）・とき・こと・の・ので・のに** | 書く（とき） |
| 仮定形 | **ば** | 書け（ば） |
| 命令形 | **命令して言い切る** | 書け（！） |

**③ 音便**：五段活用の連用形に「た・て」がつくとき形が変わる。書い－た（イ音便）、走っ－た（促音便）、読ん－だ（撥音便）。
**④ 自動詞・他動詞**：「〜が開く（自）」「〜を開ける（他）」。可能動詞：「書ける」「読める」（五段動詞から作る下一段活用。「見れる」は誤用、正しくは「見られる」）。
:::

:::point ここで差がつく
- **終止形と連体形は同じ形**。見分けは**あとに続く語**：「。」「が」なら終止形、名詞・「の」「ので」「のに」なら連体形。「走る**とき**」は連体形。
- 「ない」をつけたとき「〜**ない**」の直前を見る。「見る」→「み－ない」（イ段）＝上一段。「来る」「する」は暗記。
- 「起きる」「借りる」「足りる」は上一段、「切る」「知る」「走る」「入る」「帰る」「減る」「蹴る」は**五段**（切ら－ない）。ここが定番のひっかけ。
:::

:::q 演習（20問）
**A　――線部の動詞の活用の種類を答えなさい。**
1. 早く __起きる__。　2. 手紙を __書く__。　3. 友達が __来る__。　4. 毎日 __勉強する__。　5. パンを __食べる__。
6. 部屋に __入る__。　7. 映画を __見る__。　8. 家に __帰る__。　9. 本を __借りる__。　10. 犬が __走る__。

**B　――線部の動詞の活用形を答えなさい。**
11. 手紙を __書か__ ない。　12. 本を __読み__ ます。　13. 朝早く __起きる__。　14. 駅に __着く__ とき。　15. 雨が __降れ__ ば。
16. 早く __来い__。　17. 音楽を __聞い__ た。　18. 家に __帰る__ ので。　19. 明日は __行こ__ う。　20. 花が __咲く__ が、実はならない。
:::

:::a 解答・解説
1. 上一段（起き－ない）　2. 五段（書か－ない）　3. カ行変格　4. サ行変格　5. 下一段（食べ－ない）　6. 五段（入ら－ない）　7. 上一段（み－ない）　8. 五段（帰ら－ない）　9. 上一段（借り－ない）　10. 五段（走ら－ない）
11. 未然形（ない）　12. 連用形（ます）　13. 終止形（。）　14. 連体形（とき）　15. 仮定形（ば）　16. 命令形　17. 連用形（た：イ音便）　18. 連体形（ので）　19. 未然形（う）　20. 終止形（が）
:::

## B4　文法4：形容詞・形容動詞・副詞・連体詞

:::box 要点
**① 形容詞**（言い切り「〜い」）の活用：かろ（う）／かっ（た）・く（なる・て）／い（。）／い（とき）／けれ（ば）／○（命令形なし）
- 例：高かろ－う、高かっ－た、高く－なる、高い、高い－とき、高けれ－ば
- 補助形容詞：「読みたく**ない**」「食べて**ほしい**」「先生で**ない**」→ 本来の意味がうすれ、前の文節を補う。

**② 形容動詞**（言い切り「〜だ」）の活用：だろ（う）／だっ（た）・で（ある）・に（なる）／だ（。）／な（とき）／なら（ば）／○
- 例：静かだろ－う、静かだっ－た、静かで－ある、静かに－なる、静かだ、静かな－とき、静かなら－ば
- **「〜な＋名詞」が作れれば形容動詞**：きれいな花、元気な子、便利な道具。

**③ 副詞**：活用なし。主に用言を修飾。「どのように・どのくらい」を表す。「ゆっくり」「とても」「決して」。
**④ 連体詞**：活用なし。体言だけを修飾。数は少ないので覚える：**この・その・あの・どの、ある、あらゆる、いわゆる、大きな・小さな・おかしな、たいした、とんだ、去る・来る（来る〇日）**。
:::

:::point 形容動詞の連体形「な」と、連体詞・助動詞「な」の識別
- **形容動詞の一部**：「静か**な**」→「静かだ」と言い切れる。
- **連体詞の一部**：「大き**な**」→「大きだ」とは言えない。
- **助動詞「だ」の連体形**：「学生**な**ので」→「学生だ」（名詞＋だ）。
- **助動詞「そうだ・ようだ」の一部**：「雨が降りそう**な**空」。
:::

:::q 演習（15問）
**A　――線部の活用形を答えなさい。**
1. 今日は __寒かっ__ た。　2. もっと __静かに__ しなさい。　3. __美しけれ__ ば買う。　4. __元気な__ 子どもたち。　5. 明日は __暑かろ__ う。　6. 空が __青く__ なる。

**B　――線部の「な」の説明として正しいものを、ア 形容動詞の一部　イ 連体詞の一部　ウ 助動詞「だ」の連体形　から選びなさい。**
7. __きれいな__ 花が咲いた。　8. __小さな__ 声で話す。　9. 彼は中学生 __な__ ので、まだ選挙に行けない。　10. __おかしな__ 話だ。　11. __親切な__ 人に出会った。

**C　――線部の品詞名を答えなさい。**
12. __いわゆる__ 名作だ。　13. __すぐに__ 出発しよう。　14. __たいした__ 問題ではない。　15. 昨日は __ずいぶん__ 歩いた。
:::

:::a 解答・解説
1. 連用形（た）　2. 連用形（する）　3. 仮定形（ば）　4. 連体形（名詞）　5. 未然形（う）　6. 連用形（なる）
7. ア（きれいだ）　8. イ（小さだ×）　9. ウ（中学生だ）　10. イ　11. ア（親切だ）
12. 連体詞　13. 副詞　14. 連体詞　15. 副詞
:::

## B5　文法5：助動詞①（れる・られる／せる・させる／ない／たい）

:::box 要点
**① れる・られる**（4つの意味）— 五段・サ変には「れる」、それ以外には「られる」
| 意味 | 見分け方 | 例 |
|:--|:--|:--|
| **受け身** | 「〜に…される」。他からされる | 先生に __ほめられる__ |
| **可能** | 「〜できる」に言いかえられる | この本は一日で __読める__／朝早く __起きられる__ |
| **自発** | 自然にそうなる（思う・感じる・案じる・偲ぶ など心の動詞） | 故郷が __思い出される__ |
| **尊敬** | 主語が目上の人。「お〜になる」に言いかえられる | 校長先生が __話される__ |

**② せる・させる（使役）**：「〜させる」。五段・サ変には「せる」、それ以外には「させる」：書か__せる__、食べ__させる__、来__させる__。
**③ ない（打ち消し）**：動詞の未然形につく。**「ぬ」に言いかえられれば助動詞**（行か__ない__＝行か__ぬ__）。形容詞「ない」は「ぬ」にできない（本が__ない__＝存在しない）。「うれしく__ない__」は補助形容詞（「は」を入れられる：うれしく**は**ない）。
**④ たい・たがる（希望）**：私は行き__たい__／弟は行き__たがる__（第三者の希望）。
**⑤ た（過去・完了・存続・確認）**：昨日行っ__た__（過去）／今終わっ__た__（完了）／壁にかかっ__た__絵（存続＝「〜ている」）／明日は休みだっ__た__ね（確認）。
:::

## B6　文法6：助動詞②（そうだ・ようだ・らしい・だ・う・よう・まい）

:::box 要点
| 助動詞 | 意味 | 接続・見分け方 |
|:--|:--|:--|
| **そうだ（様態）** | 〜しそうだ・〜な様子だ | 動詞の**連用形**・形容詞（動）の語幹につく：降り__そうだ__、おいし__そうだ__ |
| **そうだ（伝聞）** | 〜と聞いた・〜ということだ | **終止形**につく：降る__そうだ__、おいしい__そうだ__ |
| **ようだ（推定）** | どうやら〜らしい | どうやら〜ようだ（「どうやら」を補える） |
| **ようだ（比況＝たとえ）** | まるで〜のようだ | 「まるで」を補える：まるで雪の__ようだ__ |
| **ようだ（例示）** | 例えば〜のような | 例えば〜のような：君の__ような__人 |
| **らしい（推定）** | どうやら〜らしい（根拠のある推定） | 助動詞。「彼は来る__らしい__」 |
| **〜らしい（接尾語）** | 〜にふさわしい | 名詞＋らしい＝形容詞を作る接尾語：学生__らしい__態度、春__らしい__天気 |
| **だ・です（断定）** | 〜である | 名詞につく：彼は医者__だ__ |
| **う・よう（意志・推量・勧誘）** | 〜しよう／〜だろう／〜しましょう | 私が行こ__う__（意志）／明日は晴れよ__う__（推量）／一緒に行こ__う__（勧誘） |
| **まい（打ち消しの意志・推量）** | 〜しないつもりだ／〜ないだろう | 二度と行く__まい__（意志）／雨は降る__まい__（推量） |
:::

:::point 「そうだ」の識別が最頻出
- **様態**：直前が**連用形・語幹**（降り－そうだ、高－そうだ、元気－そうだ）。
- **伝聞**：直前が**終止形**（降る－そうだ、高い－そうだ、元気だ－そうだ）。
- 「ようだ」は「どうやら」「まるで」「例えば」のどれを補えるかで判断。
- 「らしい」は、**「〜にふさわしい」に言いかえられれば接尾語**、できなければ助動詞。
:::

:::q 演習（15問）
**A　――線部の「そうだ」を、ア 様態　イ 伝聞 に分けなさい。**
1. 明日は雨が降りそうだ。　2. 明日は雨が降るそうだ。　3. このケーキはおいしそうだ。　4. あの店はおいしいそうだ。　5. 彼は元気だそうだ。

**B　――線部の「ようだ」の意味を、ア 推定　イ 比況　ウ 例示 から選びなさい。**
6. 彼はもう帰ったようだ。　7. 雪のように白い肌。　8. 東京のような大都市。　9. 外は寒いようだ。

**C　――線部の「らしい」を、ア 助動詞　イ 接尾語 に分けなさい。**
10. 彼は明日来るらしい。　11. 男らしい態度。　12. 今日は春らしい暖かさだ。

**D　――線部の「う・よう」の意味を、ア 意志　イ 推量　ウ 勧誘 から選びなさい。**
13. 明日は雪になろう。　14. 私が代わりに行こう。　15. 一緒に帰ろう。
:::

:::a 解答・解説
1. ア（降り＝連用形）　2. イ（降る＝終止形）　3. ア（語幹）　4. イ　5. イ（元気だ＝終止形）
6. ア（どうやら）　7. イ（まるで）　8. ウ（例えば）　9. ア
10. ア　11. イ（男にふさわしい）　12. イ
13. イ　14. ア　15. ウ
:::

## B7　文法7：助詞（格助詞・接続助詞・副助詞・終助詞）

:::box 要点
| 種類 | 働き | 主な語 |
|:--|:--|:--|
| **格助詞** | 主に**体言**につき、他の語との関係を示す | が・の・を・に・へ・と・から・より・で・や |
| **接続助詞** | 主に**用言・助動詞**につき、前後をつなぐ | ば・と・ても（でも）・けれど（けれども）・が・のに・ので・から・し・て（で）・ながら・たり |
| **副助詞** | いろいろな語につき、意味をそえる | は・も・こそ・さえ・でも・しか・まで・ばかり・だけ・ほど・くらい・など・か |
| **終助詞** | 文末について気持ち・態度を表す | か・な・なあ・ね・よ・ぞ・とも・わ・の |

**格助詞「の」の4つの働き**
| 働き | 言いかえ | 例 |
|:--|:--|:--|
| 主語 | 「が」にできる | 私__の__書いた作文（＝私__が__） |
| 連体修飾 | 「〜の（もの）」ではなく後ろの名詞にかかる | 母__の__手紙 |
| 体言の代用 | 「〜のもの・こと」に言いかえられる | これは私__の__だ（＝私のもの） |
| 並立 | 「〜の〜の」 | 行く__の__行かない__の__と迷う |

**「と」**：格助詞（友達__と__行く／「行く」__と__言った）／接続助詞（春になる__と__暖かい＝用言につく）
**「から」**：格助詞（駅__から__歩く＝起点）／接続助詞（暑い__から__窓を開ける＝理由）
**「が」**：格助詞（花__が__咲く）／接続助詞（行った__が__、いなかった）
**「ながら」**：接続助詞（歩き__ながら__話す：同時／子ども__ながら__よく知っている：逆接）
:::

:::q 演習（15問）
**A　――線部の助詞の種類を、ア 格助詞　イ 接続助詞　ウ 副助詞　エ 終助詞 から選びなさい。**

9. 父 __の__ 作った料理。　10. 姉 __の__ かばん。　11. この本は君 __の__ だ。　12. 行く __の__ 行かない __の__ とけんかする。　13. 私 __の__ 住む町。

**C　――線部の「から」を、ア 格助詞　イ 接続助詞 に分けなさい。**

:::

:::a 解答・解説
1. ウ　2. イ　3. ア　4. エ　5. ウ　6. イ　7. ア（体言につく）　8. イ（用言につく）
9. ア（父が）　10. イ　11. ウ（君のもの）　12. エ　13. ア（私が住む）

## B9　文法9：敬語（尊敬・謙譲・丁寧）

:::box 要点
| 種類 | 働き | 作り方 |
|:--|:--|:--|
| **尊敬語** | **相手（目上の人）の動作**を高める | ①特別な動詞　②お（ご）〜になる　③〜れる・られる |
| **謙譲語** | **自分（身内）の動作**をへりくだって、相手を高める | ①特別な動詞　②お（ご）〜する・お（ご）〜いたす |
| **丁寧語** | 聞き手にていねいに言う | です・ます・ございます、お（ご）〜（お茶・ご飯：美化語） |

**特別な動詞（必ず覚える）**
| ふつう | 尊敬語（相手がする） | 謙譲語（自分がする） |
|:--|:--|:--|
| 行く・来る | いらっしゃる・おいでになる | 参る・伺う |
| いる | いらっしゃる・おいでになる | おる |
| 言う | おっしゃる | 申す・申し上げる |
| 食べる・飲む | 召し上がる | いただく |
| 見る | ご覧になる | 拝見する |
| する | なさる | いたす |
| 知っている | ご存じだ | 存じている・存じ上げる |
| くれる | くださる | ― |
| もらう | ― | いただく |
| あげる・与える | ― | 差し上げる |
| 聞く・たずねる | お聞きになる | 伺う・承る |
| 会う | お会いになる | お目にかかる |

**よくある誤り**
- 二重敬語：「おっしゃられる」×→「おっしゃる」○／「お帰りになられる」×→「お帰りになる」○
- 身内に尊敬語：「（自分の）父がおっしゃいました」×→「父が申しました」○
- 相手に謙譲語：「先生が参ります」×→「先生がいらっしゃいます」○
- 「〜させていただく」の使いすぎ、「ご覧になられる」×。
:::

:::point 見分け方
- **動作をするのがだれか**を確認する。相手（先生・お客様）なら尊敬語、自分や身内なら謙譲語。
- 「お〜になる」は尊敬、「お〜する」は謙譲：先生が**お話しになる**（尊敬）／私が先生に**お話しする**（謙譲）。
- 話し合い形式の問題では「発表者が使った敬語の誤りを直す」「ふさわしい言い方を選ぶ」形で出る。
:::

:::q 演習（15問）
**A　――線部の敬語の種類を、ア 尊敬語　イ 謙譲語　ウ 丁寧語 から選びなさい。**
1. 先生が __おっしゃった__。　2. 私が __伺います__。　3. こちらは図書室 __です__。　4. お客様が __召し上がる__。　5. 母から __いただいた__ 本。　6. 校長先生が __ご覧になる__。　7. 私が __お持ちします__。

**C　次の文の敬語の誤りを直しなさい。**

14. （店員が客に）こちらの商品をいただいてください。
15. （生徒が先生に）私の父が先生にお会いになりたいと申しております。
:::

:::a 解答・解説

# 6　作文（12点）の型／古文の基礎／前日ページ

## S1　作文（12点）の型：減点されない書き方（20分）

:::box 北辰の作文（大問5）の出題のされ方
- 表やグラフなどの**資料**を見て、「あなたの考え」を書く。**条件**がつく：①資料から読み取ったことにふれる ②自分の体験や見聞をふまえる ③二段落構成 ④指定の行数（例：11行以上13行以内）で書く ⑤原稿用紙の使い方に従う。
- 採点は「条件を守っているか」が最優先。**内容の良し悪しより、条件と形式**で点が決まります。だから型で書けば安定します。
:::

:::point 2段落の型（これだけ）
| 段落 | 中身 | 書き出しの型 |
|:--:|:--|:--|
| 第1段落（4〜5行） | **資料から読み取れること**＋**自分の考え（意見）** | 「資料を見ると、〜ことがわかる。私は〜と考える。」 |
| 第2段落（6〜8行） | **体験・見聞（具体例）**＋**まとめ（これからどうするか）** | 「私は以前、〜ことがあった。そのとき〜と感じた。だから、私はこれから〜していきたい。」 |
:::

:::rule 原稿用紙のルール（減点ポイント）
1. **段落の初めは1マス空ける**。2段落なら、空けるのは2か所。
2. **句読点（、。）は1マス**使う。行の最初に来るときは、前の行の最後のマスに文字と一緒に入れる（行頭に置かない）。
3. **「」も1マス**。会話文は原則使わない（字数がもったいない）。
4. **文体を統一**：「〜だ・〜である」（常体）か「〜です・〜ます」（敬体）のどちらかにそろえる。北辰では常体がおすすめ（字数が少なくてすむ）。
5. **話し言葉を使わない**：「〜だと思う」○／「〜かなと思う」×、「なので」（文頭）×→「だから・そのため」○、「〜とか」×、「すごく」×→「とても」○。
6. **行数の条件を必ず守る**。11行以上なら11行目まで書く。最後の行の途中で終わってOK。
7. 漢字で書ける語は漢字で。**自信のない漢字はひらがなでよい**（まちがった漢字は減点、ひらがなは減点なし）。
8. 書き終えたら30秒で読み直し：主語と述語のねじれ（「私の夢は〜になりたい」×→「〜になることだ」○）、「ら抜き」（見れる×→見られる○）。
:::

:::box 使える表現
- 読み取り：「資料を見ると、〜が最も多いことがわかる。」「〜の割合は、〜より高い。」「〜は年々増えている。」
- 意見：「私は〜が大切だと考える。」「〜べきだと思う。」「その理由は〜からだ。」
- 体験：「私は以前、〜ことがある。」「そのとき、〜と感じた。」「〜を通して、〜に気づいた。」
- まとめ：「だから、私はこれから〜したい。」「〜を心がけていきたい。」「〜を大切にしていきたい。」
:::

:::ex 例（資料：「中学生が読書をしない理由」の上位が「時間がない」「読みたい本がない」だった場合）
　資料を見ると、読書をしない理由として「時間がない」を挙げた人が最も多いことがわかる。しかし私は、時間は作ろうとしなければ生まれないものだと考える。短い時間でも本を開く習慣が大切だ。
　私は以前、毎日寝る前の十分間だけ本を読むことを決めて続けたことがある。初めは十分でも長く感じたが、一か月後には自然に本に手が伸びるようになり、読む速さも上がった。短い時間の積み重ねが習慣を作るのだと実感した。だから、私はこれからも、朝や寝る前のわずかな時間を読書にあてることを続けていきたい。
:::

## S2　作文練習①（20分）

:::q 次の資料は、ある中学校の生徒に「あなたが将来のために今いちばん大切にしたいこと」をたずねた結果です。この資料から読み取れることにふれながら、「あなたが今いちばん大切にしたいこと」について、あなたの考えを書きなさい。（条件：二段落構成、自分の体験や見聞をふまえる、11行以上13行以内）
:::data 資料：今いちばん大切にしたいこと（回答者 200人）
| 項目 | 人数 |
|:--|--:|
| 勉強 | 72 |
| 友達との関係 | 58 |
| 部活動 | 40 |
| 家族との時間 | 20 |
| その他 | 10 |
:::
[[genko:13x15]]
:::
:::a 解答例とチェック
　資料を見ると、「勉強」を選んだ人が最も多く、次に「友達との関係」が多いことがわかる。私も勉強は大切だと思うが、いちばん大切にしたいのは友達との関係だ。友達がいるからこそ、勉強も部活動もがんばれると考えるからだ。
　私は以前、テスト前に不安になって勉強が手につかなくなったことがある。そのとき、友達が「一緒にやろう」と声をかけてくれ、図書館で毎日一緒に勉強した。すると不安が消え、結果も上がった。支え合える友達の存在が、自分を前に進ませてくれるのだと気づいた。だから、私はこれからも、困っている友達には自分から声をかけ、たがいに支え合える関係を大切にしていきたい。

:::q 次の資料は、地域の人に「中学生にしてほしいこと」をたずねた結果です。この資料から読み取れることにふれながら、「地域の一員として自分にできること」について、あなたの考えを書きなさい。（条件：二段落構成、自分の体験や見聞をふまえる、11行以上13行以内）
:::data 資料：中学生にしてほしいこと（回答者 150人・複数回答）
| 項目 | 人数 |
|:--|--:|
| あいさつをする | 98 |
| 地域の行事に参加する | 65 |
| 清掃活動に参加する | 44 |
| 高齢者の手助けをする | 39 |

[[genko:13x15]]

　私は以前、登校のときに毎朝見かける近所の方に、思い切って「おはようございます」と声をかけたことがある。初めは緊張したが、相手の方が笑顔で返してくださり、それからは毎朝あいさつを交わす仲になった。小さなあいさつが人と人をつなぐことを実感した。だから、私はこれから、家の近所だけでなく、地域の行事に参加したときにも自分からあいさつをして、地域の人とのつながりを広げていきたい。

## C1　古文の基礎①（歴史的仮名遣い・主語の補い方）（20分）

:::box 歴史的仮名遣い → 現代仮名遣い（必ず出る）
| 規則 | 例 |
|:--|:--|
| 語頭以外の **は・ひ・ふ・へ・ほ → わ・い・う・え・お** | いふ→いう、かは→かわ、あはれ→あわれ、こひ→こい、思ふ→思う、まへ→まえ |
| **ゐ・ゑ・を → い・え・お** | ゐる→いる、こゑ→こえ、をかし→おかし、をとこ→おとこ |
| **ぢ・づ → じ・ず** | はぢ→はじ、いづれ→いずれ、めづらし→めずらし |
| **くわ・ぐわ → か・が** | くわじ（火事）→かじ、ぐわん（願）→がん |
| **au → ō（あう→おう）** | やうやう→ようよう、さう→そう、かうべ→こうべ |
| **iu → yū（いう→ゆう）** | うつくしう→うつくしゅう |
| **eu → yō（えう→よう）** | けふ→きょう、てふ→ちょう |
| **む（助動詞）→ ん** | 行かむ→行かん |
- 「語頭」の「は」はそのまま：はな（花）は「はな」。
- 「を」が助詞のときはそのまま：「花を見る」。
:::

:::box 主語の補い方（読解のコツ）
- 古文は**主語が省略される**。「だれが」を補いながら読む。
- **「〜て」「〜で」でつながる文は、主語が変わりにくい**。**「〜ば」「〜に」「〜を」で区切られると、主語が変わりやすい**。
- **敬語で判断**：「のたまふ（おっしゃる）」「おはす（いらっしゃる）」「給ふ（〜なさる）」があれば、主語は身分の高い人。
- 古文の「けり・き」は過去、「ぬ・つ」は完了、「ず」は打ち消し、「べし」は当然・推量、「む」は推量・意志。
- **係り結び**：文中に「ぞ・なむ・や・か」→文末は連体形、「こそ」→文末は已然形。「や・か」は疑問・反語。
:::

:::q 演習
**A　次の語を現代仮名遣いに直し、すべてひらがなで書きなさい。**
1. あはれ　2. をかし　3. いふ　4. けふ　5. やうやう　6. ゐたり　7. こゑ　8. くわんぜおん　9. いづれ　10. まゐる

**B　次の文の――線部の主語（動作をした人）をア〜ウから選びなさい。**
11. 翁、竹を取りて帰りぬ。家に __ゐて__、竹の中より出でたる子を育てけり。　ア 翁　イ 竹　ウ 子
12. 帝、その人を __召して__、「いかに」と __のたまふ__。　ア 帝　イ その人　ウ 作者
:::

:::a 解答・解説
1. あわれ　2. おかし　3. いう　4. きょう　5. ようよう　6. いたり　7. こえ　8. かんぜおん　9. いずれ　10. まいる（語頭以外の「ゐ」→「い」）
11. ア（「〜て」でつながるので主語は翁のまま）　12. 「召して」も「のたまふ」もア（帝：尊敬語「のたまふ」の主語は身分の高い人）
:::

## C2　古文の基礎②（頻出古語・読解演習）（20分）

:::box 頻出古語40（意味が現代語とちがうものに注意）
| 古語 | 意味 | 古語 | 意味 |
|:--|:--|:--|:--|
| あはれ | しみじみとした趣がある、かわいそうだ | をかし | 趣がある、おもしろい |
| うつくし | **かわいらしい** | いと | とても |
| いみじ | はなはだしい（よい意味にも悪い意味にも） | ありがたし | **めったにない** |
| やがて | **そのまま、すぐに** | つとめて | **早朝**、翌朝 |
| あした | **朝** | ゆかし | 見たい・知りたい |
| かなし | **いとしい**、かわいい | おどろく | **目が覚める**、はっと気づく |
| ののしる | **大声で騒ぐ** | つれづれなり | することがなく退屈だ |
| げに | 本当に | なほ | やはり |
| さらなり | 言うまでもない | おぼゆ | 思われる、似る |
| おはす | いらっしゃる（尊敬） | のたまふ | おっしゃる（尊敬） |
| 給ふ | お〜になる（尊敬）／〜ていただく（謙譲） | 候ふ・侍り | あります・おります（丁寧） |
| 参る | 参上する（謙譲） | まかる | 退出する（謙譲） |
| いづれ | どれ、どちら | いかで | どうして、なんとかして |
| え〜ず | **〜できない** | な〜そ | **〜するな**（禁止） |
| つきづきし | 似つかわしい | わろし | よくない |
| あやし | 不思議だ、身分が低い | さうざうし | 物足りない |
| としごろ | 長年 | ひねもす | 一日中 |
| ゆゆし | 恐れ多い、不吉だ | わびし | つらい、さびしい |
| すなはち | すぐに、つまり | おのづから | 自然と、たまたま |
| まうす | 申し上げる（謙譲） | 心にくし | 奥ゆかしい |
:::

:::passage 読解演習　次の古文を読んで、あとの問いに答えなさい。（『枕草子』より）
春はあけぼの。やうやう白くなりゆく山ぎは、少し明かりて、紫だちたる雲の細くたなびきたる。
夏は夜。月のころはさらなり、闇もなほ、蛍の多く飛びちがひたる。また、ただ一つ二つなど、ほのかにうち光りて行くもをかし。雨など降るもをかし。
秋は夕暮れ。夕日のさして山の端いと近うなりたるに、烏の寝どころへ行くとて、三つ四つ、二つ三つなど飛び急ぐさへあはれなり。
:::

:::q 問い
1. ――線「やうやう」を現代仮名遣いに直し、ひらがなで書きなさい。
2. 「さらなり」の意味として最も適切なものを選びなさい。　ア 言うまでもない　イ めずらしい　ウ さびしい　エ おかしい
3. 作者が「夏」で趣があると述べているものをすべて選びなさい。　ア 月　イ 闇夜の蛍　ウ 雨　エ 烏
4. 「あはれなり」とありますが、作者は何を見て「あはれ」と感じていますか。現代語で簡潔に書きなさい。
5. この文章で、季節ごとに趣があると述べている時間帯を、春・夏・秋の順に書きなさい。
:::

:::a 解答・解説
1. ようよう　2. ア　3. ア・イ・ウ（月のころは言うまでもなく、闇夜の蛍も、雨が降るのも趣がある。烏は秋）　4. 夕日が山に近づくころ、烏がねぐらへ飛び急ぐ様子。　5. 春＝明け方（あけぼの）、夏＝夜、秋＝夕暮れ
:::

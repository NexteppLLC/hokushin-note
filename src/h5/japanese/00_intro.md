# 0　この教材の使い方

:::goal 国語の方針
- 苦手な漢字・文法・語句と、資料を使う話し合い問題を重点的に練習します。話し合い問題では、**発言の意図と資料の根拠を読み取る力**も必要です。
- **2026年度の北辰テストは課題作文の出題がありません。** 作文の配点を前提に得点計画を立てず、読解・古文・知識問題に時間を使います。
- 目標偏差値への到達は、自作模擬の点数だけで決めず、初見の北辰過去問とその回の換算で確認します。
:::

## S0　知識・読解の取り組み方と時間配分（15分で読む）

:::box 国語（50分）の時間配分案
| 内容 | 時間の目安 |
|:--|--:|
| 漢字・文法・語句・話し合い | 8分 |
| 文学的文章 | 16分 |
| 説明的文章 | 16分 |
| 古典 | 6分 |
| 見直し | 4分 |

これは練習用の配分です。実際の問題量・解答方式に合わせて調整してください。大問番号・配点は本番の問題用紙を確認します。
:::

:::box この教材で練習する内容
- **K：漢字**。読みと書きを分け、答えを見ずに確認します。
- **B・G：文法・語句**。用語を覚えた後、文の中で使い分けます。
- **H：話し合い・発表**。資料から分かること、発言の役割、表現の工夫を確認します。
- **M：知識・話し合いの自作模擬**。配点はこの教材独自の練習用です。
- **C：古文**。仮名遣い、語の意味、省略された主語、本文の根拠を練習します。
- S1〜S3の課題作文は旧形式の参考資料として残しています。10月対策の予定には入れません。
:::

:::point 解くときの確認
- 答えられる問題から進め、迷う問題は印を付けて戻ります。
- 話し合いや読解は、設問で探すものを確認してから本文・資料に戻ります。
- マークの欄と設問番号を照合し、記述は文字数や指定語句を守ります。
- [北辰の2026年度公式範囲](https://www.hokushin-t.jp/test/hani/ha_index.html)と[マーク練習用解答用紙](https://www.hokushin-t.jp/kaitouyoushi_ms/ms_kaitouyoushi.html)で形式を確認できます。
:::

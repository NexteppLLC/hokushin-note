# 3　語句6レッスン

## G1　語句1：熟語の構成

:::box 要点（二字熟語の組み立て：6つの型）
| 型 | 説明 | 例 |
|:--|:--|:--|
| ① 似た意味の漢字を重ねる | 同義・類義 | 増加、豊富、思考、絵画、道路、身体、停止 |
| ② 反対（対）の意味の漢字を重ねる | 対義 | 上下、明暗、開閉、売買、往復、賛否、損得 |
| ③ 上が下を修飾する | 「〜の／〜な／〜に」でつながる | 急行（急いで行く）、青空、深海、再会、国旗 |
| ④ 下が上の目的・対象になる | 「〜を／〜に」と下から上に返して読む | 読書（書を読む）、登山（山に登る）、乗車、開店、着席、求人 |
| ⑤ 上が主語、下が述語 | 「〜が〜する」 | 国立（国が立てる）、日没（日が没する）、地震、頭痛、雷鳴 |
| ⑥ 接頭語・接尾語がつく | 上に「不・無・非・未」、下に「的・性・化・然」 | 不安、無理、非常、未定、知的、個性、強化、平然 |
| その他 | 長い熟語の省略・同じ字を重ねる | 国連（国際連合）、人々、堂々 |

**三字熟語**：「1＋2」（新学期、不可能）／「2＋1」（芸術家、積極的）／「1＋1＋1」（松竹梅、衣食住）
**四字熟語**：「2＋2」（一日千秋、自画自賛）
:::

:::point 見分け方のコツ
- まず「反対の字か？」（②）→「下から返して読めるか？」（④：〜を・〜に）→「〜が〜する？」（⑤）→「上が下を説明？」（③）→「似た意味？」（①）の順で確認。
- 「不・無・非・未」で始まれば⑥、「〜的・〜性・〜化」で終われば⑥。
- 北辰では「次の熟語と同じ構成のものを選べ」の形が定番。まず**問題の熟語の型を決めてから**選択肢を見る。
:::

## G2　語句2：対義語・類義語・多義語

:::box 要点
**対義語（意味が反対）**：セットで覚える。
| | | | | | |
|:--|:--|:--|:--|:--|:--|
| 具体⇔抽象 | 客観⇔主観 | 絶対⇔相対 | 積極⇔消極 | 原因⇔結果 | 理想⇔現実 |
| 権利⇔義務 | 生産⇔消費 | 供給⇔需要 | 拡大⇔縮小 | 増加⇔減少 | 進化⇔退化 |
| 肯定⇔否定 | 楽観⇔悲観 | 一般⇔特殊 | 単純⇔複雑 | 精神⇔肉体 | 理性⇔感情 |
| 形式⇔内容 | 自然⇔人工 | 偶然⇔必然 | 平凡⇔非凡 | 保守⇔革新 | 集合⇔解散 |
| 過去⇔未来 | 成功⇔失敗 | 安全⇔危険 | 有名⇔無名 | 賛成⇔反対 | 直接⇔間接 |

**類義語（意味が似ている）**
| | | | | |
|:--|:--|:--|:--|:--|
| 意外＝案外 | 永遠＝永久 | 改良＝改善 | 関心＝興味 | 簡単＝容易 |
| 欠点＝短所 | 決心＝決意 | 原因＝理由 | 手段＝方法 | 準備＝用意 |
| 進歩＝発達 | 心配＝不安 | 大切＝重要 | 努力＝勉励 | 発展＝発達 |
| 平等＝対等 | 有名＝著名 | 用心＝注意 | 冷静＝沈着 | 賛成＝同意 |

**多義語**：1つの語にいくつも意味がある（「かける」：電話をかける・橋をかける・声をかける・ふとんをかける）。問題では「同じ意味で使われているものを選べ」の形。文の中で**言いかえ**て確かめる（「話がはずむ」＝「活発になる」）。
**和語・漢語・外来語**：和語（訓読み・やまとことば：やま、はなす）、漢語（音読み：山岳、会話）、外来語（カタカナ：スピーチ）。
:::

## G5　語句5：書写（行書・部首・画数・筆順）

:::box 要点
**① 行書の特徴**（楷書とのちがい）。北辰・埼玉入試では「行書で書かれた漢字の特徴」を選ぶ問題が出る。
| 特徴 | 説明 |
|:--|:--|
| 点画の連続 | 次の画へ**続けて**書く（筆を紙から離さない部分がある） |
| 点画の省略 | 一部の点や画を**省く**（「糸へん」の下の三点が一本の線になる など） |
| 筆順の変化 | 楷書と**書く順序が変わる**ことがある |
| 丸み | 角ばった部分が**丸く**なる、線が**なめらか** |
| 点画の変化 | 「とめ」が「はらい」になる、「はね」が変わる など |

**② 部首**（形と名前・位置）
| 位置 | 名前 | 例 |
|:--|:--|:--|

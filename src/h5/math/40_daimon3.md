# 4　大問3対策（一次関数の応用）

:::box 大問3の特徴
- (1) は「直線の式を求める」「交点の座標」「変域」など**基本**（5点）。(2) は面積・動点・グラフの読み取りなど**応用**で、途中の考え方を書く記述（5〜7点）。
- 10月の範囲では **関数 $y = ax^2$ は出ない**（11月から）。一次関数・比例反比例の応用が中心。
- **(1) を落とさない**ことが最優先。(2) は「式を立てるところまで」で部分点を取る。
:::

## D3-1　一次関数の式・交点・三角形の面積

:::box 要点
**① 直線の式 $y = ax + b$ の求め方**
- 傾き $a$ ＝ 変化の割合 ＝ $\frac{y の増加量}{x の増加量}$、切片 $b$ ＝ $y$ 軸との交点の $y$ 座標。
- 2点 $(x_1, y_1)$，$(x_2, y_2)$ を通る → $a = \frac{y_2 - y_1}{x_2 - x_1}$、次に1点を代入して $b$。
- 平行な直線は**傾きが等しい**。$x$ 軸との交点は $y = 0$ を代入、$y$ 軸との交点は $x = 0$ を代入。

**② 2直線の交点** → **連立方程式**を解く。

**③ 三角形の面積（座標平面）**
- **$y$ 軸上に辺がある**：底辺＝$y$ 軸上の2点間の長さ、高さ＝もう1つの頂点の $x$ 座標（の絶対値）。
- **$x$ 軸上に辺がある**：底辺＝$x$ 軸上の長さ、高さ＝$y$ 座標。
- どちらもないとき：**軸に平行な線で分ける**、または**囲む長方形からひく**。
:::

[[svg:d3_1_fig]]

:::ex 例題　直線 ℓ：$y = x + 4$ と直線 m：$y = -2x + 10$ がある。ℓ と m の交点を A、ℓ と $y$ 軸の交点を B、m と $y$ 軸の交点を C とする。
(1) A の座標を求めなさい。　(2) △ABC の面積を求めなさい。
(1) $x + 4 = -2x + 10$ → $3x = 6$ → $x = 2$、$y = 6$ → **A(2, 6)**
(2) B(0, 4)、C(0, 10) → 底辺 BC ＝ 6、高さ＝A の $x$ 座標 2 → $\frac{1}{2} \times 6 \times 2 =$ **6**
:::

:::q 演習（6問）
1. 2点 $(1, 5)$，$(3, 1)$ を通る直線の式を求めなさい。
2. 直線 $y = 3x - 2$ に平行で、点 $(2, 1)$ を通る直線の式を求めなさい。
3. 直線 $y = -\frac{1}{2}x + 3$ と $x$ 軸、$y$ 軸で囲まれた三角形の面積を求めなさい。
4. 2直線 $y = 2x - 1$ と $y = -x + 5$ の交点の座標を求めなさい。
5. 直線 ℓ：$y = 2x + 2$ と m：$y = -x + 8$ の交点を A、ℓ、m と $x$ 軸との交点をそれぞれ B、C とする。△ABC の面積を求めなさい。
6. 3点 O(0, 0)、A(6, 0)、B(2, 4) を頂点とする △OAB について、点 B を通り △OAB の面積を2等分する直線の式を求めなさい。
:::

:::a 解答・解説
1. 傾き $\frac{1-5}{3-1} = -2$。$y = -2x + b$ に $(1, 5)$ → $b = 7$ → **$y = -2x + 7$**
2. 傾き3：$1 = 6 + b$ → $b = -5$ → **$y = 3x - 5$**
3. $x$ 軸との交点：$0 = -\frac{1}{2}x + 3$ → $x = 6$。$y$ 軸との交点 $(0, 3)$ → $\frac{1}{2} \times 6 \times 3 =$ **9**
4. $2x - 1 = -x + 5$ → $x = 2$、$y = 3$ → **(2, 3)**
5. A：$2x + 2 = -x + 8$ → $x = 2$，$y = 6$ → A(2, 6)。B：$y = 0$ → $x = -1$。C：$x = 8$。底辺 BC ＝ 9、高さ 6 → $\frac{1}{2} \times 9 \times 6 =$ **27**
6. 頂点 B を通って面積を2等分 → **対辺 OA の中点 (3, 0)** を通る。B(2, 4) と (3, 0)：傾き $\frac{0-4}{3-2} = -4$ → $y = -4x + b$、$(3, 0)$ → $b = 12$ → **$y = -4x + 12$**
:::

## D3-2　面積の二等分・動点

:::box 要点
**① 三角形の面積を2等分する直線**
- **頂点を通る** → 対辺の**中点**を通る。
- **頂点以外の点（辺上や外の点 P）を通る** → まず P と頂点を結んで面積を計算し、等積変形または「面積が半分になる点」を文字でおいて方程式。

**② 等積変形**：底辺が共通で、頂点が**底辺に平行な直線上**を動くとき面積は変わらない。

**③ 動点とグラフ**（$x$ 秒後の面積 $y$）
- 点がどの辺にあるかで**区間を分ける**（例：0〜4秒は辺AB上、4〜10秒は辺BC上）。
- 各区間で $y$ を $x$ の式で表す（一次関数か定数）。グラフは**折れ線**。
- 「面積が○になるのは何秒後」→ 各区間の式で方程式（複数答えがあることが多い）。
:::

[[svg:d3_2_fig]]

:::ex 例題　右の図の長方形 ABCD は AB ＝ 4 cm、BC ＝ 6 cm。点 P は A を出発し、辺 AB、BC 上を B を通って C まで毎秒 1 cm で動く。$x$ 秒後の △APD の面積を $y$ cm² とする。
(1) P が辺 AB 上にあるとき（$0 \le x \le 4$）、$y$ を $x$ の式で表しなさい。
(2) P が辺 BC 上にあるとき（$4 \le x \le 10$）、$y$ を $x$ の式で表しなさい。
(3) △APD の面積が 9 cm² になるのは何秒後か。
(1) AP ＝ $x$、高さ AD ＝ 6 → $y = \frac{1}{2} \times x \times 6 =$ **$3x$**
(2) 底辺 AD ＝ 6、高さ＝AB ＝ 4（P が BC 上にある間は一定）→ **$y = 12$**
(3) (1) の区間で $3x = 9$ → $x = 3$。(2) の区間では常に12なので不適。→ **3 秒後**
:::

:::q 演習（4問）
1. △ABC で A(0, 6)、B(−2, 0)、C(4, 0) とする。点 A を通り △ABC の面積を2等分する直線の式を求めなさい。
2. 上の例題で、P が C を通り過ぎてさらに辺 CD 上を D まで動くとき（$10 \le x \le 14$）、$y$ を $x$ の式で表しなさい。
3. 正方形 ABCD（1辺 6 cm）で、点 P は A を出発し、B、C を通って D まで毎秒 2 cm で動く。$x$ 秒後の △APD の面積を $y$ cm² とするとき、$y$ の最大値と、そのときの $x$ の範囲を求めなさい。
4. 直線 $y = -x + 6$ と $x$ 軸、$y$ 軸で囲まれた △OAB（A は $x$ 軸上、B は $y$ 軸上）がある。原点 O を通り △OAB の面積を2等分する直線の式を求めなさい。
:::

:::a 解答・解説
1. BC の中点は (1, 0)。A(0, 6) と (1, 0) → 傾き $-6$ → **$y = -6x + 6$**
2. P が CD 上：DP ＝ $14 - x$（D に着くのが14秒後）。△APD は底辺 DP、高さ AD ＝ 6 → $y = \frac{1}{2}(14 - x) \times 6 =$ **$y = -3x + 42$**（$x = 10$ で 12、$x = 14$ で 0 と一致）
3. AB 上（$0 \le x \le 3$）：$y = \frac{1}{2} \times 2x \times 6 = 6x$（最大18）。BC 上（$3 \le x \le 6$）：底辺 AD ＝ 6、高さ 6 → $y = 18$（一定）。CD 上：減少。→ **最大値 18、$3 \le x \le 6$**
4. A(6, 0)、B(0, 6)。O を通るので AB の中点 (3, 3) を通る → **$y = x$**
:::

## D3-3　グラフの読み取り（速さ・水そう・料金）

:::box 要点
- **速さのグラフ**（横軸：時間、縦軸：道のり）：**傾き＝速さ**。水平＝止まっている。2人のグラフの**交点＝出会う・追いつく**。
- **水そう**（横軸：時間、縦軸：水の深さ）：傾き＝1分あたりの増え方。傾きが変わる＝**蛇口を増やした／水そうの形が変わった**。
- **料金**（横軸：使用量、縦軸：料金）：切片＝基本料金、傾き＝1単位あたりの料金。
- 「$x$ 分後に…」は、その区間の式に代入。区間を必ず確かめる。
:::

[[svg:d3_3_fig]]

:::ex 例題　A さんは家から 1800 m 離れた駅に向かって歩き、途中の公園で休んだ。右のグラフは、出発してから $x$ 分後の家からの道のりを $y$ m として表したものである（0〜10分：家から公園 800 m、10〜15分：休憩、15〜30分：公園から駅）。
(1) 家から公園までの A さんの速さは分速何 m か。　(2) 15〜30 分の $y$ を $x$ の式で表しなさい。　(3) A さんが出発した 12 分後に、兄が家を自転車で分速 200 m で駅に向かった。兄が A さんに追いつくのは A さんが出発してから何分後か。
(1) $800 \div 10 =$ **分速 80 m**
(2) (15, 800)，(30, 1800) を通る：傾き $\frac{1000}{15} = \frac{200}{3}$、$800 = \frac{200}{3} \times 15 + b$ → $b = -200$ → **$y = \frac{200}{3}x - 200$**
(3) 兄：$y = 200(x - 12) = 200x - 2400$。A さんが休憩中（$y = 800$）に追いつくなら $200x - 2400 = 800$ → $x = 16$ だが休憩は15分まで → 不適。15〜30分の式と連立：$200x - 2400 = \frac{200}{3}x - 200$ → $600x - 7200 = 200x - 600$ → $400x = 6600$ → $x = 16.5$ → **16.5 分後**（16分30秒後）
:::

:::q 演習（3問）
1. 深さ 60 cm の水そうに、はじめ 12 cm の水が入っている。毎分 4 cm ずつ深さが増すように水を入れる。$x$ 分後の深さを $y$ cm として、$y$ を $x$ の式で表し、満水になるのは何分後か求めなさい。
2. ある電話会社の料金は、基本料金 1200 円に、通話時間1分あたり 30 円が加わる。通話時間を $x$ 分、料金を $y$ 円として式で表し、料金が 3000 円になる通話時間を求めなさい。
3. 弟は家を出て分速 60 m で図書館へ歩いた。弟が出発して 6 分後に、姉が同じ道を分速 150 m の自転車で追いかけた。姉が弟に追いつくのは、姉が出発してから何分後か。また、家からの道のりは何 m か。
:::

:::a 解答・解説
1. $y = 4x + 12$。$60 = 4x + 12$ → **12 分後**
2. $y = 30x + 1200$。$3000 = 30x + 1200$ → $x =$ **60 分**
3. 姉が出発して $t$ 分後：弟 $60(t + 6)$、姉 $150t$。$150t = 60t + 360$ → $90t = 360$ → **4 分後**、道のり $150 \times 4 =$ **600 m**
:::

## D3-4　関数 総合演習（40分）

:::q 総合演習（5問・各8点）
1. 直線 ℓ：$y = \frac{1}{2}x + 3$ と直線 m：$y = -x + 6$ がある。ℓ と m の交点を A、ℓ と $y$ 軸の交点を B、m と $x$ 軸の交点を C とする。(1) A の座標　(2) △ABO の面積（O は原点）　(3) △ACO の面積 を求めなさい。
2. 点 (2, 3) を通り、$x$ 軸との交点の $x$ 座標が 5 である直線の式を求めなさい。
3. $y$ は $x$ の一次関数で、$x = -1$ のとき $y = 7$、$x = 2$ のとき $y = 1$ である。この関数で、$y$ の変域が $-5 \le y \le 9$ となる $x$ の変域を求めなさい。
4. 右の図（座標平面）で、A(0, 8)、B(−4, 0)、C(6, 0) とする。線分 AC 上に点 P をとり、△PBC の面積が △ABC の面積の $\frac{1}{4}$ になるとき、P の座標を求めなさい。
5. 兄は 9 時に家を出て 2400 m 先の駅へ分速 80 m で歩いた。弟は 9 時 10 分に家を出て、同じ道を自転車で駅へ向かい、9 時 20 分に駅に着いた。(1) 弟の速さは分速何 m か。　(2) 弟が兄を追いこしたのは 9 時何分か。
:::

[[svg:d3_4_fig]]

:::a 解答・解説
1. (1) $\frac{1}{2}x + 3 = -x + 6$ → $\frac{3}{2}x = 3$ → $x = 2$，$y = 4$ → **A(2, 4)**　(2) B(0, 3)：底辺 OB ＝ 3、高さ 2 → **3**　(3) C(6, 0)：底辺 OC ＝ 6、高さ 4 → **12**
2. 2点 (2, 3)，(5, 0)：傾き $\frac{0-3}{5-2} = -1$ → $y = -x + b$、$(5, 0)$ → $b = 5$ → **$y = -x + 5$**
3. 傾き $\frac{1-7}{2-(-1)} = -2$、$7 = 2 + b$ → $b = 5$ → $y = -2x + 5$。$y = 9$ のとき $x = -2$、$y = -5$ のとき $x = 5$ → **$-2 \le x \le 5$**（減少関数なので $y$ の大小と $x$ の大小が逆になる）
4. △ABC ＝ $\frac{1}{2} \times 10 \times 8 = 40$。△PBC ＝ 10 になる P の高さ（$y$ 座標）：$\frac{1}{2} \times 10 \times y = 10$ → $y = 2$。AC の式：傾き $\frac{0-8}{6-0} = -\frac{4}{3}$ → $y = -\frac{4}{3}x + 8$。$y = 2$ → $-\frac{4}{3}x = -6$ → $x = \frac{9}{2}$ → **P$\left(\frac{9}{2}, 2\right)$**
5. (1) 2400 m を 10 分 → **分速 240 m**　(2) 9時 $x$ 分：兄 $80x$、弟 $240(x - 10)$。$80x = 240x - 2400$ → $160x = 2400$ → $x = 15$ → **9 時 15 分**（兄は 1200 m 地点、駅の手前なので適する）
:::

## Q1　新範囲の準備：展開・因数分解・平方根の復習

:::box 要点
**① 展開の公式**
- $(x+a)(x+b) = x^2 + (a+b)x + ab$
- $(x+a)^2 = x^2 + 2ax + a^2$，$(x-a)^2 = x^2 - 2ax + a^2$
- $(x+a)(x-a) = x^2 - a^2$

**② 因数分解（展開の逆）**：まず**共通因数**をくくり出す → 公式にあてはめる。
- $x^2 + 5x + 6$：たして5、かけて6 → $(x+2)(x+3)$
- $x^2 - 2x - 15$：たして−2、かけて−15 → $(x+3)(x-5)$
- $x^2 - 8x + 16 = (x-4)^2$，$x^2 - 49 = (x+7)(x-7)$
- $3x^2 - 12x = 3x(x-4)$，$2x^2 + 4x - 6 = 2(x^2 + 2x - 3) = 2(x+3)(x-1)$

**③ 平方根**
- $x^2 = a$（$a>0$）の解は $x = \pm\sqrt{a}$。$\sqrt{12} = 2\sqrt{3}$，$\sqrt{50} = 5\sqrt{2}$ のように**中の数を小さく**。
- $\sqrt{a}\times\sqrt{b} = \sqrt{ab}$，$\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}$，分母の有理化：$\frac{2}{\sqrt{3}} = \frac{2\sqrt{3}}{3}$
:::

:::

## Q2　二次方程式の解法①（因数分解）

:::box 要点
**二次方程式**：$ax^2 + bx + c = 0$（$a \ne 0$）の形の方程式。解はふつう2つ。

**因数分解で解く手順**
1. **右辺を0**にする（移項してまとめる）。
2. 左辺を**因数分解**する。
3. 「$AB = 0$ ならば $A = 0$ または $B = 0$」を使う。

:::ex 例題
- $x^2 + 5x + 6 = 0$ → $(x+2)(x+3) = 0$ → $x+2 = 0$ または $x+3 = 0$ → $x = -2$，$x = -3$
- $x^2 - 4x = 0$ → $x(x-4) = 0$ → $x = 0$，$x = 4$（**$x = 0$ を忘れない**）
- $x^2 - 9 = 0$ → $(x+3)(x-3) = 0$ → $x = \pm 3$
- $x^2 - 6x + 9 = 0$ → $(x-3)^2 = 0$ → $x = 3$（解が1つ：**重解**）
- $2x^2 + 10x + 12 = 0$ → 両辺を2で割る → $x^2 + 5x + 6 = 0$ → $x = -2$，$-3$
:::
:::

:::point ここで差がつく
- 答えの書き方は「$x = -2$，$x = -3$」または「$x = -2, -3$」。符号のミスが最多：$(x+2) = 0$ なら $x = \mathbf{-2}$。
- 「$x^2 = 4x$」のような式で**両辺を $x$ で割ってはいけない**（$x = 0$ の解が消える）。必ず $x^2 - 4x = 0$ にして因数分解。
- 係数に共通因数があれば先に割る（$3x^2 - 27 = 0$ → $x^2 - 9 = 0$）。
:::

:::q 演習（16問）　次の二次方程式を解きなさい。
1. $x^2 + 8x + 15 = 0$　2. $x^2 - 7x + 10 = 0$　3. $x^2 + 2x - 24 = 0$　4. $x^2 - x - 42 = 0$
5. $x^2 + 12x + 36 = 0$　6. $x^2 - 16 = 0$　7. $x^2 + 5x = 0$　8. $x^2 = 9x$
9. $x^2 - 10x + 25 = 0$　10. $2x^2 - 18 = 0$　11. $3x^2 + 9x - 30 = 0$　12. $x^2 + 4x - 45 = 0$
13. $x^2 - 13x + 40 = 0$　14. $4x^2 - 8x = 0$　15. $x^2 + 14x + 49 = 0$　16. $x^2 - 3x - 54 = 0$
:::

:::a 解答・解説
1. $(x+3)(x+5)=0$ → $x = -3，-5$　2. $(x-2)(x-5)=0$ → $x = 2，5$　3. $(x+6)(x-4)=0$ → $x = -6，4$　4. $(x+6)(x-7)=0$ → $x = -6，7$
5. $(x+6)^2=0$ → $x = -6$　6. $x = \pm 4$　7. $x(x+5)=0$ → $x = 0，-5$　8. $x^2 - 9x = 0$ → $x(x-9)=0$ → $x = 0，9$
9. $(x-5)^2=0$ → $x = 5$　10. $x^2 = 9$ → $x = \pm 3$　11. $x^2 + 3x - 10 = 0$ → $(x+5)(x-2)=0$ → $x = -5，2$　12. $(x+9)(x-5)=0$ → $x = -9，5$
13. $(x-5)(x-8)=0$ → $x = 5，8$　14. $4x(x-2)=0$ → $x = 0，2$　15. $(x+7)^2=0$ → $x = -7$　16. $(x+6)(x-9)=0$ → $x = -6，9$
:::

## Q3　二次方程式の解法②（平方根の考え方・$(x+m)^2 = k$）

:::box 要点
**① $x^2 = k$ の形** → $x = \pm\sqrt{k}$。$\sqrt{}$ の中は小さくする。
- $x^2 = 7$ → $x = \pm\sqrt{7}$　　$4x^2 = 12$ → $x^2 = 3$ → $x = \pm\sqrt{3}$　　$x^2 - 18 = 0$ → $x^2 = 18$ → $x = \pm 3\sqrt{2}$

**② $(x+m)^2 = k$ の形** → $x + m = \pm\sqrt{k}$ → $x = -m \pm\sqrt{k}$
- $(x-2)^2 = 5$ → $x - 2 = \pm\sqrt{5}$ → $x = 2 \pm\sqrt{5}$
- $(x+3)^2 = 16$ → $x + 3 = \pm 4$ → $x = 1$，$x = -7$（$k$ が平方数なら√が消える）

**③ 平方完成**（$x^2 + px + q = 0$ を $(x+m)^2 = k$ に直す）：$x$ の係数の**半分の2乗**を両辺にたす。
- $x^2 + 6x + 2 = 0$ → $x^2 + 6x = -2$ → $x^2 + 6x + 9 = -2 + 9$ → $(x+3)^2 = 7$ → $x = -3 \pm\sqrt{7}$
- 平方完成は「$x$ の係数が偶数」のときに速い。奇数なら解の公式（Q4）へ。
:::

:::point ここで差がつく
- $(x-2)^2 = 5$ の答えを「$x = \pm\sqrt{5} + 2$」と書いても正解だが、**$x = 2 \pm\sqrt{5}$** の順で書くのがふつう。
- $(x+3)^2 = 16$ のように**√が消える**場合は、2つの数で答える（$1$ と $-7$）。「$x = -3 \pm 4$」のままでは減点。
- $(x+m)^2 = k$ を展開してから解く必要はない。**そのまま平方根**。
:::

:::q 演習（14問）　次の二次方程式を解きなさい。
1. $x^2 = 11$　2. $x^2 = 48$　3. $3x^2 = 27$　4. $2x^2 - 40 = 0$　5. $5x^2 - 15 = 0$
6. $(x-1)^2 = 3$　7. $(x+4)^2 = 10$　8. $(x-5)^2 = 9$　9. $(x+2)^2 - 8 = 0$　10. $(x-3)^2 = 12$
11. $x^2 + 4x - 1 = 0$（平方完成で）　12. $x^2 - 8x + 3 = 0$（平方完成で）　13. $x^2 + 10x + 20 = 0$　14. $x^2 - 2x - 5 = 0$
:::

:::a 解答・解説
1. $x = \pm\sqrt{11}$　2. $x = \pm 4\sqrt{3}$　3. $x^2 = 9$ → $x = \pm 3$　4. $x^2 = 20$ → $x = \pm 2\sqrt{5}$　5. $x^2 = 3$ → $x = \pm\sqrt{3}$
6. $x = 1 \pm\sqrt{3}$　7. $x = -4 \pm\sqrt{10}$　8. $x - 5 = \pm 3$ → $x = 8，2$　9. $(x+2)^2 = 8$ → $x = -2 \pm 2\sqrt{2}$　10. $x = 3 \pm 2\sqrt{3}$
11. $(x+2)^2 = 5$ → $x = -2 \pm\sqrt{5}$　12. $(x-4)^2 = 13$ → $x = 4 \pm\sqrt{13}$　13. $(x+5)^2 = 5$ → $x = -5 \pm\sqrt{5}$　14. $(x-1)^2 = 6$ → $x = 1 \pm\sqrt{6}$
:::

## Q4　二次方程式の解法③（解の公式）

:::box 要点
**解の公式**：$ax^2 + bx + c = 0$ の解は
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
**手順**：① $a, b, c$ を符号ごと書き出す　② 公式に代入　③ $\sqrt{}$ の中を計算して簡単にする　④ **約分できるか確認**

:::ex 例題
- $x^2 + 3x + 1 = 0$：$a=1, b=3, c=1$ → $x = \frac{-3 \pm\sqrt{9 - 4}}{2} = \frac{-3 \pm\sqrt{5}}{2}$
- $2x^2 - 5x + 1 = 0$：$a=2, b=-5, c=1$ → $x = \frac{5 \pm\sqrt{25 - 8}}{4} = \frac{5 \pm\sqrt{17}}{4}$
- $x^2 - 6x + 4 = 0$：$x = \frac{6 \pm\sqrt{36 - 16}}{2} = \frac{6 \pm\sqrt{20}}{2} = \frac{6 \pm 2\sqrt{5}}{2} = 3 \pm\sqrt{5}$（**2で約分**）
- $3x^2 + 2x - 2 = 0$：$x = \frac{-2 \pm\sqrt{4 + 24}}{6} = \frac{-2 \pm 2\sqrt{7}}{6} = \frac{-1 \pm\sqrt{7}}{3}$
:::
:::

:::point ここで差がつく
- $b$ が負のとき、$-b$ は**正**になる：$b = -5$ → $-b = 5$。$b^2$ は必ず正。
- $-4ac$：$c$ が負なら**たし算**になる（$-4 \times 1 \times (-2) = +8$）。
- $\sqrt{}$ の中が**平方数**（4, 9, 16, 25, 36…）なら√が消えて整数解 → 実は因数分解で解けた問題。
- 分子の**全部**が約分できるときだけ約分（$\frac{6 \pm 2\sqrt{5}}{2}$ は $6$ と $2\sqrt{5}$ の両方が2で割れる）。
:::

:::q 演習（12問）　解の公式を使って解きなさい。
1. $x^2 + 5x + 3 = 0$　2. $x^2 - 3x - 2 = 0$　3. $x^2 + x - 1 = 0$　4. $2x^2 + 3x - 1 = 0$
5. $3x^2 - 5x + 1 = 0$　6. $x^2 - 4x - 3 = 0$　7. $x^2 + 6x + 7 = 0$　8. $2x^2 - 6x + 3 = 0$
9. $x^2 - 5x + 6 = 0$（公式で解いて、因数分解の答えと一致することを確かめる）　10. $4x^2 + 4x - 1 = 0$　11. $x^2 - 2x - 4 = 0$　12. $3x^2 + 4x - 1 = 0$
:::

:::a 解答・解説
1. $x = \frac{-5 \pm\sqrt{13}}{2}$　2. $x = \frac{3 \pm\sqrt{17}}{2}$　3. $x = \frac{-1 \pm\sqrt{5}}{2}$　4. $x = \frac{-3 \pm\sqrt{17}}{4}$
5. $x = \frac{5 \pm\sqrt{13}}{6}$　6. $x = \frac{4 \pm\sqrt{28}}{2} = 2 \pm\sqrt{7}$　7. $x = \frac{-6 \pm\sqrt{8}}{2} = -3 \pm\sqrt{2}$　8. $x = \frac{6 \pm\sqrt{12}}{4} = \frac{3 \pm\sqrt{3}}{2}$
9. $x = \frac{5 \pm\sqrt{1}}{2}$ → $x = 3，2$　10. $x = \frac{-4 \pm\sqrt{32}}{8} = \frac{-1 \pm\sqrt{2}}{2}$　11. $x = \frac{2 \pm\sqrt{20}}{2} = 1 \pm\sqrt{5}$　12. $x = \frac{-4 \pm\sqrt{28}}{6} = \frac{-2 \pm\sqrt{7}}{3}$
:::

## Q5　いろいろな二次方程式（整理してから解く・解法の使い分け）

:::box 要点
**手順**：①かっこをはずす・移項して $ax^2 + bx + c = 0$ の形に　②共通因数で割る　③解法を選ぶ

| 形 | 使う解法 |
|:--|:--|
| $x^2 = k$，$(x+m)^2 = k$ | **平方根** |
| 因数分解できる（たして $b$・かけて $c$ の整数が見つかる） | **因数分解** |
| 因数分解できない | **解の公式**（$x$ の係数が偶数なら平方完成でもよい） |

:::ex 例題
- $(x+2)(x-3) = 6$ → $x^2 - x - 6 = 6$ → $x^2 - x - 12 = 0$ → $(x+3)(x-4) = 0$ → $x = -3，4$
- $x(x+4) = 2x + 15$ → $x^2 + 4x - 2x - 15 = 0$ → $x^2 + 2x - 15 = 0$ → $(x+5)(x-3) = 0$ → $x = -5，3$
- $(x-1)^2 = 3x - 1$ → $x^2 - 2x + 1 - 3x + 1 = 0$ → $x^2 - 5x + 2 = 0$ → 公式 → $x = \frac{5 \pm\sqrt{17}}{2}$
- $\frac{1}{2}x^2 - x - 4 = 0$ → 両辺2倍 → $x^2 - 2x - 8 = 0$ → $(x+2)(x-4) = 0$ → $x = -2，4$
- $0.1x^2 + 0.3x - 1 = 0$ → 両辺10倍 → $x^2 + 3x - 10 = 0$ → $x = -5，2$
:::
:::

:::q 演習（12問）　次の二次方程式を解きなさい。
1. $(x+1)(x-5) = 7$　2. $x(x-2) = 3x + 6$　3. $(x-3)^2 = 2x - 1$　4. $(x+4)(x-4) = 6x$
5. $\frac{1}{3}x^2 - 2x + 3 = 0$　6. $0.2x^2 - x - 1.2 = 0$　7. $(2x-1)^2 = 25$　8. $x^2 + 2(x-4) = 0$

:::

:::a 解答・解説
1. $x^2 - 4x - 12 = 0$ → $(x+2)(x-6)=0$ → $x = -2，6$
2. $x^2 - 5x - 6 = 0$ → $(x+1)(x-6)=0$ → $x = -1，6$
3. $x^2 - 8x + 10 = 0$ → $x = \frac{8 \pm\sqrt{24}}{2} = 4 \pm\sqrt{6}$
4. $x^2 - 6x - 16 = 0$ → $(x+2)(x-8)=0$ → $x = -2，8$
5. 3倍：$x^2 - 6x + 9 = 0$ → $(x-3)^2=0$ → $x = 3$
6. 5倍：$x^2 - 5x - 6 = 0$ → $x = -1，6$
7. $2x - 1 = \pm 5$ → $2x = 6，-4$ → $x = 3，-2$

## Q6　解と係数（解から係数を求める）

:::box 要点
**「$x = p$ が解である」＝「$x = p$ を代入すると成り立つ」**。これだけ。
:::ex 例題
- 二次方程式 $x^2 + ax - 8 = 0$ の解の1つが $2$ のとき、$a$ の値と他の解を求めなさい。
　→ $x = 2$ を代入：$4 + 2a - 8 = 0$ → $a = 2$。方程式は $x^2 + 2x - 8 = 0$ → $(x+4)(x-2) = 0$ → 他の解は $x = -4$。
- 2つの解が $3$ と $-5$ である二次方程式（$x^2$ の係数が1）を作りなさい。
　→ $(x-3)(x+5) = 0$ → $x^2 + 2x - 15 = 0$
- $x^2 + ax + b = 0$ の解が $-2$ と $4$ のとき、$a, b$ を求めなさい。
　→ $(x+2)(x-4) = x^2 - 2x - 8$ → $a = -2$，$b = -8$
:::
:::

:::q 演習（8問）
1. $x^2 - 5x + a = 0$ の解の1つが $2$ のとき、$a$ の値と他の解を求めなさい。
2. $x^2 + ax - 12 = 0$ の解の1つが $-3$ のとき、$a$ の値と他の解を求めなさい。
3. 2つの解が $1$ と $6$ である二次方程式を、$x^2 + ax + b = 0$ の形で書きなさい。
4. 2つの解が $-4$ と $-1$ である二次方程式を、$x^2 + ax + b = 0$ の形で書きなさい。
5. $x^2 + ax + b = 0$ の解が $2$ と $7$ のとき、$a, b$ の値を求めなさい。
6. $x^2 - 2x + a = 0$ の解の1つが $1 + \sqrt{3}$ のとき、$a$ の値を求めなさい。
7. $x^2 + ax + 9 = 0$ が重解をもつとき、$a$ の値をすべて求めなさい。
8. $x^2 - 6x + a = 0$ の1つの解が他の解の2倍であるとき、$a$ の値を求めなさい。
:::

:::a 解答・解説
1. $4 - 10 + a = 0$ → $a = 6$。$x^2 - 5x + 6 = 0$ → $(x-2)(x-3) = 0$ → 他の解 $x = 3$
2. $9 - 3a - 12 = 0$ → $a = -1$。$x^2 - x - 12 = 0$ → $(x+3)(x-4) = 0$ → 他の解 $x = 4$
3. $(x-1)(x-6) = 0$ → $x^2 - 7x + 6 = 0$
4. $(x+4)(x+1) = 0$ → $x^2 + 5x + 4 = 0$
5. $(x-2)(x-7) = x^2 - 9x + 14$ → $a = -9$，$b = 14$
6. 代入：$(1+\sqrt{3})^2 - 2(1+\sqrt{3}) + a = 0$ → $4 + 2\sqrt{3} - 2 - 2\sqrt{3} + a = 0$ → $a = -2$（別解：$(x-1)^2 = 3$ の形 → $x^2 - 2x - 2 = 0$）
7. 重解 → $(x \pm 3)^2 = x^2 \pm 6x + 9$ → $a = 6，-6$
8. 解を $p, 2p$ とすると $(x-p)(x-2p) = x^2 - 3px + 2p^2$。$3p = 6$ → $p = 2$ → $a = 2p^2 = 8$（解は $2$ と $4$）
:::

## Q7　二次方程式の利用①（数・整数の問題）

:::box 要点（文章題の手順）
1. **求めるものを $x$ とおく**（「ある数」「小さいほうの整数」「もとの数の一の位」など）。
2. 問題文の関係を**式**にする（「積が〜」「2乗が〜」「〜より…大きい」）。
3. 解く。
4. **解が条件に合うか確かめる**（「正の整数」なら負の解を捨てる）。**この確認を答案に1行書くと部分点にもなる**。

:::ex 例題
- 連続する2つの正の整数があり、その積が 132 である。2つの整数を求めなさい。
　→ 小さいほうを $x$ とすると、大きいほうは $x + 1$。$x(x+1) = 132$ → $x^2 + x - 132 = 0$ → $(x+12)(x-11) = 0$ → $x = -12，11$。$x$ は正の整数だから $x = 11$。答え **11 と 12**。
- ある正の数を2乗すると、もとの数を5倍した数より 24 大きくなる。この数を求めなさい。
　→ $x^2 = 5x + 24$ → $x^2 - 5x - 24 = 0$ → $(x+3)(x-8) = 0$ → $x = 8$（$x > 0$）。
:::
:::

:::q 演習（8問）
1. 連続する2つの正の整数の積が 210 である。2つの整数を求めなさい。
2. 連続する3つの正の整数があり、最も小さい数と最も大きい数の積は、中央の数の 4 倍より 20 大きい。3つの整数を求めなさい。
3. ある正の数に 3 を加えて2乗すると、もとの数の 9 倍より 7 大きくなる。この数をすべて求めなさい。
4. ある自然数から 2 をひいた数と、その自然数に 4 を加えた数の積が 72 になる。この自然数を求めなさい。
5. 大小2つの整数があり、差は 5、積は 84 である。2つの整数の組をすべて求めなさい。
6. 十の位の数が一の位の数より 3 大きい2けたの自然数がある。十の位と一の位の数の積が 28 のとき、この自然数を求めなさい。
7. 連続する2つの正の奇数の積が 195 である。2つの奇数を求めなさい。
8. ある数 $x$ の2乗と $x$ の 6 倍の和が 40 になる。$x$ の値をすべて求めなさい。
:::

:::a 解答・解説
1. $x(x+1) = 210$ → $x^2 + x - 210 = 0$ → $(x+15)(x-14) = 0$ → $x = 14$（正）→ **14 と 15**
2. 中央を $x$ とおく：$(x-1)(x+1) = 4x + 20$ → $x^2 - 1 = 4x + 20$ → $x^2 - 4x - 21 = 0$ → $(x+3)(x-7) = 0$ → $x = 7$ → **6, 7, 8**（確認：$6 \times 8 = 48 = 4 \times 7 + 20$）
3. $(x+3)^2 = 9x + 7$ → $x^2 + 6x + 9 - 9x - 7 = 0$ → $x^2 - 3x + 2 = 0$ → $(x-1)(x-2) = 0$ → **1 と 2**（どちらも正で条件に合う）
4. $(x-2)(x+4) = 72$ → $x^2 + 2x - 80 = 0$ → $(x+10)(x-8) = 0$ → $x = 8$（自然数）→ **8**（確認：$6 \times 12 = 72$）
5. 大きいほうを $x$、小さいほうを $x - 5$：$x(x-5) = 84$ → $x^2 - 5x - 84 = 0$ → $(x+7)(x-12) = 0$ → $x = 12$ のとき **12 と 7**、$x = -7$ のとき **−7 と −12**（整数なので負も可）
6. 一の位を $x$ とすると十の位は $x + 3$：$x(x+3) = 28$ → $x^2 + 3x - 28 = 0$ → $(x+7)(x-4) = 0$ → $x = 4$ → 十の位は7 → **74**
7. 小さいほうを $x$、大きいほうを $x + 2$：$x(x+2) = 195$ → $x^2 + 2x - 195 = 0$ → $(x+15)(x-13) = 0$ → $x = 13$ → **13 と 15**
8. $x^2 + 6x = 40$ → $x^2 + 6x - 40 = 0$ → $(x+10)(x-4) = 0$ → **$x = 4，-10$**（条件がないので両方）
:::

## Q8　二次方程式の利用②（図形・面積・道幅）

:::box 要点
- **長方形の面積**：縦 $\times$ 横。「縦が横より 3 cm 長い」→ 横 $x$、縦 $x + 3$。
- **道幅の問題**：幅 $x$ の道を「端に寄せて」考える → 道を除いた部分は 縦 $(a - x)$、横 $(b - x)$ の長方形（道が縦横1本ずつのとき）。
- **正方形の紙から箱を作る**：四すみから1辺 $x$ の正方形を切り取る → 底面は 1辺 $(a - 2x)$ の正方形、高さ $x$。
- **答えの吟味**：長さは正、しかも「もとの長さより短い」など、図形として成り立つ条件を確認。
:::

[[svg:q8_road]]

:::ex 例題　縦 10 m、横 14 m の長方形の土地に、右の図のように幅 $x$ m の道を縦・横に1本ずつ作り、残りを花だんにする。花だんの面積が 96 m² になるとき、$x$ を求めなさい。
道を端に寄せると、花だんは縦 $(10 - x)$ m、横 $(14 - x)$ m の長方形になるから、
$(10-x)(14-x) = 96$ → $140 - 24x + x^2 = 96$ → $x^2 - 24x + 44 = 0$ → $(x-2)(x-22) = 0$ → $x = 2，22$
$0 < x < 10$ だから $x = 2$。答え **2 m**
:::

:::q 演習（6問）
1. 縦が横より 4 cm 長い長方形の面積が 60 cm² である。横の長さを求めなさい。
2. 1辺が $x$ cm の正方形の縦を 2 cm 長くし、横を 3 cm 短くした長方形の面積が 50 cm² になった。$x$ を求めなさい。
3. 縦 8 m、横 12 m の長方形の土地に、幅 $x$ m の道を縦・横に1本ずつ作ると、残りの面積が 60 m² になった。$x$ を求めなさい。
4. 1辺 12 cm の正方形の紙の四すみから、1辺 $x$ cm の正方形を切り取ってふたのない箱を作ったところ、底面の面積が 64 cm² になった。$x$ を求めなさい。
5. 底辺が高さより 5 cm 長い三角形の面積が 42 cm² である。高さを求めなさい。
6. 正方形の1辺を 3 cm 長くすると、面積がもとの正方形の 2 倍より 7 cm² 大きくなった。もとの正方形の1辺の長さを求めなさい。
:::

:::a 解答・解説
1. 横 $x$、縦 $x + 4$：$x(x+4) = 60$ → $x^2 + 4x - 60 = 0$ → $(x+10)(x-6) = 0$ → $x = 6$ → **6 cm**
2. $(x+2)(x-3) = 50$ → $x^2 - x - 6 = 50$ → $x^2 - x - 56 = 0$ → $(x+7)(x-8) = 0$ → $x = 8$（$x > 3$ が必要）→ **8**
3. $(8-x)(12-x) = 60$ → $96 - 20x + x^2 = 60$ → $x^2 - 20x + 36 = 0$ → $(x-2)(x-18) = 0$ → $0 < x < 8$ より **$x = 2$**
4. 底面の1辺は $12 - 2x$：$(12-2x)^2 = 64$ → $12 - 2x = \pm 8$ → $x = 2$ または $x = 10$。$0 < x < 6$ より **$x = 2$**
5. 高さ $x$、底辺 $x + 5$：$\frac{1}{2}x(x+5) = 42$ → $x^2 + 5x - 84 = 0$ → $(x+12)(x-7) = 0$ → **7 cm**
6. 1辺 $x$：$(x+3)^2 = 2x^2 + 7$ → $x^2 + 6x + 9 = 2x^2 + 7$ → $x^2 - 6x - 2 = 0$ → $x = 3 \pm\sqrt{11}$ → $x > 0$ より **$3 + \sqrt{11}$ cm**（$\sqrt{11} \approx 3.3$ なので $3 - \sqrt{11} < 0$）
:::

## Q9　二次方程式の利用③（動点・関数との融合）

:::box 要点
**動点の問題の手順**
1. **$x$ 秒後**の各点の位置（動いた長さ）を $x$ で表す（速さ×時間）。
2. 求める図形（三角形など）の**底辺と高さ**を $x$ で表す。
3. 面積の式＝指定の値 → 二次方程式。
4. **$x$ の範囲**（点が辺上にある時間）で解を吟味。
:::

[[svg:q9_move]]

:::ex 例題　右の図の正方形 ABCD は1辺 8 cm。点 P は A を出発して辺 AB 上を B まで毎秒 1 cm、点 Q は B を出発して辺 BC 上を C まで毎秒 1 cm で、同時に動く。△PBQ の面積が 6 cm² になるのは、出発してから何秒後か。
$x$ 秒後：AP $= x$ より PB $= 8 - x$、BQ $= x$。△PBQ $= \frac{1}{2}(8-x) \cdot x = 6$
→ $x(8-x) = 12$ → $8x - x^2 = 12$ → $x^2 - 8x + 12 = 0$ → $(x-2)(x-6) = 0$ → $x = 2，6$
$0 \le x \le 8$ なのでどちらも適する。答え **2 秒後と 6 秒後**
:::

:::q 演習（5問）
1. 上の例題で、△PBQ の面積が 8 cm² になるのは何秒後か。
2. 長方形 ABCD は AB $= 6$ cm、BC $= 10$ cm。点 P は B を出発して辺 BC 上を C まで毎秒 1 cm、点 Q は C を出発して辺 CD 上を D まで毎秒 1 cm で同時に動く。△PCQ の面積が 12 cm² になるのは何秒後か。
3. 1辺 10 cm の正方形 ABCD で、点 P は A から B へ、点 Q は D から A へ、どちらも毎秒 1 cm で同時に出発する。△APQ の面積が 12 cm² になるのは何秒後か。
4. 一次関数 $y = -x + 6$ のグラフ上の点 P（$x > 0$，$y > 0$）から $x$ 軸、$y$ 軸に垂線をひいてできる長方形の面積が 8 のとき、P の座標を求めなさい。
5. 関数 $y = 2x + 4$ のグラフ上に点 P があり、P の $x$ 座標を $t$（$t > 0$）とする。原点 O、P、および点 $(t, 0)$ を頂点とする三角形の面積が 16 のとき、$t$ の値を求めなさい。
:::

:::a 解答・解説
1. $\frac{1}{2}(8-x)x = 8$ → $x^2 - 8x + 16 = 0$ → $(x-4)^2 = 0$ → **4 秒後**（1回だけ）
2. $x$ 秒後：PC $= 10 - x$、CQ $= x$。$\frac{1}{2}(10-x)x = 12$ → $x^2 - 10x + 24 = 0$ → $(x-4)(x-6) = 0$ → $0 \le x \le 6$（Q は 6 秒で D に着く）より **4 秒後と 6 秒後**
3. $x$ 秒後：AP $= x$、AQ $= 10 - x$。$\frac{1}{2}x(10-x) = 12$ → $x^2 - 10x + 24 = 0$ → $x = 4，6$ → **4 秒後と 6 秒後**
4. P$(t, -t+6)$：$t(-t+6) = 8$ → $t^2 - 6t + 8 = 0$ → $(t-2)(t-4) = 0$ → **P(2, 4) または P(4, 2)**
5. P$(t, 2t+4)$。三角形の底辺 $t$、高さ $2t + 4$：$\frac{1}{2}t(2t+4) = 16$ → $t^2 + 2t - 16 = 0$ → $t = -1 \pm\sqrt{17}$ → $t > 0$ より **$t = -1 + \sqrt{17}$**
:::

## Q10　二次方程式 まとめテスト（12問・35分）

:::q 問1　次の二次方程式を解きなさい。【各4点】
1. $x^2 - 6x - 16 = 0$　2. $x^2 + 9x = 0$　3. $3x^2 = 48$　4. $(x+5)^2 = 7$　5. $x^2 + 3x - 5 = 0$　6. $2x^2 - 4x - 3 = 0$　7. $(x-2)(x+3) = 14$　8. $x^2 - 12x + 36 = 0$
:::
:::q 問2　次の問いに答えなさい。【各5点】
9. 二次方程式 $x^2 + ax + 6 = 0$ の解の1つが $-2$ のとき、$a$ の値と他の解を求めなさい。
10. 連続する2つの正の整数の2乗の和が 113 になる。2つの整数を求めなさい。
11. 縦 6 m、横 9 m の長方形の土地に幅 $x$ m の道を縦・横に1本ずつ作り、残りの面積を 28 m² にしたい。$x$ の値を求めなさい。
12. 1辺 8 cm の正方形 ABCD で、点 P は B を出発して辺 BC 上を毎秒 2 cm で C まで、点 Q は C を出発して辺 CD 上を毎秒 1 cm で D まで同時に動く。△PCQ の面積が 3 cm² になるのは何秒後か。
:::

:::a 解答・解説
1. $(x+2)(x-8)=0$ → $x = -2，8$　2. $x(x+9)=0$ → $x = 0，-9$　3. $x^2 = 16$ → $x = \pm 4$　4. $x = -5 \pm\sqrt{7}$
5. $x = \frac{-3 \pm\sqrt{29}}{2}$　6. $x = \frac{4 \pm\sqrt{16+24}}{4} = \frac{4 \pm 2\sqrt{10}}{4} = \frac{2 \pm\sqrt{10}}{2}$　7. $x^2 + x - 6 = 14$ → $x^2 + x - 20 = 0$ → $(x+5)(x-4)=0$ → $x = -5，4$　8. $(x-6)^2=0$ → $x = 6$
9. $4 - 2a + 6 = 0$ → $a = 5$。$x^2 + 5x + 6 = (x+2)(x+3)$ → 他の解 $x = -3$
10. $x^2 + (x+1)^2 = 113$ → $2x^2 + 2x - 112 = 0$ → $x^2 + x - 56 = 0$ → $(x+8)(x-7)=0$ → $x = 7$ → **7 と 8**
11. $(6-x)(9-x) = 28$ → $x^2 - 15x + 54 - 28 = 0$ → $x^2 - 15x + 26 = 0$ → $(x-2)(x-13)=0$ → $0 < x < 6$ より **$x = 2$**
12. $x$ 秒後：PC $= 8 - 2x$、CQ $= x$（$0 \le x \le 4$）。$\frac{1}{2}(8-2x)x = 3$ → $(8-2x)x = 6$ → $2x^2 - 8x + 6 = 0$ → $x^2 - 4x + 3 = 0$ → $(x-1)(x-3)=0$ → **1 秒後と 3 秒後**（どちらも $0 \le x \le 4$ に入る）

**得点**（　／52）→ 42点以上で合格。間違えた型は Q2〜Q9 の該当ページへ。
:::

## D2-1　作図①（基本の5作図）

:::box 基本の作図（この5つの組み合わせで全問題が解ける）
| 作図 | かき方 | 意味（＝何の集まりか） |
|:--|:--|:--|
| **① 垂直二等分線** | A, B を中心に**同じ半径**の弧を上下にかき、交点を結ぶ | 2点 A, B から**等しい距離**にある点の集まり。線分の中点も求まる |
| **② 角の二等分線** | 頂点 O を中心に弧をかき、2辺との交点からさらに同じ半径の弧をかき、交点と O を結ぶ | 角の2辺から**等しい距離**にある点の集まり |
| **③ 直線上の点 P を通る垂線** | P を中心に弧をかいて直線と2点で交わらせ、その2点から同じ半径の弧をかき交点と P を結ぶ | P で直線に垂直 |
| **④ 直線外の点 P から直線への垂線** | P を中心に弧をかいて直線と2点で交わらせ、その2点から弧をかき、交点と P を結ぶ | P から直線への**最短距離**（距離＝垂線の長さ） |
| **⑤ 円の中心** | 円周上に3点をとり、2本の弦の垂直二等分線の交点 | 3点から等距離の点 ＝ 外接円の中心 |

2. ∠XOY の二等分線をかきなさい。
3. 直線 ℓ 上にない点 P から ℓ にひいた垂線をかきなさい。
4. 直線 ℓ 上の点 A で ℓ に接する、半径 2 cm の円の中心 O をかきなさい（O は ℓ の上側）。

:::a 解答・解説（作図の手順）
1. A, B を中心に同じ半径（AB の半分より大きく）の弧を上下にかき、交点を結ぶ。AB との交点が M。
2. O を中心に弧をかき OX, OY との交点を C, D とする。C, D から同じ半径の弧をかき、交点 E と O を結ぶ。
3. P を中心に弧をかき ℓ との交点を C, D とする。C, D を中心に同じ半径の弧を ℓ の下側（または上側）にかき、交点と P を結ぶ。
4. 接線 ℓ ⊥ 半径 OA だから、**A を通る ℓ の垂線**をかき（③）、A から 2 cm の位置（コンパスで 2 cm をとる）に O をとる。
5. 「2点から等距離」→ **AB の垂直二等分線**をかき、ℓ との交点が P。
:::

## D2-2　作図②（条件を読みかえる応用）

:::q 演習（5問）　次の条件を満たす点や線を作図する手順を、使う基本作図の番号（①〜⑤）とともに説明しなさい。実際に図にもかきなさい。
1. △ABC で、辺 AB, AC までの距離が等しく、辺 BC 上にある点 P。
2. △ABC の3つの頂点から等しい距離にある点 O。
3. 直線 ℓ 上の点 A で、ℓ との角が 45° になる直線。
4. 円 O の周上の点 A における接線。
5. 線分 AB を、点 A を中心に 60° 回転させた線分 AB′。
:::

[[svg:d2_2_ex]]

:::a 解答・解説
1. 「2辺から等距離」→ **∠A の二等分線**（②）をかき、BC との交点が P。
2. 「3頂点から等距離」→ **AB, BC の垂直二等分線**（①）を2本かき、交点が O（外接円の中心）。
3. A で ℓ の垂線（③）をかき、できた 90° を**角の二等分線**（②）で2等分すると 45°。
4. 半径 OA をひき、**A を通る OA の垂線**（③）が接線。
5. A, B を中心に半径 AB の弧をかき、交点を B′ とすると △ABB′ は正三角形 → ∠BAB′ ＝ 60°。
:::

:::point 作図の採点で落とさないために
- 弧は**必ず残す**。作図に使わない線は消す。
- 求める点には**記号（P, O など）を書く**。
- 「点 P をとりなさい」で線を引きすぎない。「直線をかきなさい」なら**直線**（両側にのばす）で。
:::

## D2-3　確率①（樹形図・表）

:::box 要点
**確率 ＝ （あることがらが起こる場合の数）÷（起こりうるすべての場合の数）**（同様に確からしいとき）
- **2つのさいころ** → **表（6×6＝36通り）**。「和」「積」「差」「目が同じ」など。
- **硬貨・カードを順に取り出す** → **樹形図**。
- **同時に2つ取り出す**（区別しない）→ 組み合わせ：A, B, C, D から2つ ＝ AB, AC, AD, BC, BD, CD の **6通り**（順に取り出すなら 4×3 ＝ 12通り）。
- **「少なくとも1つ」** → **1 −（1つもない確率）**。
- 答えは**約分**した分数。確率が1（必ず起こる）や0（決して起こらない）もある。
:::ex 例題　大小2つのさいころを投げるとき、出た目の和が 5 の倍数になる確率。
表で「和が5」（1,4）（2,3）（3,2）（4,1）の4通り、「和が10」（4,6）（5,5）（6,4）の3通り → 合計7通り → $\frac{7}{36}$
:::
:::

:::q 演習（8問）
1. 大小2つのさいころを投げるとき、出た目の和が 8 になる確率。
2. 大小2つのさいころを投げるとき、出た目の積が 12 になる確率。
3. 大小2つのさいころを投げるとき、出た目が同じになる確率。
4. 大小2つのさいころを投げるとき、大きいさいころの目が小さいさいころの目より大きくなる確率。
5. 1, 2, 3, 4 のカードから1枚ずつ2回続けて取り出し（もどさない）、順に十の位・一の位として2けたの整数を作る。この整数が 3 の倍数になる確率。
6. 赤玉2個、白玉3個が入った袋から同時に2個取り出すとき、2個とも白玉である確率。
7. 3枚の硬貨を同時に投げるとき、表が2枚以上出る確率。
8. A, B, C, D, E の5人から2人の委員を選ぶとき、A が選ばれる確率。
:::

:::a 解答・解説
1. （2,6）（3,5）（4,4）（5,3）（6,2）の5通り → $\frac{5}{36}$
2. （2,6）（3,4）（4,3）（6,2）の4通り → $\frac{4}{36} = \frac{1}{9}$
3. 6通り → $\frac{6}{36} = \frac{1}{6}$
4. 目が同じ6通りを除いた30通りの半分 → 15通り → $\frac{15}{36} = \frac{5}{12}$
5. 全部で $4 \times 3 = 12$ 通り。3の倍数：12, 21, 24, 42 の4通り → $\frac{4}{12} = \frac{1}{3}$
6. 白玉を①②③として、5個から2個の組み合わせは10通り。白2個は ①②, ①③, ②③ の3通り → $\frac{3}{10}$
7. 8通りのうち、表2枚（3通り）＋表3枚（1通り）＝4通り → $\frac{4}{8} = \frac{1}{2}$
8. 2人の組み合わせは10通り。A を含むのは AB, AC, AD, AE の4通り → $\frac{4}{10} = \frac{2}{5}$
:::

## D2-4　確率②（応用：図形・数直線・「少なくとも」）

:::q 演習（6問）
1. 大小2つのさいころを投げ、大きいさいころの目を $a$、小さいさいころの目を $b$ とする。$\frac{b}{a}$ が整数になる確率。
2. 大小2つのさいころを投げ、出た目の和を $s$ とする。$\sqrt{s}$ が整数になる確率。
3. 1〜6 の目のさいころを2回投げ、1回目の目を $x$ 座標、2回目の目を $y$ 座標とする点 P をとる。点 P が直線 $y = x + 2$ 上にある確率。
4. 数直線上の原点に点 P がある。硬貨を3回投げ、表なら +2、裏なら −1 だけ P を動かす。3回目のあと P が原点より右にある確率。
5. 1, 2, 3, 4, 5 のカードから同時に2枚引くとき、2枚の数の和が偶数になる確率。
6. 大小2つのさいころを投げるとき、少なくとも一方が 6 の目である確率。
:::

:::a 解答・解説
1. $b$ が $a$ の倍数：$a=1$ のとき $b$ は6通り、$a=2$：3通り、$a=3$：2通り、$a=4$：1通り、$a=5$：1通り、$a=6$：1通り → 14通り → $\frac{14}{36} = \frac{7}{18}$
2. $s = 4$（3通り）、$s = 9$（4通り）→ 7通り → $\frac{7}{36}$
3. $(1,3)(2,4)(3,5)(4,6)$ の4通り → $\frac{4}{36} = \frac{1}{9}$
4. 表 $k$ 回のとき位置は $2k - (3-k) = 3k - 3$。$k = 2$ → 3、$k = 3$ → 6 が右。表2回は3通り、表3回は1通り → $\frac{4}{8} = \frac{1}{2}$
5. 10通りのうち和が偶数＝「奇数＋奇数」（1,3）（1,5）（3,5）の3通りと「偶数＋偶数」（2,4）の1通り → $\frac{4}{10} = \frac{2}{5}$
6. 1 −（両方6以外）$= 1 - \frac{25}{36} = \frac{11}{36}$
:::

## D2-5　資料の活用（代表値・箱ひげ図）

:::box 要点
| 用語 | 意味 |
|:--|:--|
| 平均値 | 合計 ÷ 個数 |
| 中央値（メジアン） | 大きさの順に並べた**まん中の値**。個数が偶数なら**まん中2つの平均** |
| 最頻値（モード） | 最も多く出てくる値（度数分布表なら**度数が最大の階級の階級値**） |
| 範囲（レンジ） | 最大値 − 最小値 |
| 階級値 | 階級のまん中の値（10以上20未満 → 15） |
| 相対度数 | その階級の度数 ÷ 度数の合計 |
| 累積度数 | その階級までの度数の合計 |
| 四分位数 | データを4等分する3つの値。**第1四分位数**＝下半分の中央値、**第2四分位数**＝全体の中央値、**第3四分位数**＝上半分の中央値 |
| 四分位範囲 | 第3四分位数 − 第1四分位数（箱の長さ） |
| 箱ひげ図 | 最小値・第1四分位数・中央値・第3四分位数・最大値を1つの図に。**箱の中に約半分のデータ**が入る |
:::

[[svg:d2_5_box]]

:::ex 例題　次のデータ（9人の得点）：3, 5, 6, 6, 7, 8, 9, 9, 10
中央値＝5番目＝**7**。下半分（3, 5, 6, 6）の中央値＝第1四分位数＝$(5+6)/2$＝**5.5**。上半分（8, 9, 9, 10）の中央値＝第3四分位数＝**9**。四分位範囲＝9 − 5.5＝**3.5**。範囲＝10 − 3＝**7**。
※ 個数が奇数のときは、中央値をどちらの半分にも入れない。
:::

:::q 演習（6問）
1. データ 4, 7, 7, 9, 12, 15, 18, 20 の中央値と四分位範囲を求めなさい。
2. データ 2, 3, 3, 5, 6, 8, 9, 11, 14, 15, 20 の第1四分位数、第3四分位数を求めなさい。
3. ある度数分布表で、10点以上20点未満の階級の度数が 6、全体の度数が 40 のとき、この階級の相対度数を求めなさい。
4. 右の箱ひげ図（A組・B組の通学時間）について、正しいものをすべて選びなさい。　ア A組の中央値は20分より大きい　イ B組の四分位範囲はA組より大きい　ウ B組には通学時間が30分以上の生徒が必ずいる　エ A組の生徒の半数以上は通学時間が15分以下である
5. 5人のテストの点数の平均が 72 点で、そのうち4人の点数が 65, 70, 74, 80 のとき、残りの1人の点数を求めなさい。
6. データ 6, 8, 10, 12, $x$（$x$ は最大値）の平均値が 10 のとき、$x$ の値と中央値を求めなさい。
:::

:::a 解答・解説
1. 8個：中央値＝$(9+12)/2 = 10.5$。第1四分位数＝下半分（4, 7, 7, 9）の中央値＝7、第3四分位数＝（12, 15, 18, 20）の中央値＝16.5 → 四分位範囲＝**9.5**
2. 11個：中央値＝6番目＝8。下半分（2, 3, 3, 5, 6）の中央値＝**3**、上半分（9, 11, 14, 15, 20）の中央値＝**14**
3. $6 \div 40 = 0.15$
4. 図を読む：A組 最小5・Q1 10・中央値 15・Q3 22・最大 35、B組 最小8・Q1 15・中央値 20・Q3 30・最大 40 → ア×（15分）　イ○（B: 15、A: 12）　ウ○（第3四分位数が30なので、30以上の生徒が存在する）　エ○（中央値15 → 半数以上が15以下）→ **イ・ウ・エ**
5. $72 \times 5 = 360$、$360 - (65+70+74+80) = 360 - 289 = 71$ → **71点**
6. $6+8+10+12+x = 50$ → $x = 14$。中央値＝10
:::

## D2-6　規則性①（$n$ 番目の式）

:::box 要点
**手順**：①1番目・2番目・3番目…を**表**にする　②**増え方**を見る（毎回同じ数ずつ増える → $an + b$ の形）　③ $n = 1$ で確かめる
- 「毎回 $a$ ずつ増える」→ $n$ 番目 ＝ $a \times n$ ＋ 定数（$n = 1$ の値から定数を決める）
- 正方形に並ぶ（1, 4, 9, 16…）→ $n^2$。三角形に並ぶ（1, 3, 6, 10…）→ $\frac{n(n+1)}{2}$
- 「周りの数」「囲む数」は、全体から内側をひく（$n^2 - (n-2)^2 = 4n - 4$）
:::

[[svg:d2_6_dots]]

:::ex 例題　右の図のように、碁石を正方形の周に並べる。1番目は1辺に2個、2番目は3個、3番目は4個…。$n$ 番目の碁石の数を $n$ の式で表しなさい。
1番目 4個、2番目 8個、3番目 12個 → 4個ずつ増える → **$4n$ 個**（別解：1辺 $(n+1)$ 個で4辺、角の4個が重複 → $4(n+1) - 4 = 4n$）
:::

:::q 演習（5問）
1. マッチ棒で正三角形を横に並べていく（1個：3本、2個：5本、3個：7本…）。正三角形を $n$ 個作るのに必要なマッチ棒の本数を $n$ の式で表しなさい。また、40本でできる正三角形の数を求めなさい。
2. 1辺 1 cm の正方形のタイルを、1番目は1枚、2番目は縦横2枚ずつ（4枚）、3番目は3枚ずつ（9枚）…と正方形に並べる。$n$ 番目の周の長さを $n$ の式で表しなさい。
3. 白と黒の碁石を、1番目：黒1個、2番目：黒1個の周りに白8個（合計9個）、3番目：合計25個…と正方形に並べる。$n$ 番目の碁石の合計を $n$ の式で表しなさい。また、5番目の白の碁石の数を求めなさい（黒は中央の1個のみ）。
4. 数の列 3, 7, 11, 15, 19, … について、$n$ 番目の数を $n$ の式で表し、10番目の数を求めなさい。
5. 表のように、自然数を1段目に1個、2段目に2個、3段目に3個…と並べる。$n$ 段目の最後の数を $n$ の式で表し、10段目の最初の数を求めなさい。

| 1段目 | 1 | | | |
|:--|:--|:--|:--|:--|
| 2段目 | 2 | 3 | | |
| 3段目 | 4 | 5 | 6 | |
| 4段目 | 7 | 8 | 9 | 10 |
:::

:::a 解答・解説
1. 2本ずつ増える → $2n + 1$（$n=1$ で 3）。$2n + 1 = 40$ は整数解なし → $2n + 1 \le 40$ → $n = 19$ のとき 39本 → **19個**（40本では1本余る）
2. 1辺が $n$ cm の正方形 → 周＝**$4n$ cm**
3. 1辺 $(2n - 1)$ 個の正方形 → 合計 **$(2n-1)^2$ 個**。5番目：$9^2 = 81$、白は $81 - 1 = $ **80 個**
4. 4ずつ増える → $4n - 1$。10番目＝**39**
5. $n$ 段目の最後の数＝1段目から $n$ 段目までの個数＝$1 + 2 + \cdots + n = \frac{n(n+1)}{2}$。9段目の最後は $\frac{9 \times 10}{2} = 45$ → 10段目の最初は **46**
:::

## D2-7　規則性②・文字式による説明

:::box 要点（説明問題の型）
**「〜であることを、文字を使って説明しなさい」**は、次の3行で書く。
1. **文字のおき方**：「$n$ を整数とすると、連続する3つの整数は $n, n+1, n+2$ と表せる。」
2. **計算**：「その和は $n + (n+1) + (n+2) = 3n + 3 = 3(n+1)$」
3. **結論**：「$n + 1$ は整数だから、$3(n+1)$ は 3 の倍数である。」

| よく出る表し方 | 文字式 |
|:--|:--|
| 偶数・奇数 | $2n$、$2n + 1$（または $2n - 1$） |
| 連続する2つの整数・3つの整数 | $n, n+1$／$n, n+1, n+2$（$n-1, n, n+1$ でもよい） |
| 連続する2つの偶数・奇数 | $2n, 2n+2$／$2n+1, 2n+3$ |
| 2けたの自然数（十の位 $a$、一の位 $b$） | $10a + b$。位を入れかえた数は $10b + a$ |
| 3の倍数、5の倍数 | $3m$、$5m$（$m$ は整数） |
| 「〜の倍数である」の結論 | 「$( )$ は整数だから、$k \times ( )$ は $k$ の倍数」 |
:::

:::q 演習（4問）
1. 連続する2つの奇数の和は 4 の倍数であることを説明しなさい。
2. 2けたの自然数と、その十の位と一の位を入れかえた数の和は 11 の倍数であることを説明しなさい。
3. 連続する3つの整数で、最も大きい数の2乗から最も小さい数の2乗をひいた差は、中央の数の 4 倍になることを説明しなさい。
4. カレンダーで、縦に並ぶ3つの数の和は、中央の数の 3 倍になることを説明しなさい。
:::

:::a 解答例
1. $n$ を整数とすると、連続する2つの奇数は $2n+1, 2n+3$ と表せる。その和は $(2n+1) + (2n+3) = 4n + 4 = 4(n+1)$。$n+1$ は整数だから、$4(n+1)$ は 4 の倍数である。
2. 十の位を $a$、一の位を $b$ とすると、もとの数は $10a + b$、入れかえた数は $10b + a$。和は $(10a+b) + (10b+a) = 11a + 11b = 11(a+b)$。$a + b$ は整数だから、11 の倍数である。
3. 中央の数を $n$ とすると、3つの整数は $n-1, n, n+1$。$(n+1)^2 - (n-1)^2 = (n^2 + 2n + 1) - (n^2 - 2n + 1) = 4n$。これは中央の数 $n$ の 4 倍である。
4. 中央の数を $n$ とすると、上の数は $n - 7$、下の数は $n + 7$。和は $(n-7) + n + (n+7) = 3n$。これは中央の数の 3 倍である。
:::

## D2-8　図形の小問（角度・面積・体積）

:::box 要点
**① 角度**
- **平行線**：同位角・錯角は等しい。「Z」「F」の形を探す。補助線（平行線をもう1本引く）で解ける問題が多い。
- **三角形の内角の和 180°**、**外角＝となり合わない2つの内角の和**。
- **$n$ 角形の内角の和＝$180 \times (n-2)$**、**外角の和＝360°**（何角形でも）。正五角形の1つの内角＝108°、正六角形＝120°。
- **二等辺三角形**：底角が等しい。**正三角形**：すべて60°。
- **円周角**は次回の範囲（11月）。10月は出ない。

**② 面積・体積**
- 円：面積 $\pi r^2$、周 $2\pi r$。おうぎ形：面積 $\pi r^2 \times \frac{a}{360}$、弧 $2\pi r \times \frac{a}{360}$。
- 角柱・円柱：**底面積 × 高さ**。角錐・円錐：**底面積 × 高さ × $\frac{1}{3}$**。
- 球：体積 $\frac{4}{3}\pi r^3$、表面積 $4\pi r^2$。
- 円錐の側面積：$\pi \times$ 母線 $\times$ 半径（＝おうぎ形の面積）。展開図のおうぎ形の中心角＝$360 \times \frac{半径}{母線}$。
- 回転体：円柱・円錐・球（半球）の組み合わせ。
:::

[[svg:d2_8_angles]]

:::q 演習（8問）
1. 図①で ℓ ∥ m のとき、∠x の大きさを求めなさい。（ℓ 上の角 55°、m 上の角 30°、折れ線の頂点の角が ∠x）
2. 図②で、△ABC の ∠A ＝ 40°、∠B の外角が 110° のとき、∠C の大きさを求めなさい。
3. 正八角形の1つの内角の大きさを求めなさい。
4. 図③で、AB ＝ AC の二等辺三角形 ABC の ∠A ＝ 36° のとき、∠B の大きさを求めなさい。
5. 半径 6 cm、中心角 120° のおうぎ形の面積と弧の長さを求めなさい。
6. 底面の半径 3 cm、高さ 4 cm、母線 5 cm の円錐の体積と表面積を求めなさい。
7. 半径 3 cm の球の体積と表面積を求めなさい。
8. 直角をはさむ2辺が 3 cm、4 cm の直角三角形を、4 cm の辺を軸として1回転させてできる立体の体積を求めなさい。
:::

:::a 解答・解説
1. 頂点を通り ℓ に平行な線をひくと、錯角より ∠x ＝ 55° ＋ 30° ＝ **85°**
2. 外角110°＝∠A ＋ ∠C → ∠C ＝ 110 − 40 ＝ **70°**
3. 内角の和 $180 \times 6 = 1080$ → $1080 \div 8 =$ **135°**
4. $(180 - 36) \div 2 =$ **72°**
5. 面積 $\pi \times 36 \times \frac{120}{360} = 12\pi$ cm²、弧 $2\pi \times 6 \times \frac{1}{3} = 4\pi$ cm
6. 体積 $\frac{1}{3} \times 9\pi \times 4 = 12\pi$ cm³。表面積＝底面 $9\pi$ ＋ 側面 $\pi \times 5 \times 3 = 15\pi$ → **$24\pi$ cm²**
7. 体積 $\frac{4}{3}\pi \times 27 = 36\pi$ cm³、表面積 $4\pi \times 9 = 36\pi$ cm²
8. 底面の半径 3 cm、高さ 4 cm の円錐 → $\frac{1}{3} \times 9\pi \times 4 =$ **$12\pi$ cm³**
:::

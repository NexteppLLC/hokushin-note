# 0　この教材の使い方

:::goal 理科の方針
- 目標は**知識を、初めて見る図・実験・グラフに使えること**。用語の確認と資料を読む練習を毎日組み合わせます。
- 10月11日の範囲は中1・中2全範囲と指定の中3範囲。東京書籍P72〜106は、**生物の成長と生殖・遺伝の規則性と遺伝子**です。
- 新範囲だけに偏らず、物理・化学・生物・地学を混ぜて復習します。自作模擬の点数から北辰偏差値を直接換算することはできません。
:::

## 0-1　理科の解き方と時間配分（40分）

| 手順 | 確認すること | 時間の目安 |
|:--|:--|--:|
| 全体確認・基本問題 | 解答方式と、先に解ける問題を確認 | 7分 |
| 実験・図・計算・記述 | 設問→必要な資料→条件整理→解答 | 30分 |
| 見直し | 未解答・単位・記号・マーク欄の対応 | 3分 |

この教材の模擬は学習用の構成・配点です。本番の大問数・配点・指示は問題用紙で確認してください。時間配分も初見の過去問で調整します。

:::point 解き方のコツ
- 図の**凡例・矢印・番号**、グラフの**縦軸・横軸・単位・目盛り**を確認します。
- 実験は**変える条件／そろえる条件／比べる結果**を分けます。知識だけで答えを決めず、示された条件を根拠にします。
- 計算は使った数値と単位を残します。記述は指定語句に加え、**原因・結果・比較対象**が正しいかを確認します。
- マークと記述の両方を練習します。北辰公式：[出題範囲](https://www.hokushin-t.jp/test/hani/ha_index.html)／[解答形式](https://www.hokushin-t.jp/test/mstaisaku/mstaisaku.html)。範囲照合：2026年9月。
:::

## 0-2　34日間の進め方（番号は教材の単元）

[[include:plan_table.inc.md]]

:::note 40分の使い方
- **知識確認10分→図・資料の大問15分→根拠を確認して直し10分→数日前の再テスト5分**を基本にします。
- V1〜V24は新しい図・条件を使う演習です。初めに診断し、分からなかった単元のN・Rへ戻ります。
- 正答直後だけでなく、翌日・数日後・1週間後にも短く再テストします。時間内に別の図でも解けるかを確認します。
- 9月の答案の誤答を**知識・図表・条件・計算・記述・時間**に分け、練習の順番を調整してください。
:::

## N1　細胞分裂と生物の成長

:::box 要点
**① 生物が成長するしくみ**
- 生物のからだは細胞でできている。からだが成長するのは、**細胞の数がふえる**（細胞分裂）ことと、**分裂した細胞が大きくなる**ことによる。
- 根では、**先端に近い部分**で細胞分裂がさかんに行われる。先端から少しはなれた部分の細胞は、分裂してから大きくなっている。根の先端は**根冠**という部分でおおわれ、保護されている。

**② 体細胞分裂**（からだをつくる細胞がふえる分裂）
| 順序 | ようす |
|:--:|:--|
| ア | 分裂の前：核の中で染色体が**複製**される（この段階では、はっきりした染色体は見えない） |
| イ | 核の形が消え、**ひものような染色体**が現れる |
| ウ | 染色体が細胞の**中央**に集まって並ぶ |
| エ | 染色体が2つに分かれて、細胞の**両端**に移動する |
| オ | 細胞の中央に**仕切り**ができ始める（植物では細胞板、動物では外側からくびれる） |
| カ | 染色体が見えなくなり、2つの核ができて**2つの細胞**になる |
- 複製してから分裂するので、**分裂後の細胞の染色体の数は、もとの細胞と同じ**。
- 染色体の数は、生物の種類によって決まっている（ヒト46本、タマネギ16本など）。

**③ 細胞分裂の観察**（タマネギの根の先端）
1. 根の先端を切り取り、**うすい塩酸**に入れてあたためる → **細胞どうしをはなれやすくする**（1つ1つの細胞を観察しやすくする）。
2. **酢酸オルセイン液**（または酢酸カーミン液）をたらす → **核や染色体を染めて**見やすくする。
3. カバーガラスをかけ、ろ紙をのせて指で**押しつぶす** → 細胞の重なりをなくす。
4. 顕微鏡で観察。分裂中の細胞は**先端に近い部分**に多い。
:::

(4) 先端に近い部分
(5) 16本（分裂前に複製されるので同じ数）
(6) 細胞分裂によって細胞の数がふえ、分裂した細胞がもとの大きさまで大きくなることで、根が成長する。
:::

## N2　無性生殖・有性生殖（植物）

:::box 要点
**① 生殖**：生物が自分と同じ種類の新しい個体（子）をつくること。
| 種類 | 特徴 | 例 |
|:--|:--|:--|
| **無性生殖** | **受精を行わない**。親のからだの一部が分かれて子になる。子は親と**まったく同じ遺伝子**をもつ（形質も同じ） | **分裂**（ゾウリムシ、アメーバ、ミカヅキモ）、**出芽**（酵母菌、ヒドラ）、**栄養生殖**（ジャガイモのいも、サツマイモ、オランダイチゴのほふく茎、さし木、球根） |
| **有性生殖** | **生殖細胞**（卵・精子、卵細胞・精細胞）が**受精**して子ができる。子は両親から遺伝子を半分ずつ受けつぐ | 動物、種子植物（花で行う） |

**② 被子植物の有性生殖**
1. おしべの**やく**でつくられた**花粉**が、めしべの**柱頭**につく（**受粉**）。
2. 花粉から**花粉管**がのび、その中を**精細胞**が移動する。
3. 胚珠の中の**卵細胞**と精細胞の核が合体する（**受精**）→ **受精卵**。
4. 受精卵は細胞分裂をくり返して**胚**になる。**胚珠 → 種子**、**子房 → 果実**。
- 花粉管の観察：スライドガラスに**砂糖水**をたらし、花粉を落として観察すると、花粉管がのびるようすが見える。
:::

:::q 一問一答（15問）
1. 生物が子をつくることを何というか。
2. 受精を行わずに子をつくる生殖を何というか。
3. ゾウリムシがからだを2つに分けてふえる無性生殖を何というか。
4. 酵母菌やヒドラのように、からだの一部がふくらんで新しい個体になる生殖を何というか。
5. ジャガイモのいもから芽が出てふえるような生殖を何というか。
6. 無性生殖でできた子の遺伝子は、親と比べてどうか。
7. 生殖細胞が受精して子ができる生殖を何というか。
8. 被子植物の生殖細胞を2つ答えなさい。
9. 花粉がめしべの柱頭につくことを何というか。
10. 受粉した花粉からのびる管を何というか。
11. 卵細胞はどこにあるか。
12. 卵細胞と精細胞の核が合体することを何というか。
13. 受精卵が分裂をくり返してできる、種子の中の部分を何というか。
14. 受精後、胚珠と子房はそれぞれ何になるか。
15. 花粉管の観察で、スライドガラスにたらす液は何か。
:::

:::a 解答
1. 生殖　2. 無性生殖　3. 分裂　4. 出芽　5. 栄養生殖　6. まったく同じ　7. 有性生殖　8. 卵細胞・精細胞　9. 受粉　10. 花粉管　11. 胚珠の中　12. 受精　13. 胚　14. 胚珠→種子、子房→果実　15. 砂糖水
:::

:::q 演習（大問形式）
(1) 次のア〜エのうち、無性生殖をすべて選びなさい。　ア ジャガイモのいもから芽が出る　イ カエルの受精卵が成長する　ウ アメーバが2つに分かれる　エ アブラナの花で種子ができる
(2) 無性生殖でふえた子の形質が親と同じになる理由を、「遺伝子」という語を使って説明しなさい。
(3) 被子植物で、花粉が柱頭についたあと、受精が起こるまでの過程を「花粉管」「精細胞」「卵細胞」の語を使って説明しなさい。
(4) 受精卵が細胞分裂をくり返してできるものを何というか。また、それをふくむ胚珠は何になるか。
(5) 農家がさし木や球根で植物をふやすのは、無性生殖のどんな点を利用しているか。
:::

:::a 解答・解説
(1) ア・ウ
(2) 子は親の細胞が分かれてできるので、親とまったく同じ遺伝子を受けつぐから。
(3) 花粉から花粉管がのび、その中を精細胞が移動して、胚珠の中の卵細胞の核と合体する。
(4) 胚、種子
(5) 親と同じ形質（味・色・形など）の子ができる点。
:::

## N3　有性生殖（動物）と発生

:::box 要点
**① 動物の有性生殖**
- 雌の**卵巣**で**卵**、雄の**精巣**で**精子**がつくられる（生殖細胞）。
- 精子の核と卵の核が合体して**受精** → **受精卵**（1個の細胞）。
- 受精卵は細胞分裂をくり返して**胚**になり、からだの形ができていく。受精卵から成体になるまでの過程を**発生**という。
- 胚：受精卵が分裂を始めてから、自分で食物をとり始める前までの子。

**② カエルの発生**：受精卵 → 2細胞 → 4細胞 → 8細胞 → …（細胞の数がふえる）→ 胚 → おたまじゃくし → カエル。
- 発生の初め（分裂の初め）は、**分裂するたびに細胞1つ1つは小さくなり、胚全体の大きさはほぼ変わらない**。
- やがて細胞の形や役割がちがってくる（組織・器官ができる）。
:::

:::q 一問一答（10問）
1. 動物で、雌の生殖細胞を何というか。また、それがつくられる器官は何か。
2. 動物で、雄の生殖細胞を何というか。また、それがつくられる器官は何か。
3. 精子の核と卵の核が合体することを何というか。
4. 受精した卵を何というか。
5. 受精卵が分裂を始めてから、自分で食物をとり始める前までの子を何というか。
6. 受精卵が成体になるまでの過程を何というか。
7. カエルの受精卵は、分裂をくり返すと何になるか（子のよび名）。
8. 発生の初めのころ、分裂するたびに細胞1つの大きさはどうなるか。
9. 発生の初めのころ、胚全体の大きさはどうなるか。
10. 受精卵は何個の細胞か。
:::

:::a 解答
1. 卵・卵巣　2. 精子・精巣　3. 受精　4. 受精卵　5. 胚　6. 発生　7. おたまじゃくし　8. 小さくなる　9. ほぼ変わらない　10. 1個
:::

:::q 演習（大問形式）　カエルの発生を観察した。次の図A〜Eは発生の途中のようすを順不同で表した自作模式図である。A〜Dは同じ倍率、Eは倍率が異なる。

[[svg:visual_frog]]

(1) A〜E を発生の順に並べなさい。
(2) 受精卵がくり返す細胞分裂によって、細胞の数はどうなるか。また、B の細胞1つの大きさは A と比べてどうか。
(3) 精子と卵がつくられる器官を、それぞれ答えなさい。
(4) 受精卵が胚を経て成体になるまでの過程を何というか。
(5) 有性生殖でできた子の形質が、親と少しちがうことがある理由を、「遺伝子」の語を使って説明しなさい。
:::

:::a 解答・解説
(1) A → C → B → D → E。Aは受精卵、Cは2細胞、Bは4細胞、Dは多数の細胞になった胚、Eはおたまじゃくし。分裂の溝と細胞の数を見て順序を決める。
(2) ふえる／小さい（全体の大きさは変わらないまま分裂するため）
(3) 精子：精巣、卵：卵巣
(4) 発生
(5) 子は両方の親から遺伝子を半分ずつ受けつぎ、遺伝子の組み合わせが親とちがうから。
:::

## N4　減数分裂と染色体の受けつがれ方

:::box 要点
**① 減数分裂**：**生殖細胞**（卵・精子、卵細胞・精細胞）がつくられるときの特別な細胞分裂。**染色体の数がもとの細胞の半分**になる。
- 体細胞分裂：染色体の数は変わらない（複製してから分裂）。
- 減数分裂：染色体の数が**半分**になる。**受精**すると、卵と精子の染色体が合わさって**もとの数にもどる**。
- 例：親の細胞の染色体が 24本 → 生殖細胞は 12本 → 受精卵は 24本。

**② 染色体と遺伝子**
- **遺伝子**は染色体にふくまれている。体細胞の染色体は**2本ずつ対**になっていて、対になった染色体には同じ形質についての遺伝子がある。
- 減数分裂では、**対になっている染色体が分かれて、別々の生殖細胞に入る**。
- 有性生殖：子は父と母から染色体（遺伝子）を**半分ずつ**受けつぐ → 遺伝子の組み合わせが親と異なる → 親と異なる形質が現れることがある（**多様性**）。
- 無性生殖：体細胞分裂でふえる → 子は親と**同じ遺伝子**。

| | 体細胞分裂 | 減数分裂 |
|:--|:--|:--|
| いつ | からだが成長するとき、無性生殖 | 生殖細胞をつくるとき |
| 染色体の数 | もとと**同じ** | もとの**半分** |
:::

:::q 一問一答（10問）
1. 生殖細胞がつくられるときに行われる細胞分裂を何というか。
2. 減数分裂でできた生殖細胞の染色体の数は、もとの細胞と比べてどうなるか。
3. 受精卵の染色体の数は、親の体細胞と比べてどうか。
4. 遺伝子は細胞の何にふくまれているか。
5. 体細胞の染色体が16本の生物の、卵細胞の染色体は何本か。
6. 5 の生物の受精卵の染色体は何本か。
7. 有性生殖では、子は染色体をどのように受けつぐか。
8. 有性生殖の子の形質が親とちがうことがあるのはなぜか。
9. 無性生殖でふえるときの細胞分裂は、体細胞分裂と減数分裂のどちらか。
10. 減数分裂で、対になっている染色体はどうなるか。
:::

:::a 解答
1. 減数分裂　2. 半分になる　3. 同じ　4. 染色体　5. 8本　6. 16本　7. 父と母から半分ずつ受けつぐ　8. 遺伝子の組み合わせが親と異なるから　9. 体細胞分裂　10. 分かれて別々の生殖細胞に入る
:::

:::q 演習（大問形式）　ある動物の体細胞の染色体の数は 20 本である。
(1) この動物の精子の染色体は何本か。
(2) この動物の受精卵の染色体は何本か。
(3) 精子や卵がつくられるときの細胞分裂を何というか。また、この分裂と体細胞分裂とのちがいを、「染色体の数」という語を使って説明しなさい。

## N5　遺伝の規則性（メンデル）

:::box 要点
**① 用語**
- **形質**：生物のもつ形や性質（種子の形・花の色など）。**遺伝**：親の形質が子に伝わること。
- **対立形質**：同時には現れない、対をなす形質（丸としわ、黄色と緑色）。
- **純系**：何代自家受粉をくり返しても、親と同じ形質しか現れないもの。
- **顕性の形質**：対立形質の純系どうしをかけ合わせたとき、**子に現れる**形質。**潜性の形質**：子に現れない形質。（以前は優性・劣性とよんだ）

**② メンデルの実験（エンドウ）**
- 丸い種子の純系（AA）× しわの種子の純系（aa）→ 子はすべて **Aa**（丸：顕性が現れる）。
- 子（Aa）どうしをかけ合わせる → 孫は **AA：Aa：aa ＝ 1：2：1** → 丸：しわ ＝ **3：1**。

**③ 分離の法則**：対になっている遺伝子は、減数分裂によって**分かれて、別々の生殖細胞に入る**。

**④ 表（かけ合わせの計算）**：縦横に生殖細胞の遺伝子を書く。
| | A | a |
|:--:|:--:|:--:|
| **A** | AA | Aa |
| **a** | Aa | aa |

- Aa × aa → Aa：aa ＝ **1：1**（顕性：潜性 ＝ 1：1）
- AA × Aa → AA：Aa ＝ 1：1 → **すべて顕性**
- 遺伝子の記号は、顕性を**大文字**、潜性を**小文字**で表す。
:::

:::q 一問一答（12問）
1. 生物のもつ形や性質を何というか。
2. 親の形質が子に伝わることを何というか。
3. 丸としわのように、同時には現れない対になった形質を何というか。
4. 何代自家受粉をくり返しても同じ形質しか現れないものを何というか。

## N6　遺伝子・DNAと活用

:::box 要点
- 遺伝子の本体は **DNA**（デオキシリボ核酸）という物質。染色体の中にある。
- 遺伝子は、親から子へ、細胞から細胞へ、複製されて受けつがれる。
- **遺伝子の研究成果の活用**：品種改良（味のよい米、病気に強い作物）、**遺伝子組換え**（青いバラ、害虫に強い作物、微生物にヒトのインスリンをつくらせる）、**DNA鑑定**（犯罪捜査・親子鑑定）、医療（遺伝子の異常による病気の診断・治療）、**iPS細胞**による再生医療の研究。
- 生物の形質は「遺伝子（生まれつき）」と「環境（育ち方）」の両方の影響を受ける。
- **注意**：「生物の多様性と進化」（セキツイ動物の進化、相同器官、始祖鳥）は11月の範囲。10月は細胞分裂・生殖・遺伝までを完成させる。
:::

:::q 一問一答（6問）
1. 遺伝子の本体である物質を何というか（アルファベット3文字）。
2. DNA は細胞の何の中にあるか。
3. ある生物の遺伝子を別の生物に組みこむ技術を何というか。
4. DNA の情報を使って個人を識別することを何というか。
5. 微生物に遺伝子を組みこんでつくられる、糖尿病の薬になる物質は何か。
6. 生物の形質は、遺伝子と、もう1つ何の影響を受けるか。
:::

:::a 解答
1. DNA　2. 染色体（核）　3. 遺伝子組換え　4. DNA鑑定　5. インスリン　6. 環境
:::

# 6A　理科の図資料演習―34日間の使い方

## D0　理科の診断と、基礎の補い方

:::box Day1は40分で診断する
**診断20分＋必要知識10分＋直し10分。** 9月の北辰の自分の答案と解答を用意する。未採点ならまず採点し、既習の誤答を「知識・図表・条件・計算・記述・時間」に分ける。まだ習っていない内容は別に「未習」と記録し、既習の誤答と混ぜない。

答案がない場合は、手元の未見の過去問から、学習済み分野の資料付き大問を1〜2題選び、解答を見ずに20分以内で取り組む。この時間は診断のためであり、40分の本番練習の代わりではない。

残り10分ではN1の冒頭の要点を確認し、最後の10分で診断中に見つかった既習の誤答を1〜2問直す。**Day1ではV1〜V24の解答を先読みしない。** この計画の中3新範囲は、10月11日向けの生物の成長・生殖・遺伝を中心とする。未習部分が多ければ、先に教科書・要点から学び、診断で解けなかったことを能力不足とは扱わない。
:::

:::box 通常日の40分は、初見→必要知識→直し→後日テスト
| 順序 | 時間 | やること |
|:--|:--|:--|
| 図資料を解く | 15分 | 当日のVの大問を解答を見ずに解く。図中の矢印・単位・比較する条件に印を付ける |
| 必要な知識を確認 | 10分 | 日別表に指定されたN/R単元の「該当要点・確認2問」だけを見る |
| その日の直し（VX） | 10分 | 解答と根拠を照合し、どの図・条件を見落としたか記録する |
| 後日再テスト（VT） | 5分 | 解説を見てから24時間以上たった問題を1〜2問、解答を閉じて解く |

**必要知識10分で、40分などの標準時間が付いた単元全体を完了したことにはしない。** 終えたのは当日の指定箇所だけ。「全単元を学習した」「理解した」「24時間以上後も自力で解けた」を分けて考える。

15分で解けないときは、止まった場所も記録する。未習なら基礎学習へ切り替え、最初の記録を「未習」、学習後を「解き直し」とする。解説を見た直後の正解で、初見の結果を書き換えない。
:::

## VX　理科の直し―図のどこを読めばよかったか

:::box 当日10分の直し
答えを読む前に、自分の解答を残す。正解した問題でも、偶然の正解や理由を説明できないものには「要確認」を付ける。

| つまずき | 直しで確かめること |
|:--|:--|
| 知識 | 用語・公式・器具の操作を、当日の要点で確認する |
| 図表 | 軸・単位・目盛り・矢印・凡例のどれを見落としたか指さす |
| 条件 | 変える条件とそろえる条件、比較すべき二つの実験を選び直す |
| 計算 | 式に入れる量・単位換算・比例の向きを確認する |
| 記述 | 原因と結果がつながるように、解答を閉じて短く説明する |
| 時間 | どこで止まったか記録し、解く順番や後回しの判断を見直す |

記録例：「V9(2)／軸を逆に読んだ／先に横軸と縦軸の単位を書く」。**初見結果・直し・後日再テストは別に残す。** 同じ問題を直後に解けても、定着の確認は後日に行う。

Day20とDay27は、紙で40分の時間制限練習をした後、35分で採点・資料確認・時間配分を振り返る。手元に未見の北辰過去問があれば、サイトの模擬の代わりに使ってよい。問題用紙と解答用紙を往復し、記述・単位・マークまで行う。サイトの模擬の配点を公式の配点とみなさず、実際の問題用紙・公式資料を確認する。
:::

## VT　理科の後日再テストと、直前1週間

:::box 解説を見た時刻から24時間以上あける
再テストの対象は、以前に×・△だった問題、偶然に当たった問題、資料の根拠を説明できなかった問題。**解答や直しノートを閉じて**取り組み、正誤だけでなく理由も説明する。前日と同じ時間帯でも24時間未満なら、さらに前の問題を選ぶ。該当する問題がなければ5分は記録整理に使い、再テスト成功として記録しない。

「答えを覚えていた」場合は、図の向きや数値・条件が違う別問題でも同じ考え方を使えるか確認する。別問題が用意できないときは、図のどの二点を比較したか、なぜその公式を使うかを説明し、「未見問題でも成功した」とは記録しない。

| 期間 | 理科の配分 |
|:--|:--|
| Day2〜26（20除外） | 通常日の最後に5分、1〜2問の後日再テスト |
| Day20・27 | 模擬40分＋直し35分。直後の解き直しを後日再テストには数えない |
| Day28〜33 | 未定着問の再テスト20分＋止まった箇所の知識10分＋直し10分 |
| Day34 | 既習の要点と直し記録を20分以内で確認。新規問題は解かない |

直前期は全範囲の一問一答を最初からやり直すのではなく、残った弱点を短く確認する。単元の完了率だけで実力を判断せず、**時間内に自力で解けたか、24時間以上後にも解けたか**で学習配分を調整する。
:::

# 3　中2の全範囲（要点・一問一答・演習）

## R9　中2化学：原子・分子・化学反応式・分解

:::box 要点
**① 分解**：1種類の物質が2種類以上の別の物質に分かれる化学変化。**熱分解**（加熱による）と**電気分解**（電流による）。

**炭酸水素ナトリウムの熱分解**　$\ce{2NaHCO3 -> Na2CO3 + CO2 + H2O}$（炭酸水素ナトリウム → 炭酸ナトリウム＋二酸化炭素＋水）
- 発生した気体を**石灰水**に通すと**白くにごる**（二酸化炭素）。試験管の口についた液体に**塩化コバルト紙**をつけると**青色 → 赤（桃）色**（水）。
- 試験管の口を**少し下げる**理由：発生した水が加熱部に流れて、試験管が**割れる**のを防ぐため。
- 火を消す**前に**ガラス管を水そうから抜く理由：水が逆流して、試験管が割れるのを防ぐため。
- 残った**炭酸ナトリウム**：水に**よくとけ**、フェノールフタレイン液で**濃い赤色**（強いアルカリ性）。もとの炭酸水素ナトリウムは水に少ししかとけず、**うすい赤色**（弱いアルカリ性）。

**酸化銀の熱分解**　$\ce{2Ag2O -> 4Ag + O2}$。黒色の酸化銀 → **白色の銀**（みがくと光る＝金属光沢、電気を通す、たたくとのびる）＋**酸素**（火のついた線香を入れると**炎を上げて燃える**）。

**水の電気分解**　$\ce{2H2O -> 2H2 + O2}$。純粋な水は電流を流しにくいので**水酸化ナトリウム**をとかす。**陰極（−）に水素、陽極（＋）に酸素**、体積比は**水素：酸素＝2：1**。水素はマッチの火を近づけると**音を立てて燃える**。

**② 原子と分子**
- **原子**：物質をつくる最小の粒子。(1) それ以上**分けられない**、(2) 化学変化で**なくならず、新しくできず、種類も変わらない**、(3) 種類によって**質量と大きさが決まっている**。
- **元素記号**：H 水素、He ヘリウム、C 炭素、N 窒素、O 酸素、Na ナトリウム、Mg マグネシウム、Al アルミニウム、S 硫黄、Cl 塩素、K カリウム、Ca カルシウム、Fe 鉄、Cu 銅、Zn 亜鉛、Ag 銀、Ba バリウム。元素を整理した表が**周期表**。
- **分子**：いくつかの原子が結びついた、**物質の性質を示す最小の粒子**。$\ce{H2}$、$\ce{O2}$、$\ce{N2}$、$\ce{H2O}$、$\ce{CO2}$、$\ce{NH3}$（アンモニア）。
- **分子をつくらない物質**：金属（Fe、Cu、Mg、Ag）、炭素 C、塩化ナトリウム NaCl、酸化銅 CuO、酸化マグネシウム MgO、酸化銀 $\ce{Ag2O}$、硫化鉄 FeS など。

**③ 単体と化合物**：**単体**は1種類の元素からできている（$\ce{H2}$、$\ce{O2}$、Fe、Cu）。**化合物**は2種類以上の元素からできている（$\ce{H2O}$、$\ce{CO2}$、NaCl、CuO）。どちらも**純粋な物質**。混合物（空気、食塩水）は別。

**④ 化学反応式の書き方**：矢印の左右で、**原子の種類と数を等しく**する。分子の数は化学式の前の**係数**で表す（1は書かない）。
- 例：水素＋酸素 → 水　$\ce{2H2 + O2 -> 2H2O}$（左：H 4個、O 2個／右：H 4個、O 2個）

**⑤ 化合（物質が結びつく化学変化）**
- **鉄＋硫黄 → 硫化鉄**　$\ce{Fe + S -> FeS}$。混合物の**上部**を加熱し、赤くなり始めたら**加熱をやめても反応は続く**（反応で**熱が出る**＝発熱反応）。
- 反応前の混合物：**磁石につく**（鉄）、うすい塩酸を加えると**水素**（無臭）が発生。反応後の硫化鉄：**磁石につかない**、うすい塩酸で**硫化水素**（**卵がくさったようなにおい**、有毒）が発生 → **別の物質**になった。
- 銅＋硫黄 → 硫化銅　$\ce{Cu + S -> CuS}$。炭素＋酸素 → 二酸化炭素　$\ce{C + O2 -> CO2}$。
:::

:::a 解答
1. 分解　2. 炭酸ナトリウム・二酸化炭素・水　3. 発生した水が加熱部に流れて試験管が割れるのを防ぐため　4. 炭酸ナトリウム　5. 水　6. 銀と酸素　7. 陰極：水素、陽極：酸素　8. 電流を流しやすくするため　9. 原子　10. Na ナトリウム、Cl 塩素、Ag 銀　11. $\ce{NH3}$　12. 単体　13. 硫化鉄・FeS　14. 硫化水素　15. $\ce{2H2 + O2 -> 2H2O}$
:::

:::q 演習（大問形式）　炭酸水素ナトリウムを試験管 A に入れて加熱し、発生した気体を試験管 B の石灰水に通した。加熱後、試験管 A の口の内側には液体がつき、試験管 A の底には白い固体が残った。
(1) 発生した気体を通すと、石灰水はどうなるか。また、その気体の化学式を書きなさい。
(2) 試験管 A の口の内側についた液体が何であるかを確かめる方法と、結果を書きなさい。
(3) 加熱をやめる前にしなければならないことを、理由とともに書きなさい。
(4) 試験管 A に残った白い固体と、もとの炭酸水素ナトリウムをそれぞれ水にとかし、フェノールフタレイン液を加えた。色の違いを説明しなさい。
(5) この化学変化を化学反応式で書きなさい。
(6) この実験のように、1種類の物質が2種類以上の物質に分かれる変化を何というか。また、加熱によるものを特に何というか。
:::

:::a 解答・解説
(1) 白くにごる・$\ce{CO2}$
(2) 塩化コバルト紙をつける。青色から赤（桃）色に変わる（→ 水である）。
(3) ガラス管を石灰水から抜く。石灰水が試験管 A に逆流して、試験管が割れるのを防ぐため。
(4) 白い固体（炭酸ナトリウム）の水溶液は濃い赤色、炭酸水素ナトリウムの水溶液はうすい赤色になる。炭酸ナトリウムのほうが強いアルカリ性で、水によくとける。
(5) $\ce{2NaHCO3 -> Na2CO3 + CO2 + H2O}$
(6) 分解・熱分解
:::

## R10　中2化学：酸化・還元・質量保存・質量の比

:::box 要点
**① 酸化と燃焼**：物質が酸素と結びつく化学変化が**酸化**、できた物質が**酸化物**。熱や光を出しながら激しく酸化することが**燃焼**。
- マグネシウム：$\ce{2Mg + O2 -> 2MgO}$。**激しい光**を出して燃え、**白色**の酸化マグネシウムになる。
- 銅：$\ce{2Cu + O2 -> 2CuO}$。光は出さず、赤色（赤茶色）の銅 → **黒色**の酸化銅。
- 鉄（スチールウール）：燃やすと**質量がふえる**（酸素が結びつくため）。燃やした後は**金属光沢がなく、電気を通さず**、うすい塩酸に入れても気体が出ない → 別の物質（酸化鉄）。
- 炭素：$\ce{C + O2 -> CO2}$。水素：$\ce{2H2 + O2 -> 2H2O}$。有機物（ろう、砂糖、エタノールなど炭素をふくむ物質）を燃やすと**二酸化炭素と水**ができる。

**② 還元**：酸化物から**酸素をとり去る**化学変化。酸化と還元は**同時に**起こる。
- **酸化銅＋炭素**：$\ce{2CuO + C -> 2Cu + CO2}$。酸化銅は**還元**されて銅に、炭素は**酸化**されて二酸化炭素に。→ 炭素のほうが銅より**酸素と結びつきやすい**。
- 結果：石灰水が白くにごる。試験管に**赤色の銅**が残り、こすると**金属光沢**。
- 注意：火を消す前にガラス管を石灰水から抜く（逆流防止）。火を消したら**ピンチコックでゴム管を閉じる**：熱い銅が空気中の酸素と結びついて（再び酸化されて）しまうのを防ぐ。
- 酸化銅＋水素：$\ce{CuO + H2 -> Cu + H2O}$。

**③ 化学変化と熱**
- **発熱反応**（熱を出し、まわりの温度が上がる）：燃焼、鉄粉＋活性炭＋食塩水（**化学かいろ**）、酸化カルシウム＋水（発熱式の弁当）、鉄＋硫黄。
- **吸熱反応**（熱を吸収し、まわりの温度が下がる）：**炭酸水素ナトリウム＋クエン酸**（＋水）、**水酸化バリウム＋塩化アンモニウム**（アンモニアが発生、においに注意）。

**④ 質量保存の法則**：化学変化の前後で、物質全体の質量は**変わらない**。理由：原子の**組み合わせは変わるが、原子の種類と数は変わらない**から。
- 硫酸＋塩化バリウム水溶液 → 白い沈殿（硫酸バリウム）。混ぜる前後で全体の質量は**同じ**。
- 炭酸水素ナトリウム＋うすい塩酸（密閉容器）：反応前後で質量は**同じ**。ふたを開けると**減る**（発生した二酸化炭素が容器の外に出るから）。

**⑤ 化学変化と質量の比**：金属と酸素は**一定の質量の比**で結びつく。
- **銅：酸素＝4：1**（銅：酸化銅＝4：5）。例：銅 2.0 g → 酸化銅 2.5 g（結びついた酸素 0.5 g）。
- **マグネシウム：酸素＝3：2**（マグネシウム：酸化マグネシウム＝3：5）。例：Mg 1.2 g → MgO 2.0 g。
- 金属の質量と結びつく酸素の質量のグラフ：**原点を通る直線**（比例）。
- 加熱を**くり返して質量が変わらなくなったら**、すべての金属が酸素と結びついた。**途中で加熱をやめると**未反応の金属が残る → 「反応した金属」＝「ふえた質量（酸素）× 比」で求める。
- 同じ質量の酸素と結びつく銅とマグネシウムの質量比：酸素 1 g に対して 銅 4 g、Mg 1.5 g → **銅：Mg＝8：3**。
:::

4. 銅を加熱したときの化学反応式を書きなさい。
5. スチールウールを燃やすと、質量はどうなるか。理由も答えなさい。
6. 酸化物から酸素をとり去る化学変化を何というか。

8. 7の反応で、還元された物質と酸化された物質をそれぞれ答えなさい。
9. 7の実験で、火を消した後にピンチコックでゴム管を閉じる理由は何か。
10. 周囲の温度が下がる化学変化を何というか。また、その例を1つ答えなさい。

13. 銅と酸素が結びつくときの質量の比は。

:::a 解答
1. 酸化　2. 燃焼　3. 酸化マグネシウム・白色　4. $\ce{2Cu + O2 -> 2CuO}$　5. ふえる。空気中の酸素が結びつくから　6. 還元　7. $\ce{2CuO + C -> 2Cu + CO2}$　8. 還元：酸化銅、酸化：炭素　9. 熱い銅が空気中の酸素と再び結びつく（酸化される）のを防ぐため　10. 吸熱反応・炭酸水素ナトリウムとクエン酸の反応（水酸化バリウムと塩化アンモニウムの反応）　11. 質量保存の法則　12. 化学変化の前後で、原子の組み合わせは変わるが、原子の種類と数は変わらないから　13. 銅：酸素＝4：1　14. Mg：MgO＝3：5 より 5.0 g　15. ふえた 0.5 g が酸素 → 反応した銅は 2.0 g → 未反応は **2.0 g**
:::

:::q 演習（大問形式）　銅の粉末をステンレス皿にとり、質量が変化しなくなるまでくり返し加熱して、できた酸化銅の質量を調べた。結果は表のようになった。

| 銅の質量 [g] | 0.40 | 0.80 | 1.20 | 1.60 | 2.00 |
|:--|--:|--:|--:|--:|--:|
| 酸化銅の質量 [g] | 0.50 | 1.00 | 1.50 | 2.00 | 2.50 |

(1) 銅 1.60 g と結びついた酸素の質量は何 g か。
(2) 銅の質量と、結びついた酸素の質量の比を、最も簡単な整数の比で答えなさい。
(3) 銅の質量を横軸、結びついた酸素の質量を縦軸にとってグラフをかくと、どのようなグラフになるか。
(4) 銅 3.20 g を完全に酸化すると、酸化銅は何 g できるか。
(5) 銅 2.40 g を加熱したところ、加熱が不十分で質量は 2.80 g になった。酸化されずに残っている銅は何 g か。
(6) 同じ実験をマグネシウムで行うと、マグネシウム 1.20 g から酸化マグネシウム 2.00 g ができた。同じ質量の酸素と結びつく銅とマグネシウムの質量の比を、最も簡単な整数の比で答えなさい。
:::

:::a 解答・解説
(1) $2.00 - 1.60 = 0.40$ g
(2) 銅 1.60：酸素 0.40 ＝ **4：1**
(3) 原点を通る直線（比例のグラフ）
(4) 銅：酸化銅＝4：5 → $3.20 \times \frac{5}{4} = 4.00$ g
(5) ふえた質量 $2.80 - 2.40 = 0.40$ g が結びついた酸素。酸素 0.40 g と結びつく銅は $0.40 \times 4 = 1.60$ g。残っている銅は $2.40 - 1.60 = 0.80$ g
(6) Mg 1.20 g と結びつく酸素は 0.80 g → Mg：酸素＝3：2。酸素 1 g あたり、銅は 4 g、Mg は 1.5 g → **銅：マグネシウム＝8：3**
:::

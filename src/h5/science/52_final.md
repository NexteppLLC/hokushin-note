## FIN　前日ページ：新範囲の要点と計算公式の確認（30分）

:::summary ★新範囲「生命の連続性」最終チェック
- **体細胞分裂**の順序：核が見える → **染色体が見える** → **中央に並ぶ** → **両端に分かれる** → **しきりができる**（植物）／**くびれる**（動物）→ 2つの細胞。分裂の**前に染色体は複製**されるので、分裂後の染色体の数は**もとと同じ**。
- 観察：**根の先端**（成長点付近で分裂がさかん）、**塩酸**で細胞を離れやすくする、**酢酸カーミン液**で染色、**押しつぶす**。
- **無性生殖**（分裂・出芽・**栄養生殖**）：体細胞分裂 → 子は親と**同じ遺伝子・同じ形質**。**有性生殖**：**減数分裂**で染色体が**半分**の生殖細胞（精細胞・卵細胞／精子・卵）→ **受精** → 受精卵（**もとの数**）→ **発生**。
- 被子植物：**花粉管**の中を**精細胞**が移動 → 胚珠の中の**卵細胞**と受精 → 受精卵 → **胚**、胚珠 → **種子**、子房 → **果実**。
- カエル：受精卵 → 細胞分裂をくり返す（**胚**）→ おたまじゃくし → 成体。細胞は分裂のたびに**小さく**なり、数がふえる。
- **メンデル**：**顕性**（子に現れる）／**潜性**（現れない）。**AA × aa → すべて Aa（顕性）**。**Aa × Aa → AA：Aa：aa ＝ 1：2：1 → 顕性：潜性 ＝ 3：1**。**Aa × aa → 1：1**。分離の法則：対になった遺伝子は**別々の生殖細胞**に入る。
- 遺伝子の本体は **DNA**（デオキシリボ核酸）、染色体にふくまれる。
:::

## R11　中2生物：細胞・消化と吸収

:::box 要点
**① 細胞のつくり**
- 動物と植物に共通：**核**（**酢酸カーミン液・酢酸オルセイン液**で赤く染まる、ふつう1個）、**細胞膜**、**細胞質**（核以外の部分）。
- **植物だけ**：**細胞壁**（からだを支える、じょうぶ）、**葉緑体**（光合成）、**液胞**（不要物や水をためる、成長した細胞で大きい）。
- **単細胞生物**：ゾウリムシ、ミカヅキモ、アメーバ、ミドリムシ。**多細胞生物**：**細胞 → 組織 → 器官 → 個体**（形やはたらきが同じ細胞の集まりが組織、いくつかの組織が集まって特定のはたらきをするのが器官）。

**② 消化**：食物中の養分を、吸収されやすい小さな物質に分解すること。**消化酵素**がはたらく（体温くらいでよくはたらく、決まった物質にだけはたらく）。

| 消化液 | 出す場所 | 消化酵素 | はたらく養分 |
|:--|:--|:--|:--|
| だ液 | だ液せん | **アミラーゼ** | デンプン |
| 胃液 | 胃 | **ペプシン** | タンパク質 |
| 胆汁 | **肝臓**でつくられ**胆のう**にたくわえられる | **なし**（消化酵素をふくまない） | 脂肪の分解を助ける |
| すい液 | すい臓 | アミラーゼ・**トリプシン**・**リパーゼ** | デンプン・タンパク質・脂肪のすべて |
| 小腸の壁の酵素 | 小腸 | — | デンプン・タンパク質 |

- 最終的に：**デンプン → ブドウ糖**、**タンパク質 → アミノ酸**、**脂肪 → 脂肪酸とモノグリセリド**。
- 消化管：口 → 食道 → 胃 → 小腸 → 大腸 → 肛門（1本の管）。

**③ 吸収**：おもに**小腸**。小腸の内側のひだに無数の**柔毛**（表面積が大きくなり、効率よく吸収できる）。
- **ブドウ糖・アミノ酸 → 柔毛の毛細血管** → 肝臓（門脈）→ 全身。
- **脂肪酸とモノグリセリド → 柔毛で再び脂肪になり → リンパ管** → 首の近くで血管に合流。
- **肝臓**：ブドウ糖の一部を**グリコーゲン**にして貯蔵、有害な**アンモニアを尿素**に変える、**胆汁**をつくる。**大腸**：おもに**水分**を吸収。

**④ だ液の実験**：デンプン溶液に**だ液**を入れた試験管 A と**水**を入れた試験管 B（対照実験）を、**約40℃**（体温に近い温度）の湯に 10 分入れる。
- **ヨウ素液**：A は変化なし（デンプンがなくなった）、B は**青紫色**（デンプンあり）。
- **ベネジクト液**を加えて**加熱**：A は**赤褐色の沈殿**（麦芽糖などができた）、B は変化なし。
- 結論：だ液にはデンプンを麦芽糖などに分解するはたらきがある。
:::

:::q 一問一答（15問）
1. 核を赤く染める染色液を1つ答えなさい。
2. 植物の細胞にだけあるつくりを3つ答えなさい。
3. 細胞の形を保ち、からだを支えるつくりを何というか。
4. 単細胞生物の例を2つ答えなさい。
5. 形やはたらきが同じ細胞の集まりを何というか。また、それが集まって特定のはたらきをするものを何というか。
6. だ液にふくまれる消化酵素は何か。また、何を分解するか。
7. 胃液にふくまれる消化酵素は何か。
8. 消化酵素をふくまないが、脂肪の分解を助ける消化液は何か。また、どこでつくられるか。
9. デンプン・タンパク質・脂肪のすべてにはたらく消化液は何か。
10. タンパク質は最終的に何に分解されるか。
11. 脂肪は最終的に何と何に分解されるか。
12. 小腸の内側の壁にある、小さな突起を何というか。また、その利点は何か。
13. ブドウ糖とアミノ酸は柔毛のどこに入るか。脂肪酸とモノグリセリドはどこに入るか。
14. 肝臓のはたらきを2つ答えなさい。
15. デンプンが分解されてできた糖を調べる薬品と、その結果を答えなさい。
:::

:::a 解答
1. 酢酸カーミン液（酢酸オルセイン液）　2. 細胞壁・葉緑体・液胞　3. 細胞壁　4. ゾウリムシ・ミカヅキモ（アメーバ、ミドリムシ）　5. 組織・器官　6. アミラーゼ・デンプン　7. ペプシン　8. 胆汁・肝臓　9. すい液　10. アミノ酸　11. 脂肪酸とモノグリセリド　12. 柔毛・表面積が大きくなり、養分を効率よく吸収できる　13. ブドウ糖・アミノ酸は毛細血管、脂肪酸・モノグリセリドは（再び脂肪になって）リンパ管　14. ブドウ糖をグリコーゲンにして貯蔵する／アンモニアを尿素に変える／胆汁をつくる（から2つ）　15. ベネジクト液を加えて加熱する・赤褐色の沈殿ができる
:::

:::q 演習（大問形式）　試験管 A にデンプン溶液とだ液を、試験管 B にデンプン溶液と水を同量ずつ入れ、約40℃の湯に 10 分間つけた。その後、A と B の液をそれぞれ2つに分け、一方にヨウ素液を加え、もう一方にベネジクト液を加えて加熱した。
(1) 約40℃の湯につけたのはなぜか。
(2) 試験管 B を用意した理由を書きなさい。
(3) ヨウ素液を加えたとき、青紫色になったのは A と B のどちらか。
(4) ベネジクト液を加えて加熱したとき、赤褐色の沈殿ができたのは A と B のどちらか。
(5) (3)・(4)の結果から、だ液のはたらきについてわかることを書きなさい。
(6) だ液にふくまれる消化酵素の名前を答えなさい。
(7) 消化された養分のうち、ブドウ糖が小腸の柔毛から入る管を答えなさい。
:::

:::a 解答・解説
(1) 消化酵素は、体温に近い温度でよくはたらくから。
(2) だ液のはたらきによってデンプンが変化したことを確かめるため（だ液以外の条件を同じにして比べるため）。
(3) B（デンプンが残っている）
(4) A（麦芽糖などができた）
(5) だ液には、デンプンを麦芽糖などの糖に分解するはたらきがある。
(6) アミラーゼ
(7) 毛細血管
:::

## R12　中2生物：呼吸・血液循環・排出・刺激と反応

:::box 要点
**① 呼吸**
- 空気は 鼻・口 → **気管** → **気管支** → **肺胞**（小さな袋、毛細血管が取り巻く）。肺胞が多数あるので**表面積が大きく**、気体の交換が効率よくできる。
- 肺には筋肉がなく、**横隔膜**とろっ骨（ろっ骨の間の筋肉）の動きで空気が出入りする（横隔膜が下がると胸の空間が広がり、空気が入る）。
- **細胞の呼吸**（細胞による呼吸）：細胞が**酸素**を使って**養分**を分解し、**エネルギー**をとり出す。このとき**二酸化炭素と水**ができる。

**② 血液の成分**
- **赤血球**：**ヘモグロビン**（酸素の**多い**ところで酸素と結びつき、**少ない**ところで酸素をはなす）をふくみ、酸素を運ぶ。中央がくぼんだ円盤形。
- **白血球**：体内に入った**細菌**などを分解する。**血小板**：出血したとき**血液を固める**。
- **血しょう**：液体。養分・不要物・二酸化炭素などをとかして運ぶ。毛細血管からしみ出したものが**組織液**（細胞との物質のやりとりのなかだち）。

**③ 心臓と血液循環**
- 心臓は**右心房・右心室・左心房・左心室**の4つの部屋。心房は血液を受け入れ、心室は送り出す。**弁**で逆流を防ぐ。
- **肺循環**：右心室 → **肺動脈** → 肺 → **肺静脈** → 左心房。**体循環**：左心室 → **大動脈** → 全身 → **大静脈** → 右心房。
- **動脈**：心臓から送り出される血液が流れる。壁が**厚く**弾力がある。**静脈**：心臓にもどる血液。壁がうすく、ところどころに**弁**。
- **動脈血**：酸素を多くふくむ（あざやかな赤色）。**静脈血**：二酸化炭素を多くふくむ。★**肺静脈**には**動脈血**、**肺動脈**には**静脈血**が流れる（名前と逆）。
- 養分が最も多い血液 → 小腸を出た血液（肝臓へ向かう血管）。酸素が最も多い → 肺静脈。尿素が最も少ない → じん臓を出た血液。

**④ 排出**：細胞でアミノ酸が分解されると有害な**アンモニア**ができる → **肝臓**で害の少ない**尿素**に変えられる → **じん臓**で血液からこし出され、**輸尿管** → **ぼうこう** → 尿として排出。汗（汗せん）からも不要物が出る。

**⑤ 刺激と反応**
- **感覚器官**：目（**レンズ**が光を屈折、**網膜**に像ができる、**虹彩**が光の量を調節）、耳（**鼓膜**が振動 → 耳小骨 → **うずまき管**）、鼻、舌、皮膚（温度・圧力・痛み）。
- **神経系**：**中枢神経**（**脳・せきずい**）と**末しょう神経**（**感覚神経**：感覚器官 → 中枢、**運動神経**：中枢 → 筋肉）。
- 意識して起こす反応（手の皮膚の刺激を受けて手を動かす例）：皮膚 → 感覚神経 → せきずい → **脳** → せきずい → 運動神経 → 筋肉。
- **反射**：刺激に対して**意識とは無関係に**起こる決まった反応。例：熱いものにふれて手を引っこめる、明るさでひとみの大きさが変わる、食物を口に入れるとだ液が出る、ひざ下をたたくと足が上がる。
- **熱いものにふれて手を引っこめる反射の経路**：皮膚 → 感覚神経 → **せきずい** → 運動神経 → 筋肉。脳の意識的な判断を待たずにせきずいから命令が出るので、すばやく手を引っこめられる。**刺激の信号は脳にも伝わり、熱いと感じる。**
- 反射の命令を出す中枢は種類によって異なる。ひとみの変化やだ液の分泌も反射だが、上のせきずいの経路をすべての反射に当てはめない。
- 骨と筋肉：筋肉は**けん**で骨についている。関節をはさんで**対になった筋肉**が、一方が縮み、もう一方がゆるんでうでを曲げのばしする。
:::

:::q 一問一答（15問）
1. 肺の中にある小さな袋を何というか。また、多数あることの利点は何か。
2. 細胞が酸素を使って養分からエネルギーをとり出すことを何というか。
3. 赤血球にふくまれ、酸素と結びつく物質は何か。
4. 血液を固めるはたらきをする成分は何か。
5. 血液の液体成分を何というか。また、それが毛細血管からしみ出したものを何というか。
6. 心臓から全身へ血液を送り出す部屋はどこか。
7. 右心室 → 肺 → 左心房 の血液の流れを何というか。
8. 動脈血が流れている静脈は何か。
9. 静脈にあって動脈にない、逆流を防ぐつくりは何か。
10. アンモニアを尿素に変える器官と、尿素をこし出す器官をそれぞれ答えなさい。
11. 目で、像ができる部分を何というか。
12. 脳とせきずいをまとめて何というか。
13. 感覚器官からの信号を中枢に伝える神経を何というか。
14. 刺激に対して無意識に起こる反応を何というか。また、その例を1つ答えなさい。
15. 熱いものにふれて手を引っこめる反射で、脳の意識的な判断を待たずに命令が出ることの利点は何か。
:::

:::a 解答
1. 肺胞・表面積が大きくなり、気体の交換が効率よくできる　2. 細胞の呼吸（細胞による呼吸）　3. ヘモグロビン　4. 血小板　5. 血しょう・組織液　6. 左心室　7. 肺循環　8. 肺静脈　9. 弁　10. 肝臓・じん臓　11. 網膜　12. 中枢神経　13. 感覚神経　14. 反射・熱いものにふれて手を引っこめる（明るさでひとみの大きさが変わる など）　15. 刺激を受けてから反応するまでの時間が短い（すばやく危険からのがれることができる）
:::

:::q 演習（大問形式）　図は、ヒトの血液の循環を模式的に表したものである。①〜⑧は血管を、矢印は血液の流れる向きを表す。

(1) 血管 ① と ② の名前をそれぞれ答えなさい。また、肺から血液がもどってくる心臓の部屋の名前を答えなさい。
(2) ①〜⑧のうち、静脈血が流れている動脈はどれか。番号で答えなさい。
(3) ①〜⑧のうち、食後、ブドウ糖やアミノ酸を最も多くふくむ血液が流れている血管はどれか。
(4) ①〜⑧のうち、尿素が最も少ない血液が流れている血管はどれか。
(5) ヘモグロビンの性質を、「酸素の多いところ」「酸素の少ないところ」の語を使って説明しなさい。
(6) 肺胞のまわりの毛細血管で、血液中にとりこまれる気体と、血液中から出される気体をそれぞれ答えなさい。
(7) 熱いやかんに手がふれたとき、思わず手を引っこめた。このとき、刺激の信号が伝わる経路を、次のア〜オから必要なものを選び、順に並べなさい。　ア 感覚神経　イ 運動神経　ウ 脳　エ せきずい　オ 皮膚

:::a 解答・解説
(1) ①：肺動脈、②：肺静脈・左心房
(2) ①（肺動脈：心臓から肺へ向かう血液は二酸化炭素を多くふくむ静脈血）
(3) ③（小腸で吸収した養分をふくむ血液が肝臓へ向かう）
(4) ⑥（じん臓で尿素がこし出された後の血液）
(5) 酸素の多いところでは酸素と結びつき、酸素の少ないところでは酸素をはなす性質。
(6) とりこまれる：酸素、出される：二酸化炭素
(7) オ → ア → エ → イ（→ 筋肉）。この手を引っこめる反射では、脳の意識的な判断を待たずにせきずいから命令が出る。刺激の信号は脳にも伝わり、熱いと感じる。
:::
